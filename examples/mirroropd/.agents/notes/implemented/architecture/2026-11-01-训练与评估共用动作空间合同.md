# Agent Note: 训练与评估共用动作空间合同

Status: implemented

选择：提取纯数据的模型配对合同与分布定义，编译为现有 head 路径的索引、归一化和动作分组计划。训练继续由 LossContext 处理梯度与全局分母，只读评分继续使用 value-only 路径；V1、RolloutService、SharedTeacherScorer 和 TQ 保持执行所有权。接口、数值反例及迁移顺序由[架构方案](../../../../docs/infra/architecture/evaluation/动作空间与模型兼容.md)维护。

## 理由与代价

当前源码已经区分 raw head RKL、EOS 合并训练目标和 teacher 额外支持修正。扩大模型白名单或在调用点裁到 min(Vs,Vt) 会把数学对象的改变藏在兼容修补中。共享语义编译能让训练和验证选择同一概率空间，同时保留历史 raw 诊断。

真实备选是继续维护各入口的 slice／EOS 规则，或重建通用训练／评估框架。前者短期改动小，但每个新模型都增加语义分叉；后者引入新的调度与状态所有者，重复已经验收的执行层。实际代价是一次显式的结果字段与身份版本迁移，以及每种支持模式的数值验收。

## 不变量与验收

- 已批准的 R1 共同支持 C151936 指共同输出行，不能自动改成 151665 个有效 token ID。条件 RKL 同时报告双方排除质量。
- EOS 合并前后、MDPO 目标构造次序及输入／输出 ID 映射显式声明。分组与条件化的首版组合要求完整保留动作类。
- 原生 identity 快路径维持旧 value/VJP、位置对应和全局分母；只读评分不计算 VJP。新增映射保留 root/head FSDP hooks。
- Bootstrap 与 current 的引擎支持规则一致，并在产物身份中记录。旧未屏蔽生成回答单列保存，不改写为新协议。
- 新 Llama adapter 需真实权重、FSDP 更新与导出回读；真正不同分词边界另立序列层协议。

共同支持、排除质量、EOS 目标／raw 诊断、Llama head 和等价 ID 映射均已实现。原生默认行为的 CPU 回归、12 组 CUDA 条件核与 5 组两卡 FSDP 验证通过；真实 JustRL→R1-7B 和 GT-Llama→Llama-3.2-3B 完成单步原生全链验收。Llama tiny 配置验证了 checkpoint 回读，正式 R1 最终 HF 权重另有 128 条原轨迹的独立回读，RKL 误差为 0。证据与覆盖范围见[实现验收摘要](../../../../docs/infra/architecture/evaluation/data/compatibility-implementation-20261101/summary.json)。

这些验收覆盖所选代表实现与 checkpoint，不是所有模型 revision、硬件或精度组合的承诺。原始 R1 小 teacher 等其余科研配对、完整跨域训练和更大预算仍留在实验计划；用户要求暂不启动大型实验。新的 bias、softcap、量化或真正不同分词，需要补相应投影／序列协议和验收。

本记录补充[统一验证的任务计划与产物边界](../../proposed/architecture/2026-10-31-统一验证的任务计划与产物边界.md)，不替代其中的 Parquet、调度与最终 checkpoint 决定。只有实际新模型需要时才增加 bias、softcap 或跨分词能力，不预先引入通用 GPU 服务和长期 logit 缓存。
