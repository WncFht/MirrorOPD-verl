# 数据与统计口径

[测量结果](测量结果.csv)提供中文列名和换算单位；[同条件统计](同条件统计.csv)提供完整集生成服务的复测统计；[未舍入数据](measurements.csv)保留原始精度、运行标识和来源位置，供复算使用。

## 设备与测试方式

测试机 A 对应 bsud-quicksilver-hppk-13；测试机 B 对应 bsud-quicksilver-vtuk-1。设备标识用于隔离比较条件，不合并不同设备的结果。四卡完整验证资料中的设备只按来源确认到 H800 四卡，不能推定与 A/B 是同一台机器。

完整验证计时包含生成、判分和聚合，独立服务计时覆盖整批生成。单卡自然生成与合成长前缀测试分别记录。原始文件中的日期和运行标识只用于定位证据，不代表可比较的实验分组。

## 汇总规则

同条件统计按模型、设备、并发、显存比例、调度预算分组，仅纳入完整数学集的有效服务测量。平均耗时为总耗时除以次数，吞吐为总输出量除以总耗时。输出量和回答数列在汇总表中表示每次测量平均值；峰值列为所有测量中的最大值。抢占次数列为每次平均值，归一化抢占为总抢占次数除以总输出量。

GPU 忙碌率按采样数加权，缺失采样数时按时长加权。回答触顶比例和每 token 耗时按回答数加权。空白表示无记录，不表示零。合成压力结果只用于容量诊断，排除记录不参与推荐或平均。

原始 verl 全量与参数对照的计时、成功计数、token计数、评分失败数和NVML峰值已经按归档证据核对。原生服务记录的原流程验证状态独立判断，不能仅凭服务运行完成视为完整验证通过。
