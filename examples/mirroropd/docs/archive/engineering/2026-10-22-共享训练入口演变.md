# 共享训练入口的历史演变

以下为2026-10-22运行指南记录的入口演变。当前配置与支持以[运行指南](../../infra/training/runtime.md)及源码校验为准。

<a id="runtime-history-从-565a1fda2-到-5b3ccdd30-的脚本差异"></a>

### 从 565a1fda2 到 5b3ccdd30 的脚本差异

`565a1fda2`时已经是 shared 八卡、FSDP2、V1/TQ；不能把更早的 4+4 迁移归入这个 commit 区间。math/code 领域入口没有变化，公共脚本的变化均来自`5b3ccdd30`：

| 项目                    | 565a1fda2      | 5b3ccdd30                                                |
| ----------------------- | -------------- | -------------------------------------------------------- |
| `ROLLOUT_ENFORCE_EAGER` | 默认 True      | 默认 False，开启编译＋Graph                              |
| `VAL_BATCH_SIZE`        | 默认 16        | 默认 32                                                  |
| Graph capture sizes     | 不显式传入     | 按并发上限派生，默认`[1,2,4,8,16,32]`                    |
| 并发输入校验            | 未检查该字段   | 检查`ROLLOUT_MAX_NUM_SEQS`为正整数                       |
| 退出保护                | 运行至文件末尾 | 将 pipeline 与 exit 一并解析，防止运行期间源码变化后重入 |

配套 Python 改动是 V0/V1 验证不请求无用概率，以及 V1 初始验证增加已有`timing_s/testing`。训练 prompt/mini64、epoch1、学习率、长度、验证 n16、引擎并发 32/token8192/memory0.5 均未改变。`benchmark_decode.py`是新增独立诊断工具，不在正常训练调用链上。


<a id="runtime-history-后续实现与当前配置"></a>

### 后续实现与当前配置

优势/IS 消融已接入，算法与配置提交为 `d40950fc6`，更新计数与恢复提交为 `f274a24f6`。公共脚本读取 `PPO_EPOCHS`、`OPD_ADVANTAGE_SOURCE`、`OPD_POLICY_LOSS_MODE` 和 `OPD_CLIP_EPS`；默认和 E 系列覆盖统一见[训练配方](../../experiments/learning-signal/sampled-controls.md)，配置合同与恢复语义见[实施记录](2026-10-21-优势与更新计数原方案.md)。

第一版 V1 指标在 `7eed88db9`、`4a70b9229` 和 `5edacea9b` 接入，区分 `step/outer`、`step/update` 与 `step/optimizer`，并保留逐更新记录。后续 policy-v3 的字段与 FSDP2 四卡实测范围以[训练指标](../../infra/architecture/metrics.md)及[完整验收](../metric-implementation/2026-10-22-完整指标实现与验收.md)为准；目标八卡配置的验收边界仍按本页的配置与硬件条件单独判断。

Actor 执行默认值集中在[训练配方](../../settings/训练设置.md#actor-执行配置)；激活重算、动态 micro 与延后同步的候选比较见[调优矩阵](../../infra/performance/2026-10-22-批量大小与GPU利用率调优.md#73-actor-重算micro-与梯度同步联合筛选)。

延后同步的代码位于 [FSDP engine](../../../../../verl/workers/engine/fsdp/transformer_impl.py) 的 `_gradient_sync_context()`。`FSDPEngineConfig` dataclass 默认 True，但 [engine YAML](../../../../../verl/trainer/config/engine/fsdp.yaml) 显式设为 False，公共配方继承 YAML；判断实际行为应读取合成配置。开启后需要保留未分片梯度，性能与显存取舍按[调优矩阵](../../infra/performance/2026-10-22-批量大小与GPU利用率调优.md#7-分层筛选与四卡到八卡验收)测试。
