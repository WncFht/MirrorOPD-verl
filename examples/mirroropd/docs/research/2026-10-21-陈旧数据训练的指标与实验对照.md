# 陈旧数据训练的指标与实验对照

更新日期：2026-10-21。本文解释重要性采样（importance sampling，IS）的 p99、clipping、策略漂移和有效样本量等指标，整理 M2PO、AsyncOPD、Lightning OPD、Semi-OPD，以及 VeXact、Score Centering、CIS、Distillation Dynamics 等 14 项工作的实验设置、原文图片和结果，并给出 MirrorOPD 的下一阶段实验建议。

证据分为三类：**论文报告**指指定版本正文或表格中的数值；**图上近似读数**仅用于判断量级，不冒充原始实验数据；**本项目分析**指基于公式、源码和已下载 W&B history 的解释或建议。所有模型效果数字只在各自实验内部比较。M2PO 是可验证奖励强化学习（RLVR），其结论不能自动推广到带 teacher token 信号的 OPD。

## 1. 当前最重要的判断

本轮扩展重点见第 9 节（四篇指定论文）、第 10 节（六篇关联工作）和第 11 节（本项目指标优先级）。**效果首先看 held-out 准确率；机制诊断优先拆分同权重 TIM 与更新漂移，并看优势加权后的信号变化，不能只看 p99 或 clip 比例。**

- p99 是分布尾部的一个位置，不能单独说明平均漂移、最极端异常或更新质量。
- 我们当前跨 rollout batch 的版本延迟为 0；同批四轮更新产生的是批内 0、1、2、3 次 optimizer update 的年龄。将总训练预算从 32 改为 200，不会增加这段延迟。
- M2PO 的 stale 单位是 optimizer update；AsyncOPD 扫描图的单位是 train-batch step。两篇设置中一个外层 step 都含四次更新，因此 M2PO 的 stale-256 与 AsyncOPD 的 stale-64 在更新次数上相近，但模型、目标、数据和具体缓存协议并不相同。
- 四组 E2–E5 在共同的前 120 次更新内训练动态接近。E2/E4 有末次验证；下载时 E3/E5 的云端 history 只到 step 30、缺少最终验证。不能据此排出四组效果名次。
- 要检验 stale 鲁棒性，应增加可控延迟并记录实际概率漂移；要检验最终效果，应增加验证检查点。两者是不同实验问题。

## 2. p99 是什么，应该与哪些指标一起看

### 2.1 先明确统计对象

对有效 response token，记生成时策略为 $\mu$、当前训练策略为 $\pi_\theta$，固定前缀为 $s_i$，采样 token 为 $a_i$：

$$
\rho_i=\frac{\pi_\theta(a_i\mid s_i)}{\mu(a_i\mid s_i)},\qquad
z_i=\log\rho_i=\ell_{\theta,i}-\ell_{\mu,i}.
$$

这里比较的是 **当前 student 与行为 student**。teacher/student 的 KL、teacher/student 的 top-k overlap，以及当前 student 与另一个 proximal policy 的比率，都不是同一个量。日志必须注明分子、分母、采样分布与测量时机。

### 2.2 p99 的定义与直觉

对 $N$ 个有效观测，定义经验分布函数和分位数：

$$
\widehat F(x)=\frac{1}{N}\sum_{i=1}^N\mathbf 1[\rho_i\le x],\qquad
q_p=\inf\{x:\widehat F(x)\ge p\}.
$$

本文的 p99 指 $q_{0.99}$。在上述最近秩定义下，将 10,000 个 ratio 排序，p99 对应第 9,900 个值。若 p99=2，大约 99% 的观测不超过 2；剩余约 1% 可以是 2.1，也可以包含远大于 2 的值。不同库可能在相邻顺序统计量间插值，复现时应固定分位数算法。

| 统计量 | 回答的问题 | 单独使用的盲点 |
| --- | --- | --- |
| p50 | 典型 token 的 ratio 在哪里 | 看不到尾部 |
| p01、p05 | 当前策略是否大幅压低某些行为 token 的概率 | 只看下尾，遗漏上尾 |
| p95、p99、p99.9 | 上尾增长到什么量级 | p99 看不到最极端的 1%；小样本的高分位数不稳定 |
| mean、std | 整体中心与离散程度 | 均值可能掩盖两侧变化；std 对极端值敏感 |
| max / min | 最坏观测是什么 | 很受有效 token 数和偶发异常影响 |
| 尾部权重占比 | 少量 token 是否承担大量 surrogate 权重 | 权重占比不等于真实梯度范数占比 |

**示意反例：** 10,000 个数中，前 9,900 个都是 1；剩余 100 个全为 2，或其中一个改成 $10^6$，最近秩 p99 都是 1。后者的均值与二阶矩却会剧烈变化。这是统计量演示，不是实测的策略比率数据。

### 2.3 三种“clip”必须分开

设 PPO 的上下阈值为 $1-\epsilon_l$ 和 $1+\epsilon_h$，优势已 detach：

$$
L_i=\max\left(-\rho_i A_i,-\operatorname{clip}(\rho_i,1-\epsilon_l,1+\epsilon_h)A_i\right).
$$

可以分别记录：

$$
f_{\mathrm{outside}}=\frac{1}{N}\sum_i\mathbf1[\rho_i<1-\epsilon_l\ \lor\ \rho_i>1+\epsilon_h],
$$

$$
f_{\mathrm{active}}=\frac{1}{N}\sum_i\mathbf1[(A_i>0\land\rho_i>1+\epsilon_h)\ \lor\ (A_i<0\land\rho_i<1-\epsilon_l)].
$$

前者是 **ratio 越界比例**，后者是 **PPO 裁剪项严格改变目标的比例**；$A_i=0$ 不计入后者。ratio=2 且 $A<0$ 时，普通 PPO 不会因为上界 1.2 而剪掉该方向的项。因此实际 clip 很少，并不推出所有 ratio 都在 $[0.8,1.2]$ 内。PPO 裁剪目标也不强制真实策略比率永远处于该区间。

另有两类不同指标：**advantage clipping** 限制 $A$ 的数值，**response length clipping** 记录回答达到长度上限的比例。数值保护 `clamp(log_ratio, -20, 20)` 又是第四种操作，不应叫作 PPO clip。

### 2.4 KL、log-ratio 二阶矩与 ESS

以下是诊断定义及其条件，不表示本项目已经全部实现。

| 名称 | 经验量 | 作用与限制 |
| --- | --- | --- |
| signed log-ratio KL 估计 | $\widehat K_1=-\frac1N\sum_i z_i$ | 在固定策略、行为采样和相应支持条件下估计 $\mathrm{KL}(\mu\Vert\pi_\theta)$；有限样本项可正可负，可能抵消 |
| 非负 KL 估计形式 | $\widehat K_3=\frac1N\sum_i(\rho_i-1-z_i)$ | 单项非负；要具有同一 KL 的期望还需 $\mathbb E_\mu[\rho]=1$ 等支持条件 |
| **log-ratio 二阶矩** | $\widehat M_{2,\log}=\frac1N\sum_i z_i^2$ | M2PO Eq. (4) 的量；既反映 log-ratio 均值偏移，也反映其方差 |
| ratio 二阶矩 | $\widehat M_{2,\rho}=\frac1N\sum_i\rho_i^2$ | 与大权重集中有关，**不是 M2PO Eq. (4)** |
| 归一化有效样本量 | $\mathrm{ESS}/N=\frac{(\sum_i\rho_i)^2}{N\sum_i\rho_i^2}$ | 描述这组 IS 权重的集中程度；不是相关 token 的真实独立样本数 |

当策略与采样条件允许时，$\mathbb E_\mu[\rho]=1$，且 $\mathbb E_\mu[\rho^2]=1+\chi^2(\pi_\theta\Vert\mu)$。有限缓存、重复利用训练样本、截断采样和不同 prefix 分布都可能破坏直接套用这些人口统计恒等式的条件，不能要求实测 ratio mean 必须恰好为 1。

对 log-ratio 有恒等分解：

$$
\mathbb E[z^2]=\operatorname{Var}(z)+(\mathbb E[z])^2.
$$

这解释了为什么 $-\mathbb E[z]$ 很小时，$\mathbb E[z^2]$ 仍可能很大。但 **log-ratio 二阶矩小，不构成无条件的 ratio 极端尾部保证**。M2PO 的定理额外假设 $1/R\le\rho\le R$，才有 $\chi^2\le R^2 M_{2,\log}$；不能省略 $R$ 有界的条件。[^m2po]

### 2.5 一套实用的观测顺序

| 层次 | 建议指标 | 判断目标 |
| --- | --- | --- |
| 最终任务质量 | 各数据集 avg@n / 单次成功率估计、初始验证、多个 checkpoint、重复种子 | 是否学得更好；avg@16 不等于 pass@16 |
| 训练是否正常 | optimizer attempts/steps/skips、非有限量、梯度范数、LR、长度触顶率 | 排除计数错误、数值失稳与大量截断 |
| 数据有多旧 | 生成版本、训练版本、optimizer-update age 分布 | 量化实际延迟，不能只记录配置中的队列深度 |
| 策略究竟漂了多少 | ratio 分位数与极值、$K_1/K_3$、$M_{2,\log}$、ESS/N | 区分版本年龄与概率漂移 |
| 哪些训练信号被改掉 | outside fraction、active clip fraction、M2PO mask fraction、优势符号及大小 | 判断 clipping 是否只处理少数尾部，或丢弃了重要方向 |
| 信号与 token 类型的关系 | 按 $\lvert\rho-1\rvert$、熵、位置、优势正负分桶 | 分析高漂移 token 是否集中在高熵或特定推理位置 |
| 成本 | 有效训练 token/s、验证耗时、GPU-hours、同预算准确率 | 判断收益是否抵得过生成和评分成本 |

熵应注明策略：$H_\theta(s)=-\sum_a\pi_\theta(a\mid s)\log\pi_\theta(a\mid s)$ 是完整分布熵；单个 token 的 $-\log\pi_\theta(a\mid s)$ 是 surprisal，不应混称为完整熵。评估多个 run 的差异时，应按题目聚类做配对统计或 bootstrap，并补充不同训练种子；不能把同一道题的 16 条回答简单当成 16 个独立题目。

### 3.3 M2PO 的约束不是固定的 ratio 上限

M2PO 从有 trust-region 约束方向的 token 中，依次移除 $z_i^2$ 最大的 token，直到保留集合的平均值不超过 $\tau_{M_2}$。原文考虑的候选方向为 $A>0,\rho>1$ 或 $A<0,\rho<1$；这是 **候选约束集合**，不是普通 PPO 的完整 active-clip 条件。实际 PPO 还需跨过 $1\pm\epsilon$。[^m2po]

**本项目解释：** $\tau_{M_2}=0.04$ 对应保留集合的 log-ratio RMS 不超过 0.2，并不要求每个 $|z_i|\le0.2$，也不等于统一要求每个 ratio 处在 $[0.8,1.2]$。记录 M2 时须区分全部有效 token、候选约束集合、mask 后保留集合；否则“约束到 0.04”与日志的全体均值可能不是同一口径。

### 3.4 结果与转用边界

原论文 Table 1 中，Qwen3-Base-4B 的八基准平均成绩为：GRPO stale-0 **50.7%**、GRPO stale-256 **40.1%**、M2PO stale-256 **51.3%**。这是按其最优平均 checkpoint 选点的 RLVR 结果。[^m2po]

对 OPD 更直接的启发是“观察尾部、被裁剪 token 的性质，以及约束前后变化”。不能直接推出 OPD 应采用同一个 $0.04$ 阈值，或应该丢弃同样比例的 token。RLVR 的题目级优势与 OPD 的 teacher/student token 优势具有不同的符号、尺度和刷新机制。

论文另有完全异步系统实验，使用 100 个外层 step、队列参数 $\tau=4$；其容量为 $(\tau+1)B$，不是每条样本实测延迟恒等于 4。公开配方用很大的 `pg_clip_eps` 实现近似 no-clip，核心仍有 log-ratio 的 $[-20,20]$ 数值保护，因而需分别讨论 PPO clipping 与数值保护。[^asyncopd][^async-code]

### 8.1 为什么增加总 step 不等于增加 stale

若生成版本的 optimizer 累计计数为 $u_{\rm gen}$，某次训练 forward 前已完成更新数为 $u_{\rm train}$，应定义：

$$
\Delta_u=u_{\rm train}-u_{\rm gen}.
$$

我们每批生成后立即训练，批内四轮的 $\Delta_u$ 为 0、1、2、3。下一批重新生成，再从 0 开始。这个计数不包含 vLLM 与 FSDP 的数值差异；后者可能使年龄 0 时的 ratio 也不严格等于 1。

如果实现跨 batch 延迟 $D$，每个外层仍四次更新，则稳态训练入口的年龄约为 $4D$，批内再加 0–3。例如 $D=4$ 对应 16–19 次更新，$D=16$ 对应 64–67 次，$D=64$ 对应 256–259 次。启动初始缓存时会有 warmup，必须记录实际年龄分布。

### 8.2 下一轮最小实验与诊断

| 步骤 | 固定条件 | 增加的观测或干预 |
| --- | --- | --- |
| 补齐已有实验 | 保持 E2–E5 已有配置 | 同步 E3/E5 末次验证；检查 checkpoint 与计数 |
| 固定批诊断 | 固定轨迹、teacher 分数、行为概率 | 每内部更新记录 ratio 分位数、M2log、ESS、outside/active 比例、优势符号和大小 |
| 受控延迟扫描 | LR、batch、mini-batch、epochs、种子不同时改变 | 先 $D=0,4,16$；优先 E2/E4，随后 E1/E3 与 E5 |
| 效果延长 | 保持同组算法不变，按真实更新计数对齐 | 先看 step64，再决定 128/200；不能仅看 train loss |
| 统计复验 | 同验证集与生成参数 | 逐题配对统计、多个训练种子；区分过程最好点和最终点 |

跨 batch 队列尚未在这份最小实现中落地。提高 `PPO_EPOCHS` 可以做低成本批内复用压力测试，但同时改变样本复用和更新预算，不能标成论文的跨 batch 延迟实验。32 步预算也不足以覆盖 $D=64$ 的稳态。

### 8.3 指标聚合与实现口径

- 有效 mask 先应用于 log-prob 算术；pad、prompt、被剔除轨迹不进入 token 分母。空 rank 继续参与分布式通信。
- 每个内部 optimizer 更新有独立诊断，再明确如何汇总成外层记录。只记四轮平均值会隐藏第四轮的尾部。
- mean、M2、比例通过全局分子/分母或等价正确权重计算。全局 p99 通过全局样本、可合并分位数摘要或固定直方图估计；**不能平均各 rank 的 p99**。
- 原始 log-ratio 和数值保护后的 log-ratio 分开记录。`guard_fraction=0`只说明未触及保护，不说明 ratio 集中在 1 附近。
- M2PO 若作为后续候选，应同时记录 mask 前、mask 后以及各自分母，不能用一个命名含糊的“M2”覆盖所有集合。
- 本项目目前的事件比例经过既有 DP/mini-batch 平均路径后再相除，公共因子可抵消；这些中间量不能解释为全局事件计数。
- 优势正负、长度位置及高熵 token 的分桶诊断优先使用受控 probe 批；完整词表熵的代价应另计，避免把可观测性开销误认为算法开销。

### 9.1 VeXact: 2605.14220v2

### 9.2 Score Centering：2609.20807v1

**问题与干预。** 论文把期望更新分为 sampler 偏差引入的 drift 和 reward 相关的 covariance signal，研究固定方向权重扰动、量化与陈旧 sampler。SC 是加性 score 修正，不等于减去一个 batch 平均 advantage；SC 与 IS 也不是必然互斥。SC 单独度量的是 sampler 分布下的 covariance，不是把采样分布精确换成当前策略的 IS 恒等式。[^sc]

| --- | --- |

| 大模型 | Qwen3-30B-A3B-Base / INTELLECT-2 math；16 prompts × 8 completions；最大序列 1024 |
| 优化 | REINFORCE + group-centered rewards；每 batch 一次 SGD 更新，LR=$10^{-2}$；不能与 AdamW 的 $10^{-6}$ 直接比数值 |
| 观察窗口 | 0.6B 量化/stale 图展示到 1200 step；30B 量化图展示到 800 step；比我们的 32 步长得多 |
| stale 干预 | **每 64 个 step 才同步一次 sampler**，不是每条数据固定延迟 64，年龄随同步周期变化 |
| 其他干预 | 初始化时采样并保持的 Gaussian 权重偏移；只量化 sampler 的 W/A/KV；trainer BF16 |
| 复验 | 0.6B/1.7B各方法3 seeds；30B 的 seed 数按方法与量化条件不同，图例逐项列明 |
| 指标 | training accuracy、collapse 发生时间、完整训练曲线、top-k sampler 概率质量覆盖及多 seed 变化 |

**对本项目的解释。** “短跑里曲线重合”既可能是方法等效，也可能是小偏置尚未累积。可以设计稳定的同版本失配 probe，而不应一边改量化、一边改 LR 和 stale。当前 sampled-token OPD 中的 teacher 是真正固定的 teacher；SC 论文分析中的偏置 sampler 会跟随 trainer 变化，这两种“distillation”含义不同。直接把 SC 插入 OPD，需要重新推导目标与梯度，而不是照搬 RLVR 结论。

### 9.3 CIS：2609.32444v1

**问题与干预。** 相同量级的数值扰动映射到概率 ratio 后，会受到 token 置信度影响。论文以 $p=\pi_{\rm train}(a\mid s)$、$q=\pi_{\rm infer}(a\mid s)$ 定义 $k=p/q$ 和 log-odds 位移 $\varepsilon=\operatorname{logit}p-\operatorname{logit}q$，有：[^cis]

$$
k=p+(1-p)e^{\varepsilon},\qquad
f_\lambda(k,p)=\min\{k,1+\lambda(1-p)\}.
$$

注意 $\varepsilon$ 是 **log-odds 差**，不是 $\log k$。当 $p$ 接近 1 时，ratio 偏移会被 $1-p$ 压缩；只看 ratio 可能把同样的位移判成不同程度的异常。部署时还使用 floor $\varphi=\max(1-p,\kappa)$。CIS 权重作为 detached 系数乘在 loss 上；不能用对 ratio 直接 clamp 后反传来冒充同一修正，因为后者在饱和区可能给零导数。

| 维度 | 原文设置与诊断 |
| --- | --- |
| 静态诊断 | 2500 条 DAPO 题、每题 8 条、temperature1/top-p1、1024 cap；vLLM decode-time log-prob 对同权重 HF teacher-forcing；分别测 dense/MoE |

## 10. 相关工作补充：不同层级的 IS 不能混在一张排行榜里

本节按“实际改了什么、测了什么、对我们有何用”补充六篇。涉及多个变化或不同的 best/final 选点时，不将原文效果差异全部归因于一个 IS 公式。

### 10.1 AReaL：系统延迟和算法必须同时看

AReaL（2505.24298v5）分开 behavior policy 与 proximal policy，用受控版本延迟和 decoupled PPO 支持异步训练。论文默认 math 最大 staleness 参数 $\eta=8$、code 为 4，研究无界延迟、naive/decoupled PPO 及异步系统消融；主要看 **准确率随 PPO 更新/墙钟变化、throughput、staleness–throughput 权衡**，同 GPU 预算下最高报告 2.57 倍加速。其 $\eta$ 属于系统版本/调度控制量，不能直接抄成我们的 epochs。[^areal]

**实验启发：** 先记录每条轨迹或分段 token 的生成版本和实际 optimizer age。只有“某配置不掉分且更快”才支持系统优化价值；缓存容量更大但实际概率漂移没变，不构成算法鲁棒性测试。

### 10.2 GSPO：clip 越少不一定越好

GSPO（2507.18071v2）使用长度归一化的整序列 likelihood ratio。Qwen3-30B-A3B 冷启动实验每 rollout batch 分四个 mini-batch，GSPO clip=(3e-4,4e-4)，对照 GRPO=(0.2,0.27)；指标包括 training reward、AIME24 平均 pass@1、LiveCodeBench、CodeForces Elo 及 clip fraction。论文 Figure 2 报告 GSPO 被裁剪 token 比例比 GRPO 高约两个数量级，但训练效率仍更好。[^gspo]

**实验启发：** “我们只 clip 0.089% 所以一定稳定/有效”不成立。不同方法剪的是整条 response 或单个 token，梯度权重也不同。GSPO 的几何平均权重 $\exp(T^{-1}\sum_t\log\rho_t)$ 不等于完整轨迹 IS 权重 $\exp(\sum_t\log\rho_t)$，不能直接套用后者的无偏性解释。

### 10.3 VESPO：批内 stale、长度与软权重

VESPO（2602.10693v3）固定 mini-batch256，改变 $N=\mathrm{gbs}/\mathrm{mbs}\in\{4,8,16,32,64\}$，把一大批不同回答分成 N 次更新。这与重复同 64 条回答 N 遍不同。数学任务为 DAPO，模型包括 Llama3.2-3B、Qwen3-8B 及 30B-A3B；每 run1500 个 gradient steps、16K 上限、每题 8 条，另做代码任务。[^vespo]

关键图将 **reward、AIME25、长度、KL、entropy、PG loss** 按 N 排成矩阵，并比较 routing replay 与权重形状。30B-A3B 在 N=64 时四集平均：VESPO **61.8%**、GRPO **48.6%**、GSPO **47.6%**，按各方法平均成绩最佳 checkpoint 选点。不能只看“所有 N 的 train reward 都约 0.7”便断言泛化相同。[^vespo]

**实验启发：** 记录梯度更新预算之外，也记录新生成轨迹数、数据复用次数和长度。VESPO 软权重有界不等于网络 score 向量的范数有界；更不是 OPD 已验证的默认替代目标。

### 10.4 MinPRO：prefix 信息与丢弃位置

MinPRO（2601.22718v1）在 DAPO 上研究 Qwen3-8B/14B/30B-A3B；每全局 step16 次更新，额外 buffer 延迟 $n=2$，对应 **32–47 次更新年龄**，response cap20,480。保存每 10 个 global step，按七基准平均最佳点选择；看 **reward 崩溃、验证 pass@k、hard-clipped fraction** 等。[^minpro]

对本项目更有价值的是失败实验：直接使用完整 prefix ratio 未改善；按 prefix ratio 丢弃最小 1% 的 token 反而难以学习，作者归因于尾部位置偏置。若考虑过滤极端 token，应同时看位置和是否包含最终答案，不能只挑一个总体百分位阈值。[^minpro]

### 10.5 CTPO：按位置测累计 ratio 方差

CTPO（2605.07331v1）在 Qwen3-4B/14B 的工具推理任务上比较 token、sequence、cumulative-token ratio；DeepScaleR，最多 5 轮、8K 轨迹，batch512 prompts×8 回答，LR=$10^{-6}$。评估四竞赛集 avg@32，4B 平均分为 CTPO **51.4**、GSPO **47.7**、GRPO **43.2**。[^ctpo]

它在训练 step50/100/150 分别画 **累计 log-ratio 标准差随 token 位置增长**，并对比固定与位置自适应 clip：固定区间后段 clip 最高约 20%，自适应约 5–10%。这是累计比率的比例，不能与我们的单 token active clip 直接比。[^ctpo]

**边界：** $\log\rho_{1:t}=\sum_{j\le t}\log\rho_j$。独立假设下方差随 t 线性增长；真实 token 相关时还存在协方差项。其无偏命题依赖正确的 token 级优势函数，实际 group-relative outcome 优势、clipping 和工具环境并不自动继承完整无偏性。我们的固定 prefix 局部 OPD 与整条轨迹 RL 目标不同，不应不加分析地乘入 prefix 连乘。

### 10.6 FP16 研究：先做同权重离线测量

_Defeating the Training-Inference Mismatch via FP16_（2510.26788v1）包含与我们同名的 R1-Distill-Qwen-1.5B。离线实验测 **token 概率散点与不同长度下 sequence log-ratio 分布**；为对齐概率，专门用 temperature1、无 top-p 截断重新生成。Sanity 实验从 MATH 筛出 1460 道初始 40 次采样准确率 20–80% 的题，batch64×8 回答、每轮四次梯度更新、8K 上下文。[^fp16]

它比较 BF16/FP16、不同 IS 修正及 VeRL/Oat 两实现；BF16 vanilla GRPO 峰值 training accuracy 分别为 73%/84%，token TIS 为 82%/88% 后仍退化。评估推理精度本身的分数接近，不能把稳定性的收益等同于“推理精度越高答案就越准”。[^fp16]

**本项目边界：** 这支持先测同权重 TIM，不支持直接把本项目切成 FP16。现有准确更新计数的验收范围是 BF16/FP32、无 GradScaler；切换精度还需要处理 loss scaling、跳步与性能回归。

## 11. 我们最应该看的指标与优先级

### 11.1 第一层：效果为主判据，机制指标解释原因

如果只能保留一个效果指标，选 **固定评估协议下的 held-out 正确率曲线，横轴用确认 optimizer updates**，同时显示生成样本数或 token 成本；不要选 surrogate loss、p99 或 clip fraction。至少要有初始验证和多个检查点；三套数学集分别报告，不把单次小差异包装成方法胜出。

若问“下一项最应该补的训练诊断”，我优先选 **拆开 TIM 和学习漂移的 log-ratio，再配优势加权信号差异**。p99 是这组诊断的一部分，不是唯一健康分数。以下均是本项目建议，未声称已实现。

| 优先级 | 指标组 | 最小记录内容 | 直接回答的问题 |
| --- | --- | --- | --- |
| P0 | 验证质量与预算 | 三集 avg@n、初始点、固定 checkpoint；optimizer attempts/steps/skips；生成回答数/token数 | 学得更好还是只是更新更多、换了评估预算 |
| P0 | 实际年龄与同版本 TIM | $\Delta_u$；相同权重 log-prob 差的有符号 mean、absolute mean、绝对值的 p99/max | 是数据陈旧、引擎不一致，还是二者混合 |
| P0 | 每内部更新的漂移 | 总 log-ratio 的 mean、p01/p99、p99 绝对值、M2log、数值保护比例 | 第四轮是否已明显偏离行为策略；是否有被均值掩盖的尾部 |
| P1 | IS 权重集中 | ratio mean/std、ESS/N、top1%权重或surrogate系数质量占比 | 少量 token 是否支配更新系数 |
| P1 | 优势相关失真 | 正负组 $C=-(\rho-1)A$；current/frozen 系数差；NoIS 系数差；active clip 及其被移除质量 | 同样的 ratio 差异到底改了多少学习信号 |
| P1 | 行为变化 | 熵、长度、EOS/触顶率；按位置和置信度分桶 | 是否过度变尖、长链后段被过滤或大量回答未完成 |
| P2 | 专项诊断 | 小批固定 prefix 的 teacher/student KL、gradient cosine；OOD 检查；MoE 路由指标 | 解释剩余机制，确认没有遗忘或路由异常 |

M2log 应以原始 $z$ 计算，另记保护后数值；ratio 极端值可能溢出，应单独报非有限数，不能先静默截断再宣称尾部正常。不要从某篇 paper 搬一个 p99、ESS 或 clip 百分比作通用报警阈值；先建立本模型同步/同权重参照。

### 11.2 三份概率拆分总 ratio

记生成参数为 $\theta_g$，当前参数为 $\theta_u$。同一 prefix 和 token 上的三份 log-prob 为：

$$
\ell^{\rm infer}_g,\qquad \ell^{\rm train}_g,\qquad \ell^{\rm train}_u.
$$

则有精确分解：

$$
z_{\rm total}=\ell^{\rm train}_u-\ell^{\rm infer}_g
=\underbrace{(\ell^{\rm train}_g-\ell^{\rm infer}_g)}_{z_{\rm TIM}}
+\underbrace{(\ell^{\rm train}_u-\ell^{\rm train}_g)}_{z_{\rm update}}.
$$

这只是同一观测上的代数分解，不自动把两项的影响变成独立因果。它要求 $\ell^{\rm train}_g$ 确实来自生成时权重。当前 D=0 时，更新前 FSDP 重算可提供该参照；未来 D>0 时，需要生成版本的训练端评分缓存或独立 probe，不能把训练时重算的当前权重概率冒充 $\ell^{\rm train}_g$。仅有时间戳或当前 ratio 无法事后精确拆分。

### 11.3 为什么要把 ratio 与优势一起看

固定同一个 batch 和当前参数，忽略数值保护、普通 clip 及聚合缩放，取：

$$
A_{\rm cur}=\operatorname{sg}(\ell_T-\ell_u),\qquad
A_{\rm beh}=\operatorname{sg}(\ell_T-\ell_g^{\rm infer}),\qquad
z=\ell_u-\ell_g^{\rm infer}.
$$

有数值恒等式 $A_{\rm beh}-A_{\rm cur}=z$。把负梯度的 score 系数记为 $w$，则在同一批、同一当前策略的比较中：

$$
w_{E4}=\rho A_{\rm cur},\quad
w_{E2}=\rho A_{\rm beh},\quad
w_{E5}=A_{\rm cur},
$$

$$
w_{E2}-w_{E4}=\rho z,\qquad
w_{E4}-w_{E5}=(\rho-1)A_{\rm cur}.
$$

这些恒等式给出直接对应 E2/E4、E4/E5 问题的诊断，而不仅是 count 有多少符号翻转。建议在固定 probe 上报告：

$$
D_{\rm adv}=\frac{\sum_i|\rho_i z_i|}{\sum_i|\rho_i A_{{\rm cur},i}|+\varepsilon_0},\qquad
D_{\rm IS}=\frac{\sum_i|(\rho_i-1)A_{{\rm cur},i}|}{\sum_i|\rho_i A_{{\rm cur},i}|+\varepsilon_0}.
$$

$\varepsilon_0$只是防零项，必须同时报告分子/分母；teacher 差异趋近零时归一化比值可能放大，不能把一个很大的比例独立解释为危险。不同 run 的轨迹已经不同，以上等式应在**同一 probe、同一当前参数**下比较，而非直接对两条训练曲线作差。

对 E3，还应同时给 active clip count 和被去掉的系数质量：

$$
M_{\rm clip}=\frac{\sum_i\mathbf1[\mathrm{active\ clip}_i]|\rho_i A_{{\rm cur},i}|}{\sum_i|\rho_i A_{{\rm cur},i}|+\varepsilon_0}.
$$

这些都是 **surrogate/score系数诊断，不是真实梯度差的范数**，因为还没有乘每个 token 的 $\nabla_\theta\log\pi$，也未计入向量抵消、梯度裁剪和 AdamW 预条件。需要验证时，可在少量固定 probe 上真正计算 batch gradient cosine 与范数比；不必一开始保存全量逐 token 参数梯度。

### 11.4 一套能解释结果的最小实验

1. **同权重静态 probe**：固定一小批完整轨迹，保持 temperature/top-p、mask、next-token 对齐和权重相同；比较 decode-time 概率与 FSDP 重算，保存 $z_{\rm TIM}$ 的分布及按位置分桶结果。先排除 packing/温度/对齐错误。
2. **批内四轮 probe**：在每个内部更新分别记录 $z_{\rm total}$、$z_{\rm update}$、M2log、ESS、active clip 和上述系数差。用同一 forward 离线计算几种系数，不代表同时改变训练目标。
3. **可控延迟**：固定 LR 和复用次数，扫描 D=0/4/16，记录实际 $\Delta_u$。若同时换 LR、精度、采样方式，无法再把差异归为 stale。
4. **预算与泛化验证**：相同更新预算、相同新轨迹预算分别比较；固定初始/中间/末次评估。至少保留一个小 OOD 检查，避免只看到数学分数或 loss。
5. **仅在诊断需要时扩展**：若置信度依赖明显，再研究 CIS 类分桶；若 prefix 长度效应明显，再研究累计 log-ratio；当前 dense 模型不优先付出 MoE 路由日志成本。

我们现在最缺的不是再增加一个总体 loss，而是把 **实际年龄、概率漂移、优势加权偏差、held-out 效果** 接起来。只延长外层 step 可以观察小偏置积累和泛化变化，但不能替代受控的 stale 扫描。
