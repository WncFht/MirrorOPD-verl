## 当前定义与历史记录

旧 run 的对照、专属复现命令和第一版指标资料集中从[历史记录](archive/README.md)进入。日常分析从五组实验比较、E15 单 run 报告与当前指标字典开始；原始快照不随导航整理搬迁或覆盖。

指标字段以[当前字典](metrics/2026-10-22-指标字典.md)为准，测试范围以[完整指标实现与验收](metrics/2026-10-22-完整指标实现与验收.md)为准。第一版字典、迁移审计和设计报告保留当时口径，不作为当前接口说明。

当前接口和调用链由[代码走读文档库](internals/README.md)维护；Full-KL 算子与数据流从[当前 Full-vocab 走读](internals/full-vocab.md)进入。日期命名的旧走读、实现计划、验收和算子小实验保留当时的说明与证据。性能实测中的配置是冻结实验条件，当前启动默认值见训练配方。

## 文档维护

修改源码接口或行为时，在同一提交更新所属走读，并运行 `make docs-check`。检查范围和引用格式见[走读维护约定](internals/README.md#维护约定)。

每个主题选择一个详细定义入口。README 保留结论摘要和导航；其他文档通过章节链接复用证明、字段字典和配置合同。历史数据与来源快照保留原样，迁移后的旧路径保留跳转入口。


默认值和 E 系列预算集中在训练配方；部署命令集中在运行与架构；参数机制与冻结测量分别在调优、实测文档维护。算法比较矩阵集中在实验排序文档，具体执行预算和状态由相应队列维护。已迁出的理论章节通过旧文末尾索引保留锚点。

E15 的全程配置、训练动态和验证成本只在主报告维护；分阶段 GPU、功耗及窗口敏感性由其链接的资源报告维护。数据 README 只描述快照来源与文件，复现命令集中在分析复现。其他页面引用这些入口，不复制数值表或另一套指标定义。
