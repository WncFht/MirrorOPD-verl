## 文档维护

每个主题选择一个详细定义入口。README 保留结论摘要和导航；其他文档通过章节链接复用证明、字段字典和配置合同。历史数据与来源快照保留原样，迁移后的旧路径保留跳转入口。


默认值和 E 系列预算集中在训练配方；部署命令集中在运行与架构；参数机制与冻结测量分别在调优、实测文档维护。算法比较矩阵集中在实验排序文档，具体执行预算和状态由相应队列维护。已迁出的理论章节通过旧文末尾索引保留锚点。
