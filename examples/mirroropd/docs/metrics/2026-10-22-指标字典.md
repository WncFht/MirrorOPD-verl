# 当前训练指标字典

Last updated: 2026-10-22。

> 范围说明：本页记录第一版当前实现或其历史辅助口径，不表示指标覆盖完整。新增需求、被裁掉的观测及拟议迁移见[指标迁移审计与补齐清单](2026-10-22-指标迁移审计与补齐清单.md)；本次文档审计没有实现这些待办。

本页描述已接入的 V1 训练输出，替代旧 actor/critic/rollout_corr/val-core/val-aux 对外字段。当前主要验收范围是 FSDP2、SP=1、同步 sampled-token OPD；CPU 验证与 GPU 未验收边界见[实现与验证](2026-10-22-实现与验证.md)。不同 backend 或算法的可用字段取决于其真实输入，缺测不填零。

## 使用与时间轴

唯一新增用户配置是 `trainer.metrics_quantile_interval`，默认 8；0 关闭 p99，1 每次更新记录。已接入的采集根据算法与已有输入启用；尚未接入或被出口裁剪的条件指标见审计清单。记录 ratio 不会开启 IS correction，记录 entropy 不会开启 entropy bonus。

更新类指标默认以 `step/update` 为轴，入口/rollout/perf 以 `step/outer` 为轴，eval 以 `step/optimizer` 为轴。每行附带已知的三个计数。W&B 的 `_step` 只是写入序号；全局历史不再是一 outer 一行。切换图表横轴时使用同一行的业务坐标。

Loss、ratio、优势和 grad norm 来自更新前的 forward/梯度，成功计数属于 optimizer 调用结束后。未知绝对更新计数不补造；默认轴在首次见到指标时固定。分析缺失点时同时检查 nonfinite 比例、p99 调度和算法能力。

## 统计约定

所有新 Observation 在 micro-batch/DP 合并之后才完成均值、RMS、ESS、极值或分位数。当前观察默认在有效 response token 上等权；带权 correction 系数另纳入实际 loss 的 sequence 权重。入口与更新使用不同 token 集合时，不能把聚合结果直接相加。

概率角色与公式见[设计的 IS pair 章节](2026-10-22-训练指标系统设计与调研.md#6-is-pair-与固定统计集合)。下列 64 个名字是数学 E 系列的可能输出并集，不是每行都出现的字段数；验证、p99、PPO clip 和 guard 均有明确触发条件。

## 优化与损失

| 字段 | 含义 | 记录粒度 | 单位 |
| --- | --- | --- | --- |
| `optim/actor/grad_norm_preclip` | 实际 engine 梯度裁剪前的全局范数。非有限时省略数值，跳过更新由累计计数反映。 | update | L2 norm |
| `optim/actor/loss` | 本次 optimizer 尝试使用的总 loss；micro-batch contribution 求和后按 DP 规则归约。不同 surrogate 的数值不用于跨方法质量排名。 | update | 原目标单位 |
| `optim/actor/lr` | 本次更新调用前读取 optimizer 第一个参数组的 LR；不是 scheduler 在本批末推进后的下一次 LR。 | update | 学习率 |

## 更新修正的影响

| 字段 | 含义 | 记录粒度 | 单位 |
| --- | --- | --- | --- |
| `correction/behavior_ppo/active_fraction` | E1/E3 中真正进入 PPO clipped surrogate 分支的有效 token 比例；不是 ratio 越界比例。 | update | 比例 |
| `correction/behavior_ppo/active_mass` | 上述 token 占未做 PPO clip 的绝对 score 系数之和的比例，已纳入 loss 的序列权重及实际 guard。分母为零时缺测。 | update | 比例 |
| `correction/is/coeff_change` | 同一 forward 上 current advantage 的 IS 与 NoIS 系数绝对差之和，除以 IS 绝对系数之和；E1–E6 均可记录此反事实比较。 | update | 相对量 |
| `correction/log_ratio_guard/fraction` | 实际使用 IS 的 E1–E4 中，float32 log-ratio 超出 [-20,20] 的有效 token 比例；E5/E6 不产生该 guard。 | update | 比例 |

## 隐藏进度坐标

| 字段 | 含义 | 记录粒度 | 单位 |
| --- | --- | --- | --- |
| `step/optimizer` | 累计实际成功执行的 optimizer 更新；记录为本次操作结束后的值。 | 各记录 | 次数 |
| `step/outer` | 当前外层轮次，控制已有验证、保存和参数同步调度。 | 各记录 | 次数 |
| `step/update` | 累计 optimizer 更新尝试；micro-batch 和 GPU 数不增加此计数。 | 各记录 | 次数 |

## 模式差异与缺测

- E1/E3 记录 behavior PPO 激活比例和系数占比；E2/E4 不执行 PPO clip，所以这些字段缺席。
- E5/E6 的 NoIS 不执行 log-ratio guard，但仍记录原始 pair 和 IS/NoIS 的反事实系数差。
- Vanilla 记录 `correction/anchor_ppo/active_fraction`，与其现有 pre-dual-clip pg_clipfrac 一致；不把它等同于 E1/E3 的 behavior clip，也不输出尚未适配的 active_mass/D_A/D_IS。
- 普通 policy-gradient 路径可产生 `advantage/task/{mean,abs_mean,rms,positive_fraction}`；纯 OPD 会移除未被 loss 使用的 task observation。
- 缺少 acc 的一般 reward 任务使用 `eval/<dataset>/score_mean`，不将连续 reward 命名为准确率。当前数学 verifier 提供 acc。
- 若启用已有样例表，输出 `eval/samples`；DAPO 表使用 `rollout/filtered_reward_counts`。表格不计入上述数值字段数。
- Undefined、全空和输出溢出的普通标量不写入 W&B；文件也使用同一对外字典。没有虚构的零值或上一次值回填。

## 旧字段与性能解释

逐键处置见[历史字段映射](data/metrics-system-20261021/metric-migration-20261022.csv)。这是迁移证据，运行时不会双写旧键。旧 correction helper 的返回值仍作为其他入口的内部 API 存在，说明集中在[旧 correction 字段](2026-10-22-旧Correction辅助字段.md)。

系统 timer、显存和历史验收条件归档于[历史性能口径](2026-10-22-历史性能口径与验收.md)。FSDP allocated peak、reserved peak、整卡显存与 GPU busy 是不同对象；历史测量不能充当这次新指标实现的 GPU 验收。
