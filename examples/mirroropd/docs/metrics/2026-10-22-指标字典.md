# 当前训练指标字典：policy-v3

Last updated: 2026-10-22。

当前代码使用 policy-v3。已移除固定字段允许列表；八类语义、累计横轴与 Metric/Observation 归约保留。旧字段只在生产端适配时转换一次，不向 W&B 双写别名。第一版 64 字段定义保留在[历史字典](2026-10-22-第一版指标字典.md)。原始字段至当前名字见[迁移表](data/metrics-v3-20261022/old-to-current.csv)，实现与实测见[验收记录](2026-10-22-完整指标实现与验收.md)。

本文按模板说明动态字段；`{dataset}` 是数据源 slug，`{role}` 为 actor/critic，`{pair}` 是明确的概率对，`{score}` 是真实评分分量。不是每种算法都产生每个字段，也不再设全局字段数量上限。

## 1. 时刻、坐标与无效值

| 字段或类别 | 默认横轴 | 定义 |
| --- | --- | --- |
| `step/outer` | 坐标 | 外层调度次数 |
| `step/update` | 坐标 | actor optimizer 尝试累计数 |
| `step/optimizer` | 坐标 | actor optimizer 成功执行累计数 |
| `step/critic_update`、`step/critic_optimizer` | 条件坐标 | 仅启用 critic 时使用其独立尝试/成功计数，不冒用 actor 更新数 |
| optim/advantage/distill、更新 pair、实际 correction | `step/update` | 本次更新前向和梯度对应的观察；行内成功计数为调用后的状态 |
| critic 更新字段 | `step/critic_update` | critic 实际更新；不等于 actor 同步迭代数 |
| 入口 pair、batch correction、批量 task 摘要、rollout/perf | `step/outer` | 整批或入口测量，不能当作逐更新变化 |
| eval 标量 | `step/optimizer` | 被评估时的 actor 成功更新数 |
| eval 样例表 | `step/outer` | 每个 checkpoint 一行，每个样例占 input/output/score 三列 |

旧 checkpoint 缺少计数时仍标为未知，不用 outer×epochs 推断。Critic 的条件计数追加在已有 trainer_state.json 中；旧文件没有这些字段时不补造历史。

空 Observation 分母在输出边界转为 `<metric>/undefined=1`；非有限数值转为 `<metric>/nonfinite=1`，原值不伪装成零。事件键只在发生时写出。Loss/grad 另外有每次更新均记录的有限性标志。Raw pair 的输入非有限比例和有效 token 数用于区分输入异常与指数等统计运算溢出。

`trainer.metrics_quantile_interval` 仍默认 8：首次及每 N 次更新尝试收集训练分位数，0 关闭；入口 pair 按 outer 的首次及每 N 次采集。长度等小规模 outer 统计不受它控制。`trainer.eval_metrics_resamples=256` 是新增的唯一配置，用于跨题置信区间和大 N 投票子集估计；seed 复用 data.seed，None 使用 42，全部使用局部 RNG。

## 2. 优化与损失 optim

| 后缀或模式 | 定义与边界 |
| --- | --- |
| `optim/{role}/loss` | 本次更新的总目标；按实际 global batch/token 归一化的 micro contribution 求和和 DP 归约 |
| `grad_norm_preclip` | optimizer 实际裁剪前的全局梯度范数；不是按层统计 |
| `lr` | 本次 optimizer 操作实际使用的 LR；`lr_next` 保留 scheduler 输出，不作为当前 LR 的别名 |
| `execution_known` | 是否取得实际 optimizer 执行事实；未知不当作跳过 |
| `update_applied`、`update_skipped` | 本次实际执行/跳过事件，仅已知时记录 |
| `skipped_updates` | 已知尝试计数减成功计数的累计差 |
| `loss_nonfinite`、`grad_norm_preclip_nonfinite` | 每次有对应数值时记录 0/1；与稀疏 `/nonfinite` 事件区分 |
| `optim/actor/observations_available` | 当前 engine 是否接入完整 response 的新增 raw 观察；0 时保留已有 backend 诊断并提示，不宣称 CP/TP 分片已验证 |
| `pg_loss`、`distillation_loss`、`entropy_loss`、`kl_loss` | 实际参与目标的分项；entropy_loss 为未加权 entropy，KL 类型由 config 指定 |
| `entropy_loss_weighted`、`kl_loss_weighted`、`distillation_loss_weighted` | 应用真实符号和系数后的目标贡献；混合目标时可用于分解总 loss；蒸馏 weighted 项仅混合 task reward 时产生 |
| `kl_coef` | 实际 KL loss 系数；reward shaping 的 KL 系数另见 rollout/reward_kl |
| `optim/critic/value_loss` | critic value objective；`correction/value/active_fraction` 为 value clip 诊断 |
| `optim/actor/outer_*_mean` | 仅旧 worker 不返回逐更新记录时的 fallback 摘要，名字明确其 outer 粒度，不冒称逐更新观测 |

纯 OPD 不再发布未用于优化的 task PG loss。选择记录 entropy 不等于开启 entropy bonus；只有已有 forward 返回 entropy 时才记录 `policy/entropy/update`，不为日志另做完整词表 forward。

## 3. 概率 pair 与分布统计 policy

| Pair             | 分子/分母                 | 时刻       |
| ---------------- | ------------------------- | ---------- |
| current_behavior | 当前学生/生成策略         | 每次更新   |
| anchor_behavior  | 本批入口冻结学生/生成策略 | 本批更新前 |
| current_anchor   | 当前学生/本批入口冻结学生 | 每次更新   |

bypass 没有独立 anchor 时不伪造 current_anchor。采样来自 behavior；不能把 current_anchor 的任意统计直接称为该 pair 分母分布下的精确 KL。

令 $z=\log p-\log q$。以下公共后缀均放在 `policy/{pair}/`：

| 后缀 | 含义 |
| --- | --- |
| `log_ratio_mean`、`log_ratio_std` | 有符号均值与总体标准差；按有效 response token 等权 |
| `log_ratio_m2` | token 的 $E[z^2]$；不是方差，也不是 sequence 累积量 |
| `log_ratio_abs_mean`、`log_ratio_abs_max` | 绝对差均值、绝对极值 |
| `nonfinite_fraction`、`valid_token_count` | 原始输入概率非有限比例、有限有效 token 数 |
| `log_ratio_p01/p50/p99` | 按采集频率记录的全局 nearest-rank 分位数 |
| `sequence_log_ratio_{mean,std,min,max,m2,abs_max,p01,p50,p99}` | 每条完整 response 先对 z 求和，再对非空 sequence 等权统计 |
| `sequence_mean_log_ratio_{mean,std,min,max,m2,abs_max,p01,p50,p99}` | 先按每条 response 的有效长度取均值，再跨 sequence 等权统计 |

Token M2 与 sequence M2 分别为：

$$
M_{2,\mathrm{token}}=\frac{\sum_i\sum_t z_{it}^2}{\sum_i L_i},\qquad
M_{2,\mathrm{sequence}}=\frac1B\sum_i\left(\sum_t z_{it}\right)^2.
$$

B 为非空回答数，$L_i$ 为有效 token 数。此前讨论的 total_log_ratio_m2 对应这里的 `sequence_log_ratio_m2`，现已实现；SP/CP 未还原成完整 response 的路径不能直接用此定义。

current_behavior 和 anchor_behavior 另有：

| 后缀 | 含义 |
| --- | --- |
| `ratio_mean`、`ratio_std` | 原始 ratio 的均值和总体标准差；用 log-space 一、二阶状态归约，不截断来隐藏尾部 |
| `ess_fraction` | $(\sum w)^2/(N\sum w^2)$；原始 token ratio 的 ESS/N |
| `ratio_lt_half_fraction`、`ratio_gt_2_fraction` | 原始 ratio 小于 0.5、大于 2 的有效 token 比例；不是 loss 的实际 clip 比例 |
| `ratio_p99` | 原始 ratio 的全局 nearest-rank p99，按训练分位数频率记录 |
| anchor_behavior 的 `k3` | mean(exp(z)−1−z)，满足采样/支持条件时才可解释为 KL 估计 |

`policy/entropy/pre_update` 保留入口 entropy。`policy/anchor_behavior/prob_diff_*` 与 `prob_pearson` 恢复原概率空间诊断；不能与 log-ratio 差直接对比数值。已有 PPL、log-PPL、sampled reverse log-ratio、带 guard 的 χ² 等 helper 观测也保留，并沿用原定义；详见[辅助字段历史口径](2026-10-22-旧Correction辅助字段.md)。

## 4. 实际优势 advantage

`advantage/{task,distillation}/` 逐更新统计真正进入相应 loss 的信号：`mean`、`abs_mean`、`rms`、`std`、`min`、`max`、`positive_fraction`、`zero_fraction`、`nonfinite_fraction`、`token_count`；选定更新增加 `abs_p99`。

`advantage/task/batch_*` 是原 task reward 通路的 batch 摘要，使用 outer 轴；`batch_used_in_loss` 明确其是否参与优化。纯 OPD 的这些辅助量不替代 distillation advantage。

已有 `actor.calculate_sum_pi_squared` 默认为 False。显式启用、task reward 确实参与且重算 anchor 时，V1 取回该已有 forward 的输出，接入 `advantage/variance_proxy/{proxy2_total_power,expected_a_squared,expected_w}`。它是 logit-score 近似量，不是真实参数梯度方差。没有同口径参数梯度时不再用零填 proxy1/proxy3；不为纯 OPD 的未用 task advantage 发布代理方差。`available` 仅在请求此功能时说明是否适用。

## 5. 更新修正 correction

| 字段家族 | 含义 |
| --- | --- |
| `behavior_ppo/active_fraction`、`active_mass` | E 系列使用 behavior 分母的实际 PPO 分支事件及绝对 score 系数质量比例 |
| `anchor_ppo/*` | vanilla 蒸馏使用独立 anchor 的分支；增加 `dual_clip_fraction`、`dual_clip_mass` |
| `task_ppo/*` | 普通 task PPO 的 clip/dual-clip 事件与质量比例，结合 config 判断分母；bypass 使用 behavior |
| `distillation_behavior_ppo/*` | vanilla 蒸馏在 bypass 下的真实 behavior 分母分支，不伪称独立 anchor |
| `log_ratio_guard/fraction` | E 系列用于指数与梯度数值保护的 guard 事件，不与 PPO clip 混用 |
| `is/coeff_change` | E 系列 IS 与 NoIS 的反事实 score 系数差；不是实际 TIS 权重的 ESS 或完整梯度距离 |
| `is/applied_{mean,std,min,max,p01,p50,p99}` | 实际施加的附加 IS 权重；被 RS 去掉的原有效 token 以有效权重零计入原分母，分位数按频率 |
| `is/applied_ess_fraction`、`applied_ess` | 实际权重的全局 ESS/N 与绝对 ESS；全零权重时未定义，不补零 |
| `is/applied_zero_fraction`、`applied_nonfinite_fraction` | 原有效 token 中有效权重为零/非有限的比例 |
| `is/applied_token_count`、`applied_nonzero_count` | 实际权重观察分母与非零权重 token 数 |
| `is/applied_sequence_weight_*`、`applied_sequence_ess_fraction` | 每条序列内有效权重平均值的跨序列统计和 ESS/N；不是序列概率乘积 |
| `rejection/token_fraction` | 原有效 token 中被 rejection mask 去掉的比例 |
| `rejection/sequence_any_fraction`、`sequence_all_fraction` | 至少部分被拒、整条被拒的非空原始回答比例 |
| `rejection/kept_token_count`、`kept_sequence_count` | 筛选后真正用于训练的量 |
| `is/batch/*`、`rejection/batch/*` | Driver 整批 helper 的已有统计，使用 outer 轴，保留实际阈值与选项信息 |
| `is/local_summary/*`、`rejection/local_summary/*` | bypass 内已有局部 helper 摘要的加权汇总；非线性的局部 ESS/std 均值不能冒称全局原始矩。分析实际全局权重时使用上面的 applied\_\* 状态统计 |
| `score_centering/*` | 已有 correction、head/tail mass、支持集对齐/未知比例 |

bypass 的 PPO-clip 不施加第二层 IS 权重，所以不为它发布一套虚构的 applied IS。其 raw pair 和实际 clip 仍记录；REINFORCE 分支则记录真正使用的 IS。局部 helper 的旧概率诊断放在 `policy/current_behavior/local_summary/*`，与新的全局 raw 观察分开。

## 6. 蒸馏 distill

- `advantage/sign_flip_fraction`：current 与 frozen/rollout 优势符号相反的比例。
- `advantage/source_coeff_change`：切换优势来源的 score 系数差。与 IS/NoIS 比较均考虑实际 loss 的 sequence 权重；不是完整参数梯度差。
- `student_teacher/sampled_log_gap_{mean,std,min,max,p01,p50,p99}`：当前学生−教师的 sampled-token log-prob 差；不等于 full-vocab KL。
- `loss/abs_mean`、`min`、`max`：已有 sampled loss 的幅度/范围，注意目标变换及 clamp 时刻。
- `topk/student_mass{,_min,_max}`、`teacher_mass{,_min,_max}`：已有 top-k 支持集覆盖的概率质量。
- `topk/overlap_ratio`、`overlap_token_advantage`：已有支持集交集比例及有交集位置的平均贡献；无交集的均值是 undefined，不伪造零。

### 6.1 Full-KL 相对位置十分桶（2026-10-24）

`distill/full_kl` 为全体有效 token 的条件 reverse KL 均值。新增 `distill/full_kl_position/p00_10/{sum,token_count,mean}` 至 `p90_100`，每10%一桶，主轴 `step/update`。位置以每条实际 response 内的 token 中点 `(r+0.5)/L` 计算，保留 masked gap，prompt 不参与；空桶均值为 undefined，出口留缺失值。

跨 microbatch/GPU 先合并 sum/count 再算 mean。前30%的均值使用前三桶 sum 之和除以 token_count 之和，不能直接平均三个 mean。此统计复用已有每 token KL，不改变 loss 和梯度；支持本仓全部 Full-KL 后端中的非 Liger 路径，Liger 和 sampled PG 不伪造该完整 KL 字段。数值精度、验证及复现见[KL精度与位置分桶](../research/2026-10-24-评测预算语义与KL精度及位置分桶.md)。

## 7. 采样与 stale：rollout

| 字段家族 | 定义 |
| --- | --- |
| `score/{mean,min,max}`、`reward/*`、`returns/*` | 原始评分、shaped reward 和 return 分开；不以“当前纯 OPD”为由删除通用 RL 的量 |
| `response_count`、`response_tokens`、`total_tokens` | 本批回答数、response token、prompt+response 总工作量 |
| `training_tokens` | 每次更新实际 loss mask 的 token 数，复用的 token 每次训练都计入；不等于新生成工作量 |
| `prompt_length/*`、`response_length/*`、`response_length_nonempty_loss_mask/*` | 恢复原均值/极值等，主 prompt/response 增加 p50/p95/p99；均值、极值和分位数使用同一对象前缀 |
| `*/padded_width_fraction` | 旧 clip_ratio 的真实定义：等于本批 padded width 的比例；不是 backend finish reason |
| `finish_reason/{stop,length,aborted,completed,unknown}_count` | 完整 single-turn 提交的实际返回原因；vLLM 原始 finish_reason 已单独保留，不能用长度猜测；其他 backend 未提供时记未知 |
| `empty_loss_mask_fraction`、`preemptions` | 原 aborted_ratio 实际测量 loss mask 全空的回答比例，包含整条被 RS 拒绝的情况；与真实最终 abort 原因分开。抢占数仅在后端完整报告时输出 |
| `num_turns/*`、`tool_calls/*` | 合并旧轮数别名；内置 tool loop 记录已调度工具调用数，single-turn 为 0；known_fraction 标明工具计数覆盖率，未知不伪造零 |
| `data_reuse/update_index`、`epoch_index` | 当前 worker batch 内的更新位置/PPO epoch 位置；是单条累计轴上的系列，不创建每个 inner 独立曲线，也不冒称每条轨迹的 optimizer age |
| `staleness/trajectory_spans/*` | 一条轨迹经历的权重版本跨度 |
| `staleness/trajectory_staleness/*`、`trajectory_staleness_worst/*` | 最新/最旧生成版本相对当前发布版本的差，单位为权重版本，不是 optimizer 次数 |
| `staleness/evicted_samples*` | stale 淘汰量及其年龄摘要 |
| `filter/*`、`failures/*` | DAPO 无信号组、剩余丢弃、失败补样等原有观测 |
| `data_epoch` | 数据集遍历进度；与 PPO epoch 分开 |
| `reward_kl/coefficient` | reward shaping 使用的 KL 系数；入口 sampled KL 在 policy/anchor_reference/reward_kl |

## 8. Eval：所有支持的采样预算

每个数据源独立选择评分能力。`reward_model.metric_fields` 可为整组失败的自定义任务声明评分名集合，并可用 pred 声明投票能力；标准数学数据源声明 acc。未知且完全失败的源只输出计数与 `quality_defined=0`，不编造准确率或 reward。错答 acc=0 不计为系统失败。

| `eval/{dataset}/` 后缀 | 定义 |
| --- | --- |
| `prompt_count` | 主指标参与的题数，按题等权 |
| `response_count` | 预期回答预算，包含失败补零项 |
| `observed_response_count` | 有有效主评分的回答数 |
| `materialized_response_count` | 实际物化的最终 session 数 |
| `failed_count` | 预期预算减有效主评分数 |
| `nonfinite_score_count` | 已物化主评分为 NaN/Inf 的数量 |
| `samples_per_prompt_min/max` | 逐题预算范围；曲线只使用所有题共同支持的 1…min(N)，避免高 k 静默换题集 |
| `quality_defined` | 是否知道主评分语义，不代表分数高低 |
| `{score}/mean` | 每题先按预期预算平均，再对题平均 |
| `{score}/observed_mean` | 每题仅用有效评分平均，再对有观测的题平均；诊断口径，不替换主指标 |
| `{score}_observed/*` | 有评分缺失时另外输出仅有效评分的预算曲线及独立 prompt/response 数；无缺失时与主曲线相同，不重复输出 |
| `{score}/missing_count` | 该评分分量缺失/非有限数量 |
| `{score}/within_prompt_std` | 对补零后的题内回答计算总体 std，再对题平均，不是总体均值的 CI |
| `{score}/prefix_mean@k` | 按固定 sample index 取前 k 个回答的均值；用于看估计波动，不是“随机子集均值的期望” |
| `acc/pass@k` | 标准 $1-\binom{N-c}{k}/\binom Nk$，然后按题等权；所有共同支持的 k 都输出 |
| `acc/all_correct@k` | 无放回子集全部回答正确的概率，$\binom ck/\binom Nk$，保留二值 worst 的一致性信息 |
| `acc/majority@k` | 规范化答案投票的预期正确性；缺失答案弃权、预算仍计入；平票均匀平均候选答案评分，不依返回顺序选胜者 |
| `acc/voting_defined` | 是否具备规范化答案投票语义；标准数学或明确声明 pred 的任务即使全弃权也输出零投票结果 |
| `acc/prediction_missing_count` | 没有可用规范化答案的预算槽位数 |
| `acc/prediction_score_conflict_fraction` | 同一答案有不一致评分的题目比例；投票使用该答案的观测平均评分 |
| `{score}/best@k`、`worst@k` | 非 acc 评分的无放回 order-statistic 精确均值；二值 acc 的 best 不重复命名，使用 pass |
| `<metric>_ci_low/high` | 95% 跨题 bootstrap 区间；不代表跨训练 seed 方差，只有一题时可退化 |
| `<metric>_subset_std` | 子集结果的题内波动，再跨题平均；与跨题 CI 分开 |
| `acc/majority@k_mc_se` | 大 N 子集 Monte Carlo 的数值误差；小 N 或端点精确计算时为 0 |
| `generation/{response_length,num_turns,tool_calls}/{observed_count,mean,min,max,p50,p95}` | 有观测的最终回答生成统计，不强行作为 reward 展开预算曲线 |
| `generation/finish_reason/*_count` | 每数据集的实际结束原因计数；缺失仍为 unknown |

`{score}` 包含真实 numeric grader 分量，例如 acc、reward、score、format（来自 format_score），不因为 acc 存在就删除其他评分。acc 必须二值才能使用标准 pass 估计器。预测答案即使为数值，也不被当作评分分量。

投票直接使用 grader 提供的 pred 键；框架规范化容器序列化，不自行追加代数等价归并。N≤8 的 majority 枚举子集；较大 N 使用局部固定 seed 的无放回子集估计，k=1/N 精确计算。所有评分的 best/worst 使用组合权重直接计算，不用旧有放回 bootstrap。N=16、c=1 时，新 pass@16=1，而旧 best@16 的期望约 0.644；不能将新旧曲线视为同一统计。

原始多轮生成 trace 仍保留。新增 `validation/records/<outer>.jsonl` 每个预算槽位一条最终 session 记录，含 data_source、稳定 prompt_id、sample_index、评分、pred、长度、工具数、状态，以及缺失生成的显式占位。prompt_id 使用固定验证顺序的 source 内序号；数据源/排序改变时应视为不同评估协议，不承诺跨数据重排仍同 ID。

## 9. 系统效率 perf 与记录后端

所有实际 timer 通过 `perf/timing/{stage}_seconds` 输出，不再只允许固定阶段。已有 `gen/step/testing` 分别映射为 rollout_pipeline/outer_step/validation；验证 rollout 跨度保留 `validation_rollout_seconds`。计时重叠不能相加。

保留 actor/critic MFU、吞吐、allocated/reserved peak、CPU 使用量、负载均衡、teacher RPC、异步切换、spec decoding 和 MoE 路由等已有观测。内存峰值用显式 MAX 归约，避免改名后丢失旧 reducer 的 max 语义；CPU 使用量仍是主机使用量，不是单个进程 RSS。

W&B/file 等后端保留完整标量。Console 单独选取外层概览，并显示最近一次更新的 loss/LR/grad；这不会把摘要额外写回 W&B，也不会削减持久化数据。未知自定义标量保留并告警，不再被白名单静默删除。

固定 prefix probe、full-vocab teacher KL、按层梯度、参数更新距离仍暂缓。未验证的 engine 新 raw 观察不会假装可用；原 backend 指标仍按新规则输出。
