## 2. 统一符号与比较轴

固定外层 $k$、内层 $n$，简写 $p=p_{k,n}=p_\theta$、$q=q_k$。$q$ 仅指冻结锚点，不再用于教师；$m_k$ 保留给 MirrorOPD 的目标教师。沿用固定前缀文档：$p_\theta$ 是当前 student，$T$ 是冻结 teacher，$\beta$ 是生成轨迹时的行为分布。给定前缀 $s$，定义成本、reward 与 score：

$$
\ell_i=\log\frac{p_\theta(i\mid s)}{T(i\mid s)},\qquad
r^{\rm cur}_i=-\ell_i,\qquad
\psi_i=\nabla_\theta\log p_\theta(i\mid s).
$$

本文的默认目标是条件 reverse KL；局部标量 $K(s)=K(p,T;s)$ 对应核心稿 $J_{0,\eta}(p;T)$。$g(s)$ 是参数梯度（即 $g_{k,n}$），不是核心稿概率空间中的 $g_k=-\mathcal A_k$：

$$
K(s)=\sum_i p_i \ell_i,\qquad
g(s)=\nabla_\theta K(s)=\sum_i p_i \ell_i \psi_i.
$$

最后一个等式利用 $\sum_i p_i \psi_i=0$；完整推导与 stop-gradient 写法见共用数学文档。以下“无偏”“零方差”均指固定 $s,\theta$ 时对 next-token 抽样而言，不包含前缀分布的导数，不表示整段训练没有数据噪声。Teacher/student 必须共享 token-ID 语义；相同词表大小本身不足以保证对应关系。

| 比较轴 | 选项 | 是否改变目标 |
| --- | --- | --- |
| 散度方向 | reverse KL、forward KL、JSD 或混合 | 通常改变 |
| 动作维度的积分方式 | 一个 sampled token、多个局部候选、精确求和 | 合法估计器可保持同一目标 |
| 稀疏支持集 | teacher top-k、student top-k、独立于本次动作的其他集合 | 用于截断 loss 时通常改变；用于完整无偏估计时未必改变 |
| 头尾处理 | 丢尾、支持内归一化、尾桶、随机尾部修正 | 决定目标偏差与方差 |
| 控制变量 | 标量 KL baseline、向量尾桶控制、条件尾部 score 控制 | 正确构造时保持期望梯度 |
| 轨迹复用 | 一次更新、多 epoch、离线缓存 | 涉及行为 IS 和适应有限缓存的问题 |
| 位置权重与 teacher 来源 | token 选择/加权、多 teacher、特权上下文、自蒸馏 | 是另一个实验因素，不能混成估计器效果 |

GKD 可以在 student 轨迹上直接优化不同散度；MiniLLM 的单步分解也包含词表求和。因此“on-policy”描述轨迹来源，并不自动指定 reverse KL 或 sampled-token。[^gkd][^minillm]

## 3. 方法总表

下表固定 reverse-KL 参照，假定未截断的当前 student 抽样。需要 tail mass 或 sampled score 的稀疏方法仍需要完整归一化的 student 概率；仅支持内归一化 KL 是可省去全词表 normalizer 的特例，但它改变了目标。$O(K_{\rm head})$ 指保留的监督项或反馈宽度，不代表整个 transformer/LM head 的计算复杂度。

| 方法 | Teacher 必需信息 | 条件目标/梯度 | 动作抽样噪声 | 本项目定位 |
| --- | --- | --- | --- | --- |
| Sampled-token | $T_a$ | $\ell_a \psi_a$，期望为 $g$ | 有 | 最便宜的参照 |
| vOPD，full baseline | $T_a$ 与全词表 KL 所需信息 | $(\ell_a-K)\psi_a$，期望为 $g$ | 仍有 | 判断精确 baseline 的效果 |
| vOPD，top-k baseline | $T_a$、固定集合 $S$ 上的 $T_i$ | $(\ell_a-C_S)\psi_a$，期望为 $g$ | 仍有 | 低通信成本的优先候选 |
| 直接截断 top-k rKL | $S$ 上的 $T_i$ | 对 $\sum_{i\in S}p_i\ell_i$ 求导 | 无动作抽样噪声，但偏离 $g$ | 有偏对照，需写清是否停止系数梯度 |
| 支持内归一化 top-k rKL | $S$ 上的 $T_i$ | $\mathrm{KL}(p(\cdot\mid S)\Vert T(\cdot\mid S))$ | 同上 | TA-OPD 的主要负对照 |
| TA-OPD | teacher top-k 的完整归一化概率 | top-k + tail 桶的粗粒度 rKL | 无动作抽样噪声，但偏离完整 rKL | 检查尾部总质量的作用 |
| HETS / 同类 TT-OPD | $S$ 上的 $T_i$ 与 $T_a$ | 头部精确梯度 + sampled 尾部梯度 | 有，期望为 $g$ | ResOPD 的必要结构对照 |
| ResOPD | teacher top-k 与 $T_a$ | 粗粒度梯度 + 随机向量残差 | 有，期望为 $g$ | 尾部控制变量候选 |
| SC-TA | teacher top-k 与 $T_a$ | 粗粒度梯度 + 条件尾部 log-ratio 修正 | 有，期望为 $g$ | 应与 ResOPD 并列比较 |
| Full-vocab rKL | 全分布，或可精确重建的 hidden states + head | 直接计算 $K$ 与 $g$ | 给定前缀时为零 | 数学参照；应使用流式实现 |
| 多候选 Monte Carlo | 每个候选的 $T_{a_j}$ | 平均多个合法 sampled 梯度 | 独立抽样时随候选数下降 | 预算匹配的补充对照 |

Teacher top-k 与 student top-k 不能混记为同一配方。原版 vOPD 使用 **student top-k**；ResOPD 的 payload-matched vOPD 使用 **teacher top-k**。TA-OPD 指用户给定仓库中的 **Tail-Aware** 方法；另有同名的 Teachability-Aware OPD，属于位置选择问题，不是这里的尾桶方法。[^vopd][^taopd][^resopd]

## 4. Sampled-token 与 KL baseline

### 4.1 Baseline 的符号与无偏性

使用成本形式，令 $C(s)$ 为与本次 sampled action 无关的标量，则

$$
\widehat g_C=(\ell_a-C(s))\psi_a,\qquad a\sim p.
$$

由于 $\mathbb E_p[\psi_a]=0$：

$$
\mathbb E_p[\widehat g_C]
=\sum_i p_i \ell_i \psi_i-C(s)\sum_i p_i \psi_i=g.
$$

vOPD 取 $C=K$。换回 reward 形式，baseline 是 $b_{\rm base}=-K$，advantage 是 **$r^{\rm cur}-b_{\rm base}=r^{\rm cur}+K$**，不是 $r^{\rm cur}-K$。在 $p=q_k$ 且 $\kappa=0$ 时，$K=K_T(q_k,T)$，$r^{\rm cur}+K=\mathcal A_k$。离开锚点后，当前 KL baseline 是 $K(p,T)$，不能继续记成整轮冻结的 $K_T$；其中心化算子是 $C_p$，不是 $C_q$。这里的“value”是当前前缀下单个 next-token reward 的期望，不是另外训练一个预测完整未来回报的 critic。实现时 baseline 与 reward 系数均 detach，只让梯度经过 sampled log-prob 或 ratio。[^vopd]

只要 baseline 不依赖本次动作，即使它近似不准，也不会改变上述期望。原版 top-k baseline 为

$$
C_S=\sum_{i\in S}\bar p_i\log\frac{\bar p_i}{\bar T_i},\qquad
\bar p_i=\frac{p_i}{\sum_{j\in S}p_j},\quad
\bar T_i=\frac{T_i}{\sum_{j\in S}T_j}.
$$

原论文的 $S=\mathrm{TopK}(p)$；为共享稀疏反馈，可以另做 $S=\mathrm{TopK}(T)$ 的实验，也可将 TA 的粗粒度 KL 仅作为 detached scalar baseline。它们保持该无偏身份，但不等于原版 student-top-k baseline，方差与效果需要重新测量。

不能用同一个 sampled token 的 $\ell_a$ 当作 $C(s)$，否则梯度直接归零。也不能将 sampled token 临时并入支持集后，未经推导就宣称 baseline 独立于动作。正确做法是固定 $S$，额外返回 $T_a$，但不让 $a$ 改变 baseline 的定义。

### 4.2 Baseline 不保证处处降低方差

对于给定参数空间中的梯度，最小化协方差迹的成本 baseline 是

$$
C^*(s)=\frac{\mathbb E_p[\ell_a\lVert \psi_a\rVert^2]}
{\mathbb E_p[\lVert \psi_a\rVert^2]}.
$$

推导是将 $\mathbb E[(\ell_a-C)^2\lVert \psi_a\rVert^2]-\lVert g\rVert^2$ 对 $C$ 求导并令其为零。$K=\mathbb E_p[\ell_a]$ 一般不等于 $C^*$；KL baseline 的收益是有条件的，不是逐前缀的普遍定理。我们的二分类 CPU 反例 $p=(0.9,0.1)$、$T=(0.5,0.5)$ 中，logit 梯度协方差迹从约 0.348 增至 0.556。该反例不否定论文的实测收益，只限定能作出的保证。

有行为 IS 时，$\widehat g=w_a(\ell_a-C)\psi_a$，$w_a=p_a/\beta_a$；baseline 项仍在期望下消失。此时最优 baseline 的权重变为 $\beta_aw_a^2\lVert \psi_a\rVert^2$，更不能直接声称精确 KL 是最优选择。PPO clip、ratio clamp、按动作筛选或 NoIS 会破坏这套简单的零均值论证。

### 4.3 作者实现与本仓的工程差距

vOPD 作者实现继承 TRL `MiniLLMTrainer`。`compute_loss()` 先运行 student，再在 `no_grad` 下运行 teacher，得到两份 logits；`kl_top_k` 控制 baseline，`opd_top_k` 控制直接 distillation loss 的支持。代码在形成 `centered_gap` 后 detach。默认 top-k YAML 是 100，论文主设置为 20；复现时必须显式区分。[^vopd-code]

源码并未在所有 baseline 运算外包一层 `no_grad`：student 侧部分临时图直到最后 detach 才断开。移植时应将 baseline 的选集、归一化、求和整体放入 `no_grad`，避免建立随后丢弃的图。Teacher/student logits 同时可用是作者代码“无需额外 inference”的前提。我们的共享 teacher 先评分再 offload，只保留 sampled 分数，不能直接套用这个成本结论。

论文报告的 4B 单 H200 步时为 top-k vOPD 32.88 秒、full-vocab OPD 77.66 秒；作者默认配置另有 LoRA、1024/2048 长度、cosine LR 等差异。该数据说明其实现上的相对成本，不用于预测我们全参数 FSDP2、7168 response 的速度。[^vopd][^vopd-code]

## 5. Top-k、TA-OPD 与随机尾部修正

令 $S$ 是固定支持集，默认取 teacher top-k，定义

$$
p_S=\sum_{i\in S}p_i,\quad T_S=\sum_{i\in S}T_i,\quad
\tau_p=1-p_S,\quad\tau_T=1-T_S,\quad \ell_{\rm tail}=\log\frac{\tau_p}{\tau_T}.
$$

### 5.1 直接截断、归一化与 TA 是三个目标

直接截断 $\sum_{i\in S}p_i\ell_i$ 不一定非负；普通 autograd 还产生 $\sum_{i\in S}\nabla p_i$，因为子集质量不恒等于 1。因此它与 stopped-coefficient 的头部梯度 $g_{\rm head}=\sum_{i\in S}p_i\ell_i \psi_i$ 也不相同。

支持内归一化 KL 只比较头部条件分布，丢失 $p_S,T_S$ 的质量匹配。TA-OPD 保留真实 top-k 概率，并补一个 tail 类别：

$$
K_{\mathrm{TA}}=\sum_{i\in S}p_i\ell_i+\tau_p\log\frac{\tau_p}{\tau_T}.
$$

将尾部完整求和拆开可得

$$
K=K_{\mathrm{TA}}+
\tau_p\,\mathrm{KL}\bigl(p(\cdot\mid\bar S)\Vert T(\cdot\mid\bar S)\bigr).
$$

因此 TA 是完整 rKL 的下界，但忽略尾部内部的条件分布差异。它能纠正“头尾总质量不匹配”，并非完整梯度的无偏估计器；也不保证其梯度总比截断梯度更接近完整梯度。[^taopd]

TA 作者代码使用 `logsumexp` 和 `log1mexp` 计算 tail log-mass，比 BF16 下直接 `1-sum(exp(logp))` 更稳健。仍需监测尾质量接近零时的数值保护，并保证用于质量计算的是全词表归一化概率，而非已在 top-k 内归一化的数值。[^ta-code]

### 5.2 HETS 与 TT-OPD：需要补入的对照

定义单动作梯度 $v_a=\ell_a \psi_a$，尾事件 $J_a=\mathbf1[a\notin S]$。HETS 为

$$
\widehat g_{\mathrm{HETS}}=g_{\rm head}+J_a v_a.
$$

其期望是头部精确项加完整尾部期望，等于 $g$。它使用和 ResOPD 相同的 top-k + sampled-token payload，因此是判断 ResOPD 控制变量收益的必要对照。EMA-PG 的 Top-k KL 提供了相关头尾混合实现；其 EMA anchor 是另一项机制，我们只参考估计器，不引入动态 teacher。[^ema][^ema-code]

源码名称不保证梯度一致。EMA-PG 审阅版本的 `search/verl/trainer/ppo/core_algos.py::compute_memory_efficient_kl(full_reverse)` 对头部 $\sum_{i\in S}p_i\ell_i$ 保留普通 autograd，尾部却使用 stopped log-ratio；对普通可微输入，头部多出 $\nabla p_S$。我们抽取该 primitive、枚举四个动作后，期望与 full-rKL 梯度最大差为 0.13，减去 $\nabla p_S$ 后误差回到浮点精度。因此这里只将它作为头尾拆分的工程参考，不把这个已审阅代码路径直接称为标准 HETS 的通过验收实现；结论限于该 primitive，不代替整个 EMA-PG RL 系统的效果评价。[^ema-code]

TT-OPD 论文也给出了 stopped-coefficient 的精确头部加 sampled 尾部，在相同 $S$ 与采样条件下对应这一梯度结构。其默认实验使用 student top-k，不能与 teacher-top-k HETS 不加区分地比较。已读论文中未定位到作者明确链接的代码仓库，不将第三方复现当作作者实现。[^ttopd]

稀有 tail hit 的梯度可能很大；高 head coverage 不意味着 tail sampling 方差可以忽略。反过来，HETS 也不是对每个分布都必然优于完整 sampled-token estimator。

### 5.3 ResOPD：对尾事件使用向量控制变量

尾桶对应的条件 score 与向量控制为

$$
\bar \psi_{\mathrm{tail}}=\nabla\log\tau_p
=-\frac{1}{\tau_p}\sum_{i\in S}p_i \psi_i,
\qquad \mathbf b_{\rm tail}=\ell_{\rm tail}\bar \psi_{\mathrm{tail}}.
$$

TA 的梯度为 $g_{\mathrm{coarse}}=g_{\rm head}+\tau_p\mathbf b_{\rm tail}$。ResOPD 构造

$$
\widehat g_{\mathrm{Res}}=g_{\rm head}+\tau_p\mathbf b_{\rm tail}+J_a(v_a-\mathbf b_{\rm tail}).
$$

因为 $\mathbb E[J_a]=\tau_p$，向量控制在期望中抵消，得到 $g$。它不是简单把 TA loss 和 sampled loss 相加：尾部修正必须减去 $\mathbf b_{\rm tail}$，否则重复计算粗尾部信号。[^resopd]

作者 `resopd.py` 使用等价的 centered-event surrogate，停止 score 系数和事件中心化质量的梯度，并通过 `value.detach() + surrogate - surrogate.detach()` 保留指定日志值。其前向数值与反向 surrogate 的角色不同；不能用该标量直接当作每次都非负的真实 full KL。源码会物化 FP32 的全词表 `log_softmax`，所以“稀疏 teacher 反馈”不等于“常数显存的 student loss”。[^res-code]

### 5.4 SC-TA 与 ResOPD 不是同一个估计器

SC-TA 的梯度为

$$
\widehat g_{\mathrm{SC}}=g_{\mathrm{coarse}}+J_a(\ell_a-\ell_{\rm tail})\psi_a.
$$

与 ResOPD 的逐动作差异为

$$
\widehat g_{\mathrm{SC}}-\widehat g_{\mathrm{Res}}
=J_a \ell_{\rm tail}(\bar \psi_{\mathrm{tail}}-\psi_a).
$$

该差异的条件尾部期望为零，所以两者具有相同目标，但有限样本方差不同。ResOPD 论文给出的统一族可写为

$$
\widehat g_\gamma=g_{\rm head}+\tau_p \mathbf b_{\rm tail}+
J_a\left[v_a-\mathbf b_{\rm tail}-\gamma \ell_{\rm tail}(\psi_a-\bar \psi_{\mathrm{tail}})\right].
$$

$\gamma=0$ 是 ResOPD，$\gamma=1$ 是 SC-TA。它们是可组合控制变量的两个端点，不存在无需条件的方差排序。我们独立枚举 64 组有限动作案例，验证两者期望均等于完整 rKL 梯度，但逐动作向量确实不同。[^resopd][^taopd]

TA 作者仓库的 SC-TA helper 支持 `behavior_logp_y`；直接 loss 的调用方实际传入 `old_log_probs`，不是 vLLM 的 `rollout_log_probs`。在本仓移植时要使用真实行为分母，不能把变量名当作分布一致性的证明。另一个静态代码问题是该调用方在 PG 分支将 `behavior_logp_y` 设为 None，随后无条件 `.detach()`；该分支不能未经修正和测试就照搬。这里只报告源码审计，未运行作者完整训练栈。[^ta-code]

### 5.5 多次更新时，IS 只放在随机残差上

对 $a\sim\beta$，正确的固定前缀 ResOPD 扩展是

$$
\widehat g_{\mathrm{Res,IS}}
=g_{\rm head}+\tau_p\mathbf b_{\rm tail}+J_aw_a(v_a-\mathbf b_{\rm tail}),\qquad w_a=p_a/\beta_a.
$$

HETS 的随机尾项和 SC-TA 的随机尾项也分别乘 $w_a$。头部与粗尾部已在当前 $p$ 下精确求和，不应机械套入一个 sampled PPO ratio。每次 forward 都要重算当前 $p_i,p_S,\tau_p,\mathbf b_{\rm tail}$；teacher 值和固定支持集可以复用。

直接 full-vocab 或 TA 的条件散度已经显式积分 next-token，没有 sampled action 的 IS 校正需求，但轨迹前缀分布仍可能变旧。E1–E6 的 fixed/current、NoIS/PPO 开关不能原封不动地套在这些直接散度上。

### 5.6 k1/k2/k3 名称不能代替梯度定义

还应把“KL 标量估计器”与“KL 梯度估计器”分开。令 $\ell=\log(p_a/T_a)$，常见 $k_1=\ell$、$k_2=\ell^2/2$、$k_3=e^{-\ell}-1+\ell$。在 $a\sim p$ 时 $k_3$ 的数值期望是 reverse KL，但固定样本后直接求导得到 $(1-T_a/p_a)\psi_a$；其当前分布期望为 $-\mathbb E_T[\psi_a]$，不是本文的 reverse-KL score 梯度。数值无偏不自动意味着所写计算图的梯度无偏。

所以把当前 `loss_mode=k1` 换成 k3、再把它当作 reward，并不等于加 KL baseline。需要连同采样分布、IS、detach 与 backward 路径一起审计；已有数学文档第 3.3 节给出了能逐样本抵消额外导数项的修正标量。

## 6. Full-vocab 与高效 baseline 的实现取舍

Full-vocab 必须标明方向：本文参照是 $\mathrm{KL}(p\Vert T)$；$\mathrm{KL}(T\Vert p)$ 是另一个目标。给定所有 logits，reverse-KL 的 logit 梯度为

$$
\frac{\partial K}{\partial z_j}=p_j(\ell_j-K).
$$

精确求和时加入任意 action-independent baseline 会被 $\sum_i p_i \psi_i=0$ 精确抵消，因此 **full-vocab + scalar baseline 不构成新的降方差实验**。Full-vocab baseline 用于 sampled-token 则仍有动作噪声，二者不可混称。

高效实现的公共选择如下，详细算法、内存公式和预算只在[计算与显存预算](../full-vocab/2026-10-22-词表蒸馏的计算与显存预算.md)维护：

| 目标 | 建议的数据通路 | 主要注意点 |
| --- | --- | --- |
| Teacher-top-k baseline / TA / HETS / Res / SC-TA | teacher 一次前向返回完整归一化 top-k，另保留 actual sampled score | 同一 payload 支持多种算法；拒绝把 sampled token 混入 baseline 支持集 |
| 原版 student-top-k baseline | student 先产生选集，再让 teacher 对这些 IDs 评分；或保留 teacher hidden states | 需调整现有 teacher→old-log-prob 顺序；多轮重选支持集要重新取 teacher 值 |
| Full baseline | teacher hidden states + 冻结 LM head，在 `no_grad` 下流式累积 KL，最终仅保存 scalar | 没有额外 critic，但当前架构必须补 teacher 信息通路 |
| Full-vocab rKL | hidden states + 分块重建，定制 backward 或重计算 | 不能先物化 `[N,V]` 再声称消除了 logits 显存 |

原版 student-top-k baseline 的归一化还允许直接在选出的 student/teacher logits 上各自做 `log_softmax`，共同的 full-vocab log-normalizer 会抵消。这个技巧只能用于支持内归一化 baseline；TA/Res 的 tail mass 与 sampled reward 仍需要真实全词表归一化值。

## 8. 可以组合的方案与不能机械组合的方案

| 组合 | 判断 | 条件或原因 |
| --- | --- | --- |
| Sampled-token + full/top-k/coarse KL baseline | 可以 | baseline 独立于当前抽样动作、detach，采样/IS 合法 |
| Sampled-token + 多个局部候选 + baseline | 可以 | 固定前缀独立有放回抽样；不是额外生成多条完整回答 |
| HETS + 尾事件向量控制 | 就是 ResOPD 所属族 | 不能只加 TA loss 而不减重复项 |
| ResOPD + 条件尾部 score 控制 | 可以，SC-TA 是一个端点 | 系数 $\gamma$ 改变方差；不可预设越大越好 |
| ResOPD + 全局标量 baseline | 数学上可构造 | 减去 $C(s)\psi_a$ 的零均值项会重新引入 head 分支随机性；只在 tail 减 baseline 而不补均值会有偏 |
| Full-vocab + scalar baseline | 梯度不变，不必单列 | 条件动作期望已精确求和 |
| TA + 任意 sampled correction | 不一定合法 | 必须使用 SC-TA/Res 这类消除重复粗项的推导 |
| 任一估计器 + token 位置加权/teacher 变换 | 可以研究，但另开实验轴 | action-dependent 权重或选择会改变目标和无偏性条件 |
| 任一直接散度 + E1–E6 全套 PPO/NoIS 开关 | 不应直接组合 | 直接积分的头部/全词表不需要 sampled action ratio |

多候选估计在固定参数、独立抽样下，平均 $M$ 个估计器的协方差缩小为 $1/M$。重复 token 应保留频次，不应去重后直接等权；deterministic top-k 也不是 $M$ 次 Monte Carlo 抽样。候选数、完整 rollout 数、词表 top-k、采样 top-k 是四个不同参数。

## 9. 在当前 math setting 下的实验安排

方法重要性排序、full-vocab 数值/梯度计算图及 One-Shot-OPD 支持集审计见[实验排序与 Top-k 支持集](2026-10-21-Reverse-KL实验排序与Top-k支持集.md)。新页将 full-vocab 的小规模 oracle 提前；下文仍保留按稀疏数据通路组织的工程接线顺序。

### 9.1 先固定一次更新，再比较估计器

原数学脚本是 current + vanilla、batch=mini-batch=64、每批一次更新；E1–E6 入口默认四次更新。为了先隔离估计器，建议第一轮统一 **`ppo_epochs=1`**，使用真实行为概率、无 PPO clip 的 sampled-token 作为参照；现有代码对应 `PPO_EPOCHS=1` 的 E4。不要同时引入四轮复用、teacher 支持集变化和新 loss。

建议的第一轮矩阵：

| 优先级 | 实验 | 解决的问题 |
| --- | --- | --- |
| 1 | Sampled-token + teacher-top-16 baseline，与 sampled-token 对照 | 最小增加的数据通路能否改善噪声/质量 |
| 1 | TA-OPD 与 normalized teacher-top-16 rKL 对照 | 尾质量建模是否必要 |
| 1 | HETS、ResOPD、SC-TA，统一 teacher-top-16 + sampled payload | 对同一完整 rKL 目标，尾部控制如何影响方差与训练 |
| 2 | 小批固定前缀的精确 full-vocab rKL | 取得真实 KL、梯度偏差及协方差参照 |
| 2 | 流式 full-vocab 的端到端组、full KL baseline | 比较精确梯度与精确 baseline，验证实际成本 |
| 2 | 原版 student-top-20 baseline，与 teacher-top-20 变体 | 区分支持集选择与 baseline 机制 |
| 3 | k=4/16/32、局部 MC=2/4/8、控制系数 $\gamma$ | 测定通信、计算与估计质量的折中 |

资源只够少数组时，先做 sampled、teacher-top-k baseline、TA、Res 四组；但正式声称 Res 的残差控制有效之前必须补 HETS，声称 Res 优于另一种无偏尾补偿之前必须补 SC-TA。原版 vOPD 的 student 支持不能悄悄换成 teacher 支持后沿用同一名称。

### 9.2 再研究复用与资源预算

筛选估计器后再做 epochs=4，与已有 E 系列连接。随机部分采用真实行为 IS，精确部分每轮按当前 student 重算。Full baseline 可缓存 rollout 时的 scalar，仍作为 action-independent 近似 baseline，但它不再是每轮当前模型的精确 KL baseline，需独立命名。

比较至少同时报告：实际 optimizer 更新数、生成 response token 数、teacher 评分 token 数、完整训练/验证墙钟与 GPU 小时。等更新次数、等生成预算、等墙钟是不同问题，不能只按外层 step 对齐。共享 fixed-prefix 审计使用同一批真实轨迹；端到端各组后续轨迹会分叉，同 seed 不保证相同回答。

### 9.3 需要记录的量

固定前缀：真实 full rKL、估计梯度均值偏差、协方差迹、梯度方向，以及 teacher-top-k 下 student mass/tail mass。小模型或少量位置可枚举完整词表；大模型可记录 logit/hidden/head 梯度代理，但必须标明它们不等于全参数梯度协方差。

端到端：三个数学验证集各自的 `acc/mean@16`，以及 grad norm、clip/数值保护/跳步比例、teacher forward/transfer、actor update、整卡峰值和主机 payload 峰值。不同方法的 surrogate loss 数值不直接横比；ResOPD 的日志 surrogate 和真实 KL 应分列。既有 GPU busy、FSDP allocated 和整卡显存的口径沿用 infra 文档。
