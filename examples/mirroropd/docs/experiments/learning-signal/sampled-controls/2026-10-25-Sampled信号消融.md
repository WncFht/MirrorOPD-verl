# Sampled-token 信号与修正消融

## 实验问题与设置

E1–E12 比较教师信号来自 rollout 还是 current，以及 token IS、token PPO 或 REINFORCE NoIS。`rollout` 使用生成时的行为 log-prob；它不自动等于训练端重算的冻结 anchor。短程与长程预算分别观察 4 次和 16 次批内复用。

| 短程 / 长程 | advantage_source | policy_loss_mode | 已有正式运行 |
| --- | --- | --- | --- |
| E1 / E7 | rollout | token_ppo | 两个编号均未发现记录 |
| E2 / E8 | rollout | token_is | 两组完成 |
| E3 / E9 | current | token_ppo | 两组完成 |
| E4 / E10 | current | token_is | 两组完成 |
| E5 / E11 | current | reinforce（NoIS） | 两组完成 |
| E6 / E12 | rollout | reinforce（NoIS） | 两个编号均未发现记录 |

| 设置 | E1–E6 | E7–E12 |
| --- | --- | --- |
| 每批复用 / outer 预算 | 4 / 32 | 16 / 200 |
| 计划更新数 | 128 | 3200 |
| 验证 / 保存 | 最后一步 | 每 50 / 100 outer；包含最终步 |
| 初始验证 | 关闭 | 关闭 |

已跑八组使用 R1-Distill-Qwen-1.5B student、JustRL-DeepSeek-1.5B teacher、DAPO、seed=42、batch=mini-batch=64、每题一条训练回答、LR=1e-6、token-mean；prompt/response cap 为 4096/7168。验证 MATH-500/AMC23/AIME25，500/40/30 题，每题 16 条、T=0.7、top-p=0.9、response cap=31744。关键设置见[运行记录](../../运行记录.md)；完整 config 在日志仓库按 run ID 查询，包含额外 clip、优化器、模型与数据路径，见[查看方法](../../维护说明.md#当前运行与验证表)。

## 运行入口

```bash

STUDENT_GPUS=8 bash examples/mirroropd/run_math_opd_ablation_fsdp2.sh E10
CONFIG_ONLY=1 bash examples/mirroropd/run_math_opd_ablation_fsdp2.sh E10
```

资源与环境配置见[训练配方](../../../settings/训练设置.md)。当前消融合同见[优势与 IS 实现](../../../infra/training/2026-10-21-优势与IS消融及更新计数实现方案.md)。环境变量和 Hydra 覆盖后，按实际 config 登记 setting。
