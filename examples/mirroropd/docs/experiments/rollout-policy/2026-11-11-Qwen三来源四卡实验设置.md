# Qwen 三来源四卡实验设置

更新日期：2026-11-11。本文记录 Qwen initial、current、teacher 三个训练条件的实验协议，以及 Math64＋Code32＋IF32 双来源固定银行的 RKL 读出与中期权重保存方案。三个来源的四卡短检查均已通过，正式队列已进入共享基线生成，尚未开始正式 optimizer 更新。训练复用主线优化后的 full-vocab RKL 链路；周期模型快照和三域双来源原生评估已实现并通过四卡短检查。

## 比较目标与三个条件

固定 learner 为 Qwen3-1.7B（non-thinking），固定监督 teacher 为 Qwen3-4B-Instruct-2507，只改变训练回答的生成来源。三组分别重新加载相同原始 learner，使用新的 AdamW 状态；训练题目及其顺序、学习预算、损失与评估协议相同。

| 条件          | 训练轨迹生成者         | 生成权重的变化                          |
| ------------- | ---------------------- | --------------------------------------- |
| initial（S0） | 原始 Qwen3-1.7B        | 始终固定；每轮对新的训练 batch 生成回答 |
| current（S）  | 正在训练的 learner     | 每轮使用上一轮完成更新后的权重          |
| teacher（T）  | Qwen3-4B-Instruct-2507 | 始终固定                                |

三组的优化目标都指向同一个监督 teacher。Initial 固定生成器权重，不是复用第一批回答。本轮不包括 LM、PM、TM、R1 配对或 batch128 扩展。已有 E64/E63/E65 分别对应这三种来源，但编号默认配置尚不包含本文新增的保存与三域评估协议，不能直接视为完整执行命令。

| 数据            | 复用旧 Qwen 六来源的去重 DAPO 训练池，16986 题；排除 320 道保留题和 630 道任务评测题的规范化文本交集 |
| 访问预算        | batch64、n=1，40 outer 访问 2560 道不同训练题；三组共用同一冻结 sampler 顺序                         |
| 更新预算        | 每个新 batch 连续 reuse16，共 640 次 optimizer 更新/组                                               |
| 目标            | 原生完整词表 reverse KL，token-mean；任务奖励不进入 loss；终止 token 不合并、不额外屏蔽              |

| Full-vocab 执行 | `precompute_fused`，token chunk1024                                                                  |

## 三域 held-out 与双来源固定银行

保留题目沿用[旧共同协议](data/scientific-v2-20261030/sources/teacher-transfer-protocol.md#训练数据与-held-out-的具体含义)和[六来源完成协议](r1-sources.md#已确认的共同评估协议)的题目身份，按本轮 Qwen non-thinking 模板编码。

| 域   | 来源                  | 完整保留题池 | 本轮固定评分题数 | 银行回答生成上限 | 常规评分窗口               |
| ---- | --------------------- | ------------ | ---------------- | ---------------- | -------------------------- |
| Math | DAPO                  | 192          | 64               | 7168 token       | 前 1024 个 response token  |
| Code | TACO                  | 64           | 32               | 1024 token       | 前 1024 个 response token  |
| IF   | MultiIF，English 条目 | 64           | 32               | 1024 token       | 前 1024 个 response token  |
| 合计 | 三域                  | 320          | 128              | 按域设置         | 提前结束只评分实际有效位置 |

全部 320 道保留题都排除于训练池；常规评分使用其中 128 题，另外 192 题仍保持保留。Held-out 仅表示未参与本轮蒸馏更新；这些题来自上游 train split，不能保证 teacher 或 learner 的上游训练未见。文本隔离不保证没有语义近重复。

在相同 128 题上分别生成两套银行，每题每来源一条，共 256 条轨迹：

- **Initial bank**：原始 Qwen3-1.7B 生成。
- **Teacher bank**：固定 Qwen3-4B-Instruct-2507 生成。

银行使用 temperature1、top-p1、top-k−1、non-thinking 模板和相同停止集合；冻结逐题 seed、原始 token、mask、停止原因及生成配置。生成一次后由三个训练条件、所有读出节点共用，不随 learner 更新重新生成。复用已有 Qwen 银行前核对题目、模型、模板、token 及有效采样协议身份；身份不同则在新运行目录生成，旧银行保持原样。

每次读出都用当前训练 learner，在两套固定银行上分别计算到同一监督 teacher 的完整词表 RKL。Initial 与 teacher 在这里首先区分的是轨迹来源；KL 的两侧始终是当前 learner 与监督 teacher，initial 不作为另一个 KL 目标。

令 $b$ 为银行来源，$d$ 为域，$h_{i,t}^{b}$ 为冻结回答第 $t$ 个有效位置之前的完整历史，$L_i$ 为常规窗口内的有效 response token 数。主指标为逐题有效 token 平均后再按题平均：

$$
R_{b,d}(\theta)=\frac{1}{N_d}\sum_{i=1}^{N_d}\frac{1}{L_i}\sum_{t=1}^{L_i}D_{\mathrm{KL}}\!\left(p_\theta(\cdot\mid h_{i,t}^{b})\,\Vert\,q_{\mathrm{teacher}}(\cdot\mid h_{i,t}^{b})\right).
$$

两套银行、三个域分别报告绝对 RKL 和相对 outer0 的变化，形成六条读出序列/训练条件。空回答单列并核查，不以零风险填充。整体摘要按 Math/Code/IF 的 64∶32∶32 题数加权，先汇总风险再计算降幅，不平均三个域的下降百分比。

为与旧报告对照，同一批逐题累计值另导出固定 H1024 分母的兼容指标。有效 token 均值是本轮主指标；固定 H1024 是旧口径，两者分别命名、分别画图，不拼成一条曲线。Code/IF RKL 衡量跨域条件分布拟合，不等于代码通过率或指令任务成功率。

本轮不额外安排 Math32 长前缀评分、fresh/current held-out 生成或 history RKL 读出。Math 银行的完整生成轨迹仍保留，可供后续明确安排的长历史分析使用；实际训练轨迹继续完整存盘。

## 读出节点与任务评测

| 项目              | outer 节点                              | 内容                                                |
| ----------------- | --------------------------------------- | --------------------------------------------------- |
| 固定 held-out RKL | 0、1、2、3、4、5、8、10、15、20、30、40 | 每次评分两来源×三域，共 256 条固定轨迹的短窗口      |
| FP32 模型快照     | 1、2、3、4、5、8、10、15、20、30、40    | 保存该轮 16 次更新全部完成后的 learner              |
| 完整任务 accuracy | 20、40                                  | 当前纯 learner 在 630 题上每题 4 次回答             |
| 原始模型基线      | 训练前共享一次                          | 原始 learner 与 teacher 的 accuracy；各训练条件共用 |

任务题由 MATH-500、AMC23、AIME24、AIME25、AIME26 组成。生成使用 temperature0.7、top-p0.9、response cap31744、独立评估随机流和统一停止集合。先平均每题 4 个评分，再计算各数据集 accuracy 与五集等权 macro，指标为 avg@4。Accuracy 只评估纯 learner，不使用 initial 或 teacher 来源替代训练后模型生成。

两套银行的 held-out RKL 是共同固定状态读出，训练 rollout loss 是各来源访问状态上的优化记录，accuracy 是自由生成任务结果，三者分别展示。原生入口默认的额外 public/history/current-state 读出不自动继承到本协议；最终配置需与本表一致。统计如需区间，按题配对 bootstrap，不把同题 token 或 4 条回答当独立样本；单训练 seed 的区间不代表跨训练 seed 不确定性。

## 中期权重与轨迹保存

每组保留 11 份 FP32 HF 模型快照及 tokenizer、配置、outer、实际 optimizer 更新计数、模型和输入身份。outer0 引用原始资产。快照在暂存目录完成后核对文件完整性和权重精度，再发布完成回执；指定保留节点不进入滚动清理。短检查验证导出和加载前后固定输入 RKL 一致，正式保存记录对应校验结果。

这些快照用于追加推理和参数变化分析，属于 model-only 导出。完整恢复还需要 optimizer、RNG、sampler 和评估进度；滚动完整恢复属于尚未纳入本协议的能力，不把 model-only 快照标成可连续续训。

训练轨迹每轮全存 64 条，每组共 2560 条，三组共 7680 条。保留 prompt/response 原始 token IDs、有效 mask、可读文本、题目身份、轨迹身份、实际来源、生成权重版本、采样配置及停止原因。实际逐请求 seed 或 behavior log-prob 若可取得则保存；缺失项显式标注，不用全局 seed 代替逐请求 seed，不重新生成回答补充成原轨迹。完整词表 logits 不作为常规存盘项。

Current 第 $k$ 轮轨迹由第 $k-1$ 轮更新结束的模型生成，`outer-k` 快照则包含第 $k$ 轮全部更新；initial/teacher 来源始终指向各自固定模型。运行记录同时保存生成者版本与接受更新的 learner 版本，避免将训练前缀误配到更新后权重。三域固定银行与任务评测的原始回答、逐题 RKL/评分、逐更新指标均保留。

按 1.7B 参数估计，每份 FP32 模型约 6.8 GB，11 份约 75 GB/组，三组约225 GB；另需暂存导出、日志和轨迹空间。该数字不包含完整 optimizer 恢复状态，实际占用以导出文件为准。新运行及验收产物统一放仓库 `runs/` 下，旧六来源证据和共享模型保持原位。

## 实现状态与正式运行依据
