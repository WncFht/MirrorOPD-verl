# Rollout 来源与混合效果

## 背景与 motivation

本线从 2610.11291 的复现和直接扩展出发，检验在同一师生配对和 learner 配方下，不同训练数据生成策略是否改变最终 accuracy。当前不承担同源/异源跨 batch 迁移的微观解释。

## Setting 与实验设计

比较当前 student、初始冻结 student、teacher，以及轨迹混合和逐 token 混合。每项实验固定模型配对、learner loss、optimizer、训练与验证协议，明确更新、token 和生成成本的匹配方式；实际 setting 在具体方案中登记。数学上定义的融合中心与实际双模型后端分别见[理论](../../theory/rollout-policy/2026-10-28-Rollout策略的目标设计与求解.md)和[工程实现](../../infra/rollout/fusion/README.md)。

## 正在进行的来源对照

[E20 设置下的六种前缀对照](2026-10-30-E20设置下的六种前缀对照.md)记录 R1-1.5B 配 JustRL-1.5B、Polaris-7B-Preview 的十二组 40 outer × reuse16 实验。旧无验证/无保存的 S0 运行只作优化诊断。用户已确认新版共同 held-out RKL 与纯 student 任务评测协议，数据与银行准备正在进行；新版十二组尚未启动，不把旧预跑计作其正式结果。

## 实验结果与分析

现阶段不填入模拟或工程 smoke 的 acc 作为正式结果。后续首先比较训练曲线、末次 accuracy 和成本；不预设混合策略更优，也不以分布中心半径下降代替学习效果。

Polaris 的固定来源、跨 batch 及交叉评分用于迁移假说，完整保留在[迁移机制](../teacher-transfer/transfer-mechanism/README.md)，不计作本线已完成效果实验。
