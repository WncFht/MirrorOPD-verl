# 跨 batch 与跨 state 迁移机制

## 背景与 motivation

同源 JustRL 与异源 Polaris 的局部拟合收益向其他 batch 传播的程度不同。需要固定输入、复测旧批和未见批，区分保持、迁移与访问分布变化；换批 loss 回升本身不是遗忘率。

## Setting 与证据

- [Qwen3 谱系与同构教师吸收](qwen3/2026-10-29-Qwen3谱系与同构教师吸收.md)：固定 1.7B student，九位 teacher，所有候选 avg@4；基线运行中，统一引擎训练验证待完成。
- [同架构吸收假说与最新续训设计](2026-10-29-同架构教师吸收假说与续训设计.md)：每个 student 一张终点汇总图；优先 J/N/M 续训与固定 1.5B 学生的新增 teacher，含新增教师评测、六组训练设置、轻量保存与完整 GapRecovery 口径；R1 扩展已完成，含十五个终点的 GapRecovery。

## 结果与分析

这些实验回答已见与未见 state 的收益为何不同，teacher/student rollout 是机制控制变量。它们不替代以最终 acc 为主要目的的来源/混合效果实验；每个系列的固定风险、fresh 风险与任务采样范围分别解释。
