# 当前展示协议：固定状态、0–320 更新

本页只定义本轮读图口径。新的训练／验证设置和 infra 调整留待后续讨论，既有实验条件不改写。

## 数据与状态

本地固定抽样来自 DAPO 数学、TACO 代码和 MultiIF 英文指令题。完整银行 640 题：数学训练池 A–T 共 320；数学留出 192；Code、IF 各 64。当前常规留出使用 Math64、Code32、IF32，共 128 题。剩余题不自动加入训练或主评分。

训练只使用数学题。每个 student／模式由原始权重生成自己的 S0 回答，temperature1、固定逐题 seed、H1024，EOS 后停止。该线所有 teacher 共用相同 token 前缀。student 每次更新重新计算这些前缀上的分布；teacher 固定，可缓存其 hidden/head。当前不是每步 fresh rollout 的完整在线 OPD。

held-out 仅相对于本轮梯度更新而言；源数据来自 train split，部分历史研究曾使用，不能声称完全未见或无预训练污染。独立任务评测为 MATH500、AMC23、AIME24/25/26 共 630 题，采用 avg@4，与这里的固定风险面板不同。

## 预算和优化

batch16, reuse16, H1024, AdamW LR1e-6, β=(0.9,0.999), ε=1e-8, weight decay0.01, clip1.

| 学生更新数 | 已访问训练题组 | 已访问独立题数 |
| ---------- | -------------- | -------------: |
| 64         | A–D            |             64 |
| 128        | A–H            |            128 |
| 320        | A–T            |            320 |

参数、梯度、Adam 和输出头使用 FP32；主干采用 BF16 autocast，RoPE buffers 保留 FP32，TF32 关闭。数值执行条件以每个实验实际记录为准。新 R1 副本显式使用确定性 FA2 backward，与历史轨迹分开记录。

## 风险和画图

训练目标为 full-vocab RKL，即在固定前缀上对整个动作支持求和的 KL(student || teacher)。R1 小教大使用单列的共同 151936 维条件 RKL；Tulu 的额外 teacher 输出质量单独记录。不同支持口径不混称同一目标。

既有风险使用每题固定 H1024 分母；EOS 后没有损失项。整体留出先按 Math64、Code32、IF32 合并风险，再计算相对初始降幅，不平均三个领域的百分比。

终点图中，训练栏只包括该终点已经访问的题；固定全训练池曲线可包括尚未访问的计划训练题，必须注明。A–D 是训练池子集。batch 影响图需要区分已见、当前和未见训练题组，永久 held-out 另列。

所有当前图限制在 0–320；更长运行目录中的历史快照也只能读取这一区间。teacher 的 SFT checkpoint 名称、银行题数与学生更新数是不同概念。Thinking／non-thinking 的银行不同，主要比较各线内部，不跨银行直接按绝对 KL 排名。

## 已保存的数据

每次更新记录当前 batch 的更新前 loss、梯度范数、实际 token 数和耗时；每 16 更新记录逐题固定评分。常见字段有 RKL、JS、TV、student／teacher entropy、额外支持质量及有效 token 数，并有响应位置分段汇总。既有记录通常不含完整逐 token KL 或全词表概率。

训练 loss 对应更新前参数；fixed 快照对应完成该次更新后的参数。附录绘图应显式对齐这一时刻差异。图谱与数据可用性见[附录绘图草案](appendix/figure-plan.md)。
