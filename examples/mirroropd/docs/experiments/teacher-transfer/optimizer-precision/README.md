# 优化器与精度

## 背景与 motivation

正确目标不保证有限步 optimizer 返回更好的策略。近目标误差、实际函数步幅、历史状态和计算精度需要受控区分。MDPO 当前重点是确认公式、数值路径和训练链路没有明显实现问题；任务优势、成本排名及更大优化器矩阵留待之后研究。

## MDPO 实现验收的重点

已有 E50/E51 支持修复后的生产路径恢复了固定目标的净下降。继续检查时围绕实现合同：η=1 与普通 Full-KL 的一致性；内层 anchor/teacher 冻结及归一化；目标、梯度与数值参考的一致性；优化器、AMP 跳步及恢复状态；最后一次实际更新后的目标评分。最后一项在既有日志中仍缺额外观测，不把更新前的第 16 次观测当作更新 16 次后的值。

实现验收不要求每个有限步优化器更新都单调下降，也不以 MDPO 的 acc 必须超过 OPD 作为通过条件。异常应先区分公式或执行错误、数值误差和正常的优化器行为，再决定是否需要进一步精度对照。
