# 模型与长度的失败复现

## 背景与 motivation

检验论文中的模型/长度失效条件，并区分语义修复、预算变体和原配对矩阵。综合研究问题见[模型配对与生成退化](../../README.md)。

本系列采用 DAPO → MATH-500／AMC23／AIME25，比较 sampled-token 与 full-vocab，包含基础版和同批 reuse16。详细模型、prompt/response 长度、终止协议、采样、训练预算、论文依据和启动命令集中在[正式实验方案](2026-10-25-Sampled-token与Full-vocab失败复现方案.md)。

## 正式训练进度

[实验矩阵与实际 setting](2026-10-28-矩阵与已运行变体映射.md)统一维护 E 编号、实际运行和结果入口，本页不再复制状态表。矩阵用于挂接实验与查看条件，空格不构成补齐任务；步数按实际运行记录，是否足以分析取决于研究问题与曲线证据。

## 原始师生参考与分析条件

各模型对还需要相同验证协议下的原始 student/teacher 评测。现有 1.5B 历史参考见[Full-KL 师生分析](../../../learning-signal/sampled-vs-full/2026-10-24-Full-KL收敛与师生参考评测.md)；执行／模板不同，不能直接补成新矩阵的真实 step 0。正式比较保持同组 sampled/full 的停止协议与过滤后题目集合一致，并补充相同 seed 集合。
