### 4.5 历史模型扩展筛查：49 个参考权重与 heldout 动态

#### 覆盖范围与统一测量

原 fixed-state explorer 中 47 条完整 single-pass 曲线全部接入，涉及 37 个不同 teacher 权重、39 个 initial-student/teacher 配对。其中 22 条曲线、19 个 teacher 配对通过完整张量名称与形状兼容检查，可以计算参数差；其余条件只比较各自完整权重谱。另补齐原 explorer 未纳入的三条 Polaris 曲线，独立保存，不混入主预测比较。历史清单的 42 个参考权重全部完成测量，再加入受控 RAW/CCS 三个 SFT teacher 和 MiMo 四个阶段权重，共 49 个参考权重。连同 OPD student 导出，共测量 102 个 checkpoint、612 个完整权重矩阵；原 explorer 有 50 个精确预算 student 读出可用于更新与残差分析。

每个 checkpoint 取第 $0,\lfloor(L-1)/2\rfloor,L-1$ 层的 k_proj 与 v_proj，共六个矩阵，以 CPU FP64 做精确 SVD。这是统一的六矩阵筛查，全层结论继续使用 §4.1 的独立测量。逐矩阵保存奇异值、能量分布、范数、张量哈希及来源；配对保存 $B,T,S_t,T-B,S_t-B,T-S_t$。统计表中的配对特征为六矩阵中位数。top-1% 指前 $\lceil0.01r\rceil$ 个奇异值的平方能量占比，$r$ 为矩阵最小维度；stable rank、90% 能量秩同时保存绝对值和除以 $r$ 的比例。

“同源”在数据中分成直接父模型与共同祖先分支。R1 的六个同尺寸 teacher、Qwen 的 Samsung/e3/GRPO 和 R7 Light 等按可核验父模型元数据登记。Thinking-Space 从 Qwen3-Base 训练，而此处 initial student 是后训练的 Qwen3-1.7B，因此两者属于共同祖先分支；$T-B$ 是实验 teacher 与实际 initial student 的差，并非该 teacher 自身的训练更新。MiMo 则显式保留 Base→SFT、Base→RL、Base→RL-Zero、SFT→RL、SFT→RL-Zero 五种配对。架构兼容只保证差矩阵有定义，训练血缘单独进入筛选。

[参数—heldout 交互浏览器](../../../../../runs/teacher-spectrum-followup-20261110/spectrum-expanded-v4/explorer.html)支持选择指标、64/320 更新、Math/Code/IF、绝对 KL、剩余比例和末 64 步下降，并下载筛选后的 CSV。它与原 explorer 的曲线一一关联；[覆盖清单](../../../../../runs/teacher-spectrum-followup-20261110/spectrum-expanded-v4/final-coverage.json)、[逐阶段关联表](../../../../../runs/teacher-spectrum-followup-20261110/spectrum-expanded-v4/heldout-feature-join.csv)及[模型指纹](../../../../../runs/teacher-spectrum-followup-20261110/spectrum-expanded-v4/model-profiles.json)提供可复算数据。

#### 关联尚未成为可靠的新 teacher 预测器

以 log 初始 KL 和 student/输入模式为基础预测量，预测 log10 终点绝对 KL。固定 ridge α=1，每轮留出整个 teacher 权重，所有输入模式一起留出；特征标准化只使用训练折。误差先在同 teacher 的模式内平均，再对 teacher 等权平均。64 步有 19 个 teacher，320 步有 17 个。

| 预测特征 | 64 步 MAE，dex | 320 步 MAE，dex |
| --- | ---: | ---: |
| 初始 KL + student/模式 | .153 | .220 |
| 再加更新幅度 | .143 | .193 |
| 再加 top-1% 能量 | .154 | .211 |
| 再加七个几何特征 | .179 | .261 |

更新幅度提供了最大的单项平均增益，但固定预测误差的 teacher 配对 bootstrap 中，改进量 95% 区间分别为 [−.054,+.032]、[−.109,+.052] dex，均跨零。该 bootstrap 重采样已生成的 teacher 误差，不重拟合模型，也不估计训练 seed 不确定性。仅保留有直接父模型元数据的配对后，幅度在 64 步改善 MAE，320 步反而从 .272 增至 .287。把所有几何特征加入小样本模型还会增加误差。

当前优先保留“更新幅度 + 谱集中度”作为候选组合。κ 与奇异值位移比例的相关方向跨组改变，预测误差也未改善；它们适合描述几何类型，尚无证据支持作为通用吸收评分。
