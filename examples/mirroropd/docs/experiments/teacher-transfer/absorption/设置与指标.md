## 研究对象：每条配对自己的 initial student

Base 在本文指实际 initial student $W_0$，可以已经经过 SFT 或 RL。Teacher 为 $W_T$，OPD 第 t 步为 $W_S(t)$。

$$
\Delta_T=W_T-W_0,\qquad \Delta_S(t)=W_S(t)-W_0,\qquad M_t=W_T-W_S(t).
$$

模型由许多独立参数矩阵组成。对每层七类投影分别计算差、范数和 SVD；全层绝对范数先把各矩阵平方范数相加再开方。不同宽度的模型只比较输出，不直接相减权重或 hidden。

## 指标：分别测量距离、几何、响应和效用

### 函数风险

固定状态 s 上，RKL 为 $D_{KL}(p_S\Vert q_T)$，FKL 为 $D_{KL}(q_T\Vert p_S)$。**Prefix 来源与 KL 方向独立**：teacher-prefix 上仍可以测 RKL。固定 bank 风险为：

$$
K_H=\frac1N\sum_{i=1}^{N}\frac1H\sum_{t\in i}D_{KL}(p_S(\cdot\mid s_{it})\Vert q_T(\cdot\mid s_{it})).
$$

| 指标               | 测量                                               | 解释                                 |
| ------------------ | -------------------------------------------------- | ------------------------------------ |
| 绝对风险 K         | 全词表、相同 prefix，单位 nats，固定 H 归约        | 当前还差多少输出行为                 |
| 剩余比例           | $K_t/K_0$                                          | 相对初始差距的吸收；必须伴随绝对值   |
| 窗口改善           | $K_a-K_b$ 及相对下降，预定义 64 步窗口或长预算窗口 | 持续下降、变慢或平台                 |
| 保留 KL 改善       | $(K_0-K_{edit})/(K_0-K_{end})$                     | 更新截断保留多少已学函数，允许超过 1 |
| 消除 endpoint 残差 | $(K_{end}-K_{edit})/K_{end}$                       | 补回是否修复剩余拟合，负数为恶化     |
| 生成正确率         | 同题 greedy 输出，原 grader 与显式答案补充评分并列 | 被吸收行为的任务价值                 |

输出谱另对 teacher/OPD 相对 initial 的 log-probability 变化做 base-Fisher 加权。在 calibration 拟合谱框架，heldout 读取固定 band 与 complement；其能量不等同于 native KL。[完整公式](附录-定义与复算.md#a-native-风险与输出谱)。

### 吸收分组与动态比较

分布吸收同时报告绝对风险 $K_t$、剩余比例 $K_t/K_0$ 与同协议曲线；能力吸收由任务生成另测。主表采用 H1024 的 128 道 heldout，覆盖 14 条件；五个条件剩 2.2%–5.7%，三个剩 9.9%–15.1%，六个剩 22.6%–47.2%。这是观察分组，64 步条件单独标明。

| 数据层        | 实际测量与来源                                                            | 当前使用方式                                                        |
| ------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| H1024 主面板  | 本地历史模型全词表前向；Math64、Code32、IF32；14 条件                     | 本轮从原始逐题 JSON 重算 262 个首遍读数；未新增 GPU 前向            |
| H128 功能面板 | 本地扩展干预评分；每域 calibration4、heldout12                            | 共 36 独立 heldout 题，比较截断／补回／框架恢复；不作为主要好坏分类 |
| 端点参数几何  | 本地 checkpoint 逐矩阵精确 SVD；16 条件全层七投影                         | 完整 W 左右角度、ΔW 谱与全层参数残差                                |
| 首遍阶段几何  | 既有六轨迹全层重叠，加九轨迹新主角分布；新三来源 k/v 全 28 层、中层七投影 | reference≤320；新角度 rank16/64/128，既有重叠 rank8–512             |

H1024 与 H128 使用不同题目和 prefix bank，不是只改变 H 的对照。H 是题内风险的固定分母与截断上限，实际有效 token 不足 H 时不伪造额外位置；同时保留长度信息。每题多个 prefix 或多个位置不增加独立样本量。

首遍历史训练使用 fixed initial-student 轨迹、batch16、reuse16、LR1e−6、weight decay .01，20 批 A–T 共 320 步；DeepCoder 与 Light 当前端点 64 步。只读取每条 run 一个来源中的首遍，不拼接复制快照或后续训练池循环。动态参考点也限制到 320 步以内，不能以更晚权重为 reference 后只裁掉图的后半段。逐题身份、来源哈希及 checkpoint 身份见[首遍附件](data/first-pass-20261112/identities.json)。风险 bootstrap 按题重采样 2000 次、seed20261112，不包含训练 seed 不确定性。

JustRL 的阶段 batch20 与主风险表端点不是同一存储权重；e3 原 lineage 也单列为独立运行，不能将其 frame 值直接配到主表计算逐权重相关。Light 最早空间已在 50% 进度，其他轨迹为 5% 或 20%，不同起点不排列“谁更早锁定”。

下一阶段使用下文 18 组统一方案：Math128/Code64/IF64 共 256 题、双固定 bank、生成与逐 outer 评分均覆盖实际完整响应（cap7168）；FKL 暂不加入当前入口。

### 右子空间的阶段角度与新增更新

后续动力学统一使用右侧输入子空间，旧左右对照保留为历史附件。每个 checkpoint 的累计更新为 $\Delta W_t=W_t-W_0$，独立做 FP64 精确 SVD 并取右前 k 列 $V_{t,k}$。step0 更新为零，不定义其更新 frame。所有参考点不超过 step320；Qwen 三来源的 step320 是分析参考点，训练本身另有更晚保存点。

| 探测         | 计算与对象                                                                          | 读数含义                                           |
| ------------ | ----------------------------------------------------------------------------------- | -------------------------------------------------- |
| 完整主角分布 | $\cos\theta_i=\sigma_i(V_{a,k}^{\top}V_{b,k})$                                      | 小角度对应相近空间；保存全部角度，主图给平均与 p90 |
| 两两阶段热图 | 每对已保存 checkpoint 独立算角度                                                    | 区分方向逐渐移动、突然改变和阶段稳定               |
| 参考终点重叠 | $\mathrm{Sim}=k^{-1}\sum_i\cos^2\theta_i$                                           | 与 2606.07082 同定义；另报随机基线 k/d 及调整值    |
| 后续增量捕获 | $D_{a:b}=W_b-W_a$，计算 $\Vert D_{a:b}V_{e,k}\Vert_F^2/\Vert D_{a:b}\Vert_F^2$，e≤a | 检查早期空间能否解释之后新进入的更新               |
| 相对最优捕获 | 上项除以 D 自身的最优 rank-k 能量比例                                               | 区分 rank 太小与方向不匹配；不是任务收益           |
| 完整权重主角 | 完整 W 相对 initial 的右 top-k 主角                                                 | 对应 2511.08567；与ΔW 动态分别呈现                 |
| 谱的辅助量   | stable rank、rank90、k 处相对谱隙与绝对更新能量                                     | 检查角度变化是否伴随谱形状变化或边界方向近简并     |

累计更新的空间重叠会受早期历史积累影响，不能代替后续增量捕获。主角对空间内部换基和奇异向量符号不敏感；若 rank 边界奇异值接近，主空间角度可能放大弱方向差异，需与捕获能量、多个 rank 共同解释。矩阵统计取层中位数，28 层不是 28 个独立模型或训练 seed。

Qwen 三来源共同 initial 为 Qwen3-1.7B、teacher 为 Qwen3-4B-Instruct-2507，训练 rollout 分别来自 current／initial／teacher；三个条件各取 16/32/48/64/80/128/160/240/320 步。batch64、每批 reuse16，与旧 fixed-S0 的 batch16 协议分开。k/v 全 28 层，中层第 13 层补 q/o 及 gate/up/down；完整 W 角度只在中层七投影计算。跨尺寸 teacher 不参与参数差分，只在输出风险中使用。

### 下一轮训练的 checkpoint 保存建议

只在完整 outer 结束后保存，不增加批内 optimizer-step 触发。计划 40 个 outer，每 outer 为 64 道题的一次 current rollout、同批 16 次更新；每条训练 9 份新增 model-only 快照，加共享 initial 引用，共 10 个分析节点：

| outer          | 0   | 1   | 2   | 3   | 4   | 8   | 12  | 20  | 30  | 40  |
| -------------- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| optimizer step | 0   | 16  | 32  | 48  | 64  | 128 | 192 | 320 | 480 | 640 |

前 4 个 outer 密集保存，后期逐渐稀疏；step320 与现有首遍比较对齐，480/640 保留末段。这个方案不能识别最初 1–4 次更新内部的形成过程，研究问题相应限定为第一完整 outer 之后的动态。step0 只引用原资产，final-model 计入 9 份新增快照，不重复保存最终权重。

固定 bank RKL 每个 outer 计算，模型只在上述 outer 导出；两项 schedule 独立。全层 SVD 离线读取快照，不进入训练热路径。逐更新 loss、梯度/更新范数、token 与耗时继续记录。快照保存 FP32 master 并做现有 native 重载 RKL 校验。现有统一 evaluation 要求 fresh run、model-only 导出，尚不提供这条路径的滚动 optimizer 恢复；不把模型快照称为完整恢复 checkpoint，也不承诺仅配置即可启用恢复槽。

### 候选复训面板与共同设置

本轮固定 18 个 pair（E94–E111）、单 seed42，仅计算固定 bank RKL，不测 accuracy。主问题是 student 自身的更新 frame 如何随输出拟合变化，因此允许 teacher 与 student 尺寸不同。所有动态计算使用 $\Delta W_t=W_t-W_0$，两项均来自同一个 student；跨尺寸 teacher 仅提供输出目标，不参与参数差分。训练仍需通过 token-ID 语义、完整词表支持、共同 prefix、context 与模型执行兼容检查；hidden width 和层数不同本身不构成障碍。

训练 current rollout 与评估 prefix 来源分开。Heldout 不在每个 checkpoint 重新生成：固定 Math128/Code64/IF64 共 256 题，按 initial 与 teacher 各生成一条轨迹，冻结 token/mask 后反复前向评分。新面板全部重新 rollout，不导入旧 bank 的回答。response cap7168、prompt cap4096、T=1、top-p=1、top-k=−1、seed42；按同一 pair 的 student 输入模板构造共同 token prefix，保留有效 mask、停止原因与完整 token。相同 initial、模板、题单和采样协议的 pair 共享本轮新生成的 initial-bank；teacher-bank 按 teacher 与输入协议身份分别生成，避免重复采样相同资产。跨 pair 的停止集合需记录其 token 语义；不将 sampler 参数相同误称为完整生成协议相同。每个读出对全部实际有效 response 位置评分，上限 7168；不再切成 H1024 主面板。主指标为逐题有效 token 均值，再按域／固定题权重汇总，报告分域绝对 RKL 与相对初始变化。早终止不补零 token，空回答单列为无有效评分；禁止把完整轨迹 KL 累和÷1024 标为 H1024 风险。固定 bank 回答“同样状态上输出是否靠近 teacher”，不能称为每阶段 current 状态上的期望风险。

常规主曲线改为**outer0 基线及每个 outer 结束都测 initial/teacher 双 bank**，不拆分来源频率。现有`banks` schedule 原本就一起评分两个来源，配置`every: 1`即可；snapshot 通过`export_outers`独立配置。按每来源 256 题、41 个节点，每 pair 为 20992 条 checkpoint-trajectory 评分，有效 response 位置上限为 150470656（约 1.50 亿）；18 组累计 377856 条评分，上限约 27.08 亿位置，实际随提前结束减少。它们是固定输入的前向评分，不是每轮重新生成回答。acc、bench current 生成与 source/history 附加评分均关闭。

现有 score_native_rows 逐 window 执行 teacher forward 和 student full-vocab 评分，**没有跨 outer 持久 teacher logits 缓存**。本轮直接沿用该实现，不为缓存增加新执行路径。当前读出产物为 RKL；FKL 虽可利用相同 logits 计算，但现有这个入口未输出 FKL，先不把它列入零改动计划。

主训练复用 verl.trainer.main_ppo、v1 sync/shared_sync、现有FSDP2/current-rollout与precompute_fused full-vocab 链路，固定 bank 评分和模型导出复用 verl.trainer.evaluation。18 pair 脚本只负责 pair 注册、输入身份、主线配置与 broker/guard 队列，不复制 loss、生成、评分或优化循环。four_gpu.py 带 Qwen、旧 bank、设备和 outer 节点硬编码，是已验收示例，不能直接把其固定实验身份套到 18 pair。

统一 evaluation 已提供`accuracy_enabled: false`：bootstrap 不启动判分 worker，不生成或要求 initial-accuracy/teacher-accuracy；outer0、周期边界与终点都不输出 accuracy 或 gap recovery。开关默认 true，保留旧实验行为。它与 current-prefix RKL 独立：18 pair 的固定 bank 方案还需设置`bench: {at: [], final: false}`，避免周期及终点重新生成 current heldout；`banks: {every: 1}`维持逐 outer 双 bank 评分。该改动只涉及评估组件，训练 loop 与 outer 内部更新保持原样。接口说明见[统一评估](../../../../../../verl/trainer/evaluation/README.md#独立关闭-accuracy)。

若 $V_{a,k}$ 是早期累计更新的右框架，后续增量捕获率定义为：

$$
C_{a\to b:c}(k)=\frac{\|I_{b:c}V_{a,k}\|_F^2}{\|I_{b:c}\|_F^2},\qquad a\le b<c.
$$

同时报告该增量自身最优 rank-k 捕获率 $C^*(k)=\sum_{i\le k}\sigma_i(I)^2/\|I\|_F^2$ 及 $C/C^*$。高捕获率需要与最优上界、rank 和输入维度一起解释。不同 checkpoint 间隔的 optimizer 更新数不相等，图中保留间隔，不能把增量能量直接当作每步变化速度；零增量没有可解释的方向或捕获比例。

同一环境维度 $d=n$ 中，独立均匀 k 维子空间的期望重合度为 $k/d$。实际重合度报告随机基线及调整值；$k=d$ 时调整值无定义，标记完整输入空间。对于矩形矩阵，$k=\min(m,n)$ 的 top-k 能量比例必为 1，但当 $k<n$ 时右子空间重合度仍不必为 1。谱隙很小时，截断边界的 frame 可随微小扰动变化，结合能量捕获率解释角度。

聚合先保留逐层、逐投影、逐 rank 的值，再画 layer×stage 热图和 Attention／MLP 分面；浅中深层按各模型实际层号与相对深度显示。矩阵中位数描述典型矩阵，pooled 范数和残差由能量／内积先求和再归一化。一个 pair 是一个训练条件，不能把层数或矩阵数当作独立训练重复。Math 与 avg 分类分别展示，避免将跨域残差归因于数学更新完全无效。

这组测量是观察性 checkpoint 分析，能够检验“更新空间更稳定”等关联，不能单独建立 frame 稳定导致吸收更好的因果关系。不包含投影后继续训练、谱交换或新的 acc 评估。实现和可执行命令见[统一轨迹分析入口](../../../../research/studies/spectral/README.md#本轮统一-checkpoint-几何入口)。

Bank 直接复用主线`verl.trainer.evaluation.bootstrap`的 initial／teacher／finalize 入口和`NativeGenerator`。已有跨数据集有界请求流、least-inflight 路由、分块 Parquet 发布、失败排空、匹配身份的生成恢复，以及独立 accuracy 开关；不另写生成服务。配置 datasets 的 n=1，避免沿用 accuracy 的多回答预算；bank 并发与引擎序列上限、chunk 发布大小独立配置。当前启动 resolved config 可能沿用独立 accuracy 的大 context，需要显式核对本轮 4096+7168 预算，避免为不用的 32K 上下文预留资源。完整长评分复用现有 hidden 窗口分批，优先检查 payload 与 host 拷贝峰值；旧约 6 秒仅是 H1024 实测，不能作为本轮逐 outer 评估耗时。

### 参数谱：分解什么矩阵

默认矩阵范围是**所有层**的 q/k/v/o 与 gate/up/down 二维投影，排除 embedding、head、norm、MTP。每个矩阵独立做 thin SVD，不把整个模型拼成一个巨型二维矩阵。矩阵为 $m\times n$ 时，q=min(m,n)，完整 thin 框架维度为 m×q 和 n×q。

先区分三种矩阵，避免把它们的 rank 混在一起：

| 分解对象     | 一个矩阵的含义                                          | 奇异值和奇异向量描述什么                 |
| ------------ | ------------------------------------------------------- | ---------------------------------------- |
| 完整权重 W   | 某层某个线性投影，如 q_proj                             | 当前线性映射的增益与输入/输出方向        |
| 参数增量 ΔW  | 同一投影在两个 checkpoint 之间的差                      | 训练改变了哪些参数方向、改变有多集中     |
| 输出变化矩阵 | 固定状态上的 log-probability 变化，另按 Fisher 度量加权 | 不同状态的输出变化能否用少量共同方向表示 |

完整权重的左右奇异向量 U、V 合称**奇异框架（frames）**，Σ 是奇异值。对输入 x，$Wx=U\Sigma(V^\top x)$：V 定义输入方向，Σ 调整各方向的增益，U 定义输出方向。换谱与换框架分别替换这两个部分。

例如，一个 2048×2048 的更新矩阵，rank16 能量是它前 16 个奇异值的平方和除以全部平方和；top1% 截断则保留 ceil(2048×.01)=21 个分量。它们既不是前 16 层，也不是把全模型只保留 16 个方向。

| 对象/指标             | 定义                                                              | 聚合方式                                                        |
| --------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------- |
| 完整权重谱            | $W=U\Sigma V^\top$                                                | 每矩阵精确 FP64 SVD；保存精度权重提升 FP64                      |
| Teacher/student更新谱 | 对 $\Delta_T$、$\Delta_S$ 分别 SVD                                | top16 为前 16 奇异值平方和÷全部平方和；不同于完整 W 的 top16    |
| 全层更新相对范数      | $\sqrt{\sum_\ell\|\Delta_\ell\|_F^2/\sum_\ell\|W_{0,\ell}\|_F^2}$ | 先汇总平方能量再开方                                            |
| 完整谱距离δΣ          | $\|\sigma(W)-\sigma(W_0)\|_2/\|W_0\|_F$                           | 每矩阵算比值后报告中位数                                        |
| 谱占参数位移ρΣ        | $\|\sigma(W)-\sigma(W_0)\|_2/\|W-W_0\|_F$                         | 范数比；pooled 先汇总分子/分母平方再开方                        |
| 对角富集κ             | $\frac{mn}{q}\|\Delta_{diag}\|_F^2/\|\Delta\|_F^2$                | Base 框架坐标内的一阶量；各向同性参考 1                         |
| 参数残差能量          | $\sum\|\Delta_T-\Delta_S\|_F^2/\sum\|\Delta_T\|_F^2$              | 与函数风险独立，允许大于 1                                      |
| 子空间重叠            | $\|V_a^\top V_b\|_F^2/k$                                          | 同矩阵左／右 top-k 空间分别计算；符号及内部换基不影响 projector |

阶段比较还同时保存 top-k 能量、绝对更新能量和参数幅度。独立均匀 k 维随机空间的期望重叠是 $k/d$，基线调整后为 $(S-k/d)/(1-k/d)$；当 k=d 时空间已经饱和，不把必然为 1 的重叠解释成锁定。

令 $a=\Vert\Delta_S\Vert/\Vert\Delta_T\Vert$、$c=\langle\Delta_S,\Delta_T\rangle/(\Vert\Delta_S\Vert\Vert\Delta_T\Vert)$，参数残差比满足 $R_{\rm param}=1+a^2-2ac$。它衡量参数位置；RKL 衡量给定状态上的输出分布；生成得分衡量任务效用。三者分别报告。

完整权重精确扫描有 16 条件、1036 个去重 base 矩阵任务，按共享 base 复用。较早的 18 配对 3808 矩阵测的是范数/内积几何；中层新增五模块 rank16 使用两 seed 随机近似。三类覆盖不混为同一精确 SVD 实验。矩阵中位数描述典型矩阵，不能代替全模型能量比例。

### 四种关键干预

| 操作                 | 改变的对象                                          | 固定的内容                            | 要判别什么                 |
| -------------------- | --------------------------------------------------- | ------------------------------------- | -------------------------- |
| 更新 top1%/5% 截断   | 对 $\Delta_S$ 保留 ceil(.01q)/ceil(.05q) 个奇异分量 | Initial W；原幅度与恢复更新范数分别测 | 已学函数可压缩性和幅度作用 |
| ISO 恢复完整 base 谱 | $U_1\Sigma_0V_1^\top$                               | Endpoint 奇异框架，非编辑参数         | 行为依赖奇异值漂移多少     |
| ISO 恢复 base 框架   | $U_0\Sigma_1V_0^\top$                               | Endpoint 奇异值，非编辑参数           | 框架移动是否必要           |
| Missing off/null补回 | $W_S+\beta(M_t)_{off/null}$                         | Endpoint 其余参数                     | 遗漏的真实方向能否改善拟合 |

Base thin-SVD $W_0=U_0\Sigma_0V_0^\top$ 下，令 $C=U_0^\top XV_0$。diag 是 C 的对角部分回投，off 是 C 的非对角部分回投，null 为 $X-U_0CV_0^\top$。它们是正交坐标分解，off 不等于精确有限旋转；方阵满框架 null 为结构零。

Own-update 删除使用 $W_X-(W_X-W_0)_{off}$，X 可为 teacher 或 student；它与 missing 补回作用于不同矩阵。随机控制逐矩阵匹配 Frobenius 范数；同谱随机框架还保留全部奇异值，仅改变方向。

### 响应、局部对齐与 PAC 传播

JVP 测固定单位参数方向经过 student Jacobian 后引起的输出变化；Gaussian 和同谱随机框架逐矩阵匹配范数。精确方向导数 $\langle\nabla L,d\rangle$ 为负，表示沿正 d 的无穷小位移降低风险；β=1 的有限干预还包含曲率与多层交互。

PAC 以完整题目轨迹为单位。令 $b_{it}=\nabla_{z_{it}}\ell_{it}$ 为 logit 请求，$J_{it}=\partial z_{it}/\partial\theta$，固定 H 归约后：

$$
g_i=\frac1H\sum_tJ_{it}^{\top}b_{it},\qquad
P=\mathbb E_i\frac1H\sum_t\|b_{it}\|^2,\qquad
A=\frac{\mathbb E_i\|g_i\|^2}{P},\qquad
C=\frac{\|\mathbb E_i g_i\|^2}{\mathbb E_i\|g_i\|^2}.
$$

P 是请求能量，A 是单位请求形成的题梯度能量，C 是题间聚合后保留的平方能量比例。$q=(P/L)AC$ 是固定目标、欧氏梯度流下的相对局部下降速度。真实 Adam 更新另用保存的参数位移测对齐与 test 风险；局部一致性中的 $C_d$ 使用绝对标量，不与 PAC 的 C 混用。[完整推导](附录-定义与复算.md#指标与比较口径)。

## 统计与数值条件

β仅在 calibration 的{0,.25,.5,1}中选择，两个 bank 等权 RKL；heldout 同时报告该选择与预定义固定条件，FKL 不重新选β。区间以题目配对 bootstrap 为主，B8 传播面板使用 cluster bootstrap；训练 seed 的不确定性单独报告。探索性多重比较的范围与校正写在相应结果处。

无编辑重载、teacher-self matched execution、矩阵重构与精确导数差分先验收。ISO α=1 与旧 matched 评分最大误差要求≤1e−6；teacher-self 同阈值。三组原补回导出重载 gate 通过。所有谱编辑由原始 tensor 重新构造，tied 参数只编辑一次。完整矩阵范围、来源与验收见[附录](附录-定义与复算.md)。
