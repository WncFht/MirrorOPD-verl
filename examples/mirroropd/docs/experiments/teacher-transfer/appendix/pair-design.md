# 教师吸收的研究问题与师生配对设计

本文把已有实验整理为可验证的问题，并选择能区分训练谱系、后训练阶段和尺寸影响的 student–teacher pair。表中 `student → teacher` 表示从左侧权重初始化学生、拟合右侧冻结教师；模型的训练来源另行说明。已有结果沿用固定 S0、H1024、0–320 更新的历史条件；新增配对均为建议，未启动训练。

当前证据支持：直接从学生继续后训练的教师通常更易拟合；同尺寸远分支和跨尺寸配对保留更大残差。现有实验尚未分别识别 SFT／RL 方法、教师更新幅度、数据和初始化的作用，也未证明全局完全吸收或异构必然不可吸收。

## 1. 问题中的变量

### 1.1 同构、同源与异构

| 配对关系             | 控制条件                                                                        | 当前代表                                      |
| -------------------- | ------------------------------------------------------------------------------- | --------------------------------------------- |
| 直接后训练           | teacher 从 student 的公开型号继续训练，结构与尺寸一致；精确父 revision 仍须核验 | Qwen3-1.7B → e3／Samsung Math SFT             |
| 同一 Base 的不同分支 | 结构与尺寸一致，但双方经历不同后训练                                            | Qwen3-1.7B → Thinking-Space SFT／GT-Base-MATH |
| 同家族跨尺寸         | tokenizer 可兼容，尺寸、预训练权重与表示不同                                    | Qwen3-1.7B → Qwen3-4B；R1-7B → R1-1.5B        |
| 跨家族或跨架构       | 结构、预训练谱系或 tokenizer 进一步变化                                         | 当前主比较没有足以验证这一类普遍结论的配对    |

“同一个 Base”有两种含义。若指同一份精确初始权重，则双方属于同结构、同尺寸的谱系，可以研究不同后训练分支的影响。若指 Qwen3-1.7B-Base 与 Qwen3-4B-Base，则仅为同家族 Base，不能称相同 basemodel。

因此，“异构但保证 Base 一样”应拆成两项：共同精确 Base 能否消除异分支的拟合困难；真正跨尺寸时，在拟合教师 Base 的基础上，能否继续吸收其 SFT／RL 增量。

### 1.2 SFT 数据与后训练的区别

SFT 本身属于后训练。归因时要分别控制：教师的预训练起点、教师后训练使用的数据、教师后训练方法和预算，以及学生蒸馏时使用的问题与轨迹。同一个模型家族名不能控制预训练差异，同一个数据集名也不能保证具体子集相同。

这里的“吸收 SFT／RL”默认指用统一蒸馏方法拟合经 SFT／RL 得到的教师。它与“直接对学生做 SFT／RL”是两类实验。

### 1.3 吸收的观察范围

分别报告训练状态拟合、同域新题泛化、跨域泛化，以及教师前缀上的覆盖。固定 S0 上残差下降，不能单独证明自生成行为或完整回答分布被复制。后续读出遵循[四域 RKL 协议](../protocols/online-four-domain.md)，不另设“完全吸收”的数值门槛；任务能力另按后续确认的低频评测安排判断。

## 3. 研究问题与主要配对

### 3.1 同构情况下的 SFT 与 RL 吸收

研究问题：在相同 student 初始化下，直接后训练的 RL 和 SFT 教师分别能被拟合到什么程度；差异能否由教师更新幅度、数据和优化预算解释。

| 用途            | Student               | Teacher                  | 状态与选择理由                             |
| --------------- | --------------------- | ------------------------ | ------------------------------------------ |
| 同源 RL 主对照  | Qwen3-1.7B            | e3-1.7B                  | 已有 320；公开谱系为当前型号继续 RL        |
| 同源 SFT 主对照 | Qwen3-1.7B            | Samsung Qwen3-1.7B-Math  | 已有双模式 320；公开谱系为当前型号继续 SFT |
| RL 复核         | R1-1.5B               | DeepScaleR／JustRL       | 已有 320；覆盖不同残差水平                 |
| Llama 复核      | Llama-3.2-3B-Instruct | GT-MATH／arithmetic-full | 已有 320；SFT 数据披露与镜像身份限制保留   |

Qwen 两组作为主要现象对照，R1／Llama 用于检查现象能否复现。公开教师的训练配方不受控，所以当前只能比较这几个目标，不能直接得出 RL 普遍比 SFT 更易吸收。

要识别方法因素，须从同一精确父权重分别构造 SFT／RL 教师，保存若干早晚 checkpoint，控制任务问题池与输入协议，并分别按训练计算量和实测目标变化幅度比较。SFT 的答案监督与 RL 的奖励监督应明确记录；二者不能仅凭共享题目就称全部信息相同。这属于后续受控教师构造，不包含在当前开训安排中。

区分数据与方法还需要两个交叉控制：固定 SFT 配方、更换教师数据；固定任务问题池、分别构造 SFT 与 RL 教师。前者检验数据来源，后者检验训练路径及监督方式。两类控制均保持父权重一致，并覆盖相近的目标变化幅度；只比较 Samsung SFT 与 e3 无法完成这项归因。

### 3.2 共同 Base 与不同后训练分支

研究问题：当 student 和 teacher 的结构相同，当前困难主要来自教师目标本身，还是来自 student 已走向另一条后训练分支。

令 `B = Qwen3-1.7B-Base`，`I = Qwen3-1.7B`。优先补齐下表，而非继续增加相近教师。

| Student 初始化 | SFT teacher：Thinking-Space Qwen3-1.7B-SFT        | RL teacher：GT-Qwen3-1.7B-Base-MATH                    |
| -------------- | ------------------------------------------------- | ------------------------------------------------------ |
| B              | **新增配对**：直接从公开 Base 型号拟合其 SFT 后继 | **新增配对**：直接从公开 Base 型号拟合其 RL 后继       |
| I              | 已有：从另一后训练分支拟合同一 SFT teacher        | 已有 non-thinking：从另一后训练分支拟合同一 RL teacher |

同一 teacher 固定时，更换 B／I 初始化，比较拟合速度、绝对残差和跨域改善。如果 B 明显更易拟合，支持初始化谱系影响训练难度；如果 B 同样困难，则继续检查数据覆盖、教师更新幅度和优化。只有精确父权重已核验时，才能把 B 组称为严格直接后继对照。

新实验须共享题目，并在一个预先固定的共同银行上交叉评分；各初始化自己的 rollout 另列。只比较 B 自己的银行与 I 自己的银行，会同时改变初始化和评估状态。训练也需加入共同固定前缀控制，才能把初始化影响与训练访问分布影响分开。新预算结果与已有 320 结果分别报告。

该矩阵能区分初始化因素；Thinking-Space 与 GT 的数据和算法不同，不能用横向两列差异单独识别 SFT／RL 因果效应。

### 3.3 跨尺寸中的 Base 差距与后训练增量

研究问题：跨尺寸 student 难以拟合的是 teacher 原有 Base 分布，还是新增 SFT／RL 行为；教师本身的后训练是否已经难以从同尺寸 Base 学回。

| Student                | Teacher 集合                                  | 状态与作用                                                     |
| ---------------------- | --------------------------------------------- | -------------------------------------------------------------- |
| Qwen3-1.7B             | Qwen3-4B-Base                                 | **新增配对**；为已有 SFT／RL 教师补上共同 Base 目标            |
| Qwen3-1.7B             | 4B Math-CoT SFT step80／step640；4B-Base-GRPO | 已有三组 320；观察跨尺寸对不同后训练目标的响应                 |
| Qwen3-4B-Base          | 同一组 step80／step640／Base-GRPO             | **新增三组配对**；固定 teacher，比较同尺寸直接谱系与跨尺寸拟合 |
| 4B Math-CoT SFT step80 | 同一 run 的 step640                           | 备选新增配对；隔离晚期 SFT 增量，避免每次都从 Base 学完整 SFT  |

4B-Base 是否已在本地及能否作为 student 运行，需另行验收；本提案不把新初始化写成已完成训练。step80／step640 来自同一 SFT run，身份已固定；GRPO 为另一项目，仍不是与 SFT 同数据、同预算的对照。

比较时同时保留“教师终点拟合”与“教师阶段变化跟随”两种观察。对相同的小 student 分别蒸馏 Base 与 post-trained teacher，在共同前缀上比较两个 student 的 token 偏好变化是否跟随教师的对应变化。已有[Tulu 阶段偏好诊断](../post-training-stages.md#stage-curves)可作为方法参考，但投影系数不能称阶段吸收百分比。

两个 teacher 的终点 RKL 差不能直接拆成“Base 残差＋SFT／RL 残差”。KL 的两个参数均随实验分支变化，不具有这种加法归因。严格研究方法效应仍需受控教师。

### 3.4 相邻阶段的直接吸收

研究问题：已经拥有上一阶段行为时，下一阶段的增量能否被吸收；已有跨尺寸终点差距是否掩盖了这件事。

| 阶段     | 建议 Student → Teacher            | 已有材料与缺口                                     |
| -------- | --------------------------------- | -------------------------------------------------- |
| Base→SFT | Llama-3.1-8B Base → Tulu-3-8B-SFT | teacher 已有；Base student 身份与接口待验收        |
| SFT→DPO  | Tulu-3-8B-SFT → Tulu-3-8B-DPO     | 两份权重已有，师生配对未做；单列偏好优化阶段       |
| DPO→RLVR | Tulu-3-8B-DPO → Tulu-3-8B 最终版  | 两份权重已有，师生配对未做；直接隔离最终 RLVR 阶段 |
| Base→RL  | Llama-3.1-8B Base → SimpleRL-Zoo  | 可选复核；与 Tulu 不同项目、数据和输入条件         |

优先补 DPO→RLVR，直接回答已有跨尺寸 Tulu 结果尚不能回答的 RL 增量问题。若需要在同一家族覆盖完整阶段链，再补 Base→SFT 和 SFT→DPO。DPO 与 RLVR 分开解释，不合并为一个未经区分的 RL 标签。

### 3.5 异构边界与容量解释

“异构是否都不能吸收”是普遍命题；一个可靠反例就能推翻它，有限负例不能证明它。更可执行的问题是：哪些尺寸方向、初始化和目标变化下残差更大，增加覆盖或改变起点能否消除差距。

现有 R1 小教大两组可与小学生学习大教师的结果构成方向对照，但双方不是镜像实验，需保留各自状态银行、支持与预算。Polaris-7B 分别由 R1-1.5B 和 R1-7B 学习则固定了 teacher，可用于检查近源同尺寸初始化的作用；两组需在共同预算节点比较，不能直接用 64 对 320 排名。

真正的跨家族架构效应尚缺对照。若扩展到 tokenizer 不同的配对，应先定义共同输出事件和可比目标；逐 token ID 的原生 full-vocab RKL 不能直接跨词表使用。当前优先补齐已有兼容谱系中的控制。

## 4. 不能充分吸收的原因与判别实验

当前最直接的观察是：部分 teacher 的当前训练状态仍能改善，独立状态的改善却已明显减弱。原因须通过干预区分。

| 候选原因                 | 已有证据                                                               | 下一项能区分解释的控制                                                                      |
| ------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 数值、输入模板或输出支持 | 模式改变会显著影响结果；R1 小教大与 Tulu 有支持差异                    | 同输入／精度的重复评分、同结构 teacher-copy；单列支持与模板条件                             |
| 优化路径或有限预算       | Qwen 同尺寸六组均有更低风险的 teacher-copy 可行参数点                  | 固定数据覆盖改变优化预算；固定更新预算改变覆盖，分别报告计算量                              |
| 数据覆盖与泛化           | Polaris 已见状态可明显拟合，新状态收益较弱；扩大覆盖有效但尚未消除残差 | 同一 pair 做旧题复用、新题固定 S0、新题 current rollout 控制                                |
| rollout 状态变化         | 固定状态改善与 fresh 状态变化可互相抵消                                | 同一题目上的初始／最终参数 × 初始／最终轨迹交叉评分；属于额外诊断，不自动加入新协议         |
| 初始化与后训练分叉       | 当前直接 RL 教师近，Base 分叉教师较远，方法与距离混杂                  | 第 3.2 节 B／I × SFT／RL 矩阵；同一 teacher 只改变初始化                                    |
| 共享可泛化修正较弱       | Polaris 后期 loss-gradient Gram 更分散、留出梯度投影较低               | 同参数／同状态上测实际 Adam 位移对独立风险的影响，再比较局部线性与全参数拟合                |
| 表示或模型容量限制       | 大学生学小教师仍有残差；同尺寸组存在更好可行参数                       | 固定 teacher 比较同尺寸、跨尺寸与初始化；训练拟合匹配后再比较留出，避免把优化失败称表达上限 |
| 教师 SFT 数据或训练方法  | SFT 早晚 checkpoint 难度不同，但公开 RL／SFT 配方混杂                  | 同精确父权重，分别控制数据、方法和教师更新深度；仅换一个公开模型无法完成归因                |

Qwen 的[teacher-copy 与参数距离分析](qwen-lineage-evidence.md)表明：后四个同尺寸目标存在远低于当前训练终点的可行风险，因此当前残差不能直接归因于架构不可表达。copy 参考仍受加载与数值路径影响，不是普遍理论下界。

[跨批次实验](../cross-batch-transfer.md#batches)中，Polaris 在已观察边界上的旧批保持并未退步，重排同一题池也未明显解除独立留出平台；这削弱了“只是旧批遗忘”或“只是连续 reuse”的充分解释。[谱诊断](../mechanisms/spectral.md)支持后期共享修正较弱，但测到的是 teacher-conditioned loss-gradient Gram，不能直接当作学生 NTK 或缺失 feature 的证明。

[能力筛选实验](../mechanisms/capability-filter.md)已展示 RKL 可以记住随机映射而不泛化。因此，“OPD 自动过滤所有不能迁移的信息”不符合已有实验。表示缺失、预训练数据差异和容量上限仍是待验证解释。

## 5. 推荐的补齐顺序

以已有 Qwen3-1.7B → e3／Samsung SFT 作为同源 RL／SFT 参照，优先补齐以下六个配对：

| 次序 | 新增配对                             | 解决的主要缺口                         |
| ---- | ------------------------------------ | -------------------------------------- |
| 1    | Qwen3-1.7B-Base → Thinking-Space SFT | SFT 残差是否依赖从另一后训练分支初始化 |
| 1    | Qwen3-1.7B-Base → GT-Base-MATH       | 同一初始化问题能否在 RL 目标复现       |
| 2    | Qwen3-1.7B → Qwen3-4B-Base           | 跨尺寸原有 Base 差距缺少目标对照       |
| 2    | Qwen3-4B-Base → Math-CoT SFT step80  | 同一早期 SFT teacher 的同尺寸参照      |
| 2    | Qwen3-4B-Base → Math-CoT SFT step640 | 同一晚期 SFT teacher 的同尺寸参照      |
| 2    | Qwen3-4B-Base → 4B-Base-GRPO         | 同一 RL teacher 的同尺寸参照           |

这六组分别补初始化矩阵与跨尺寸阶段矩阵。Tulu-DPO → Tulu-RLVR 作为下一项独立复核；R1 与 Llama 原有组用于检查结论是否跨谱系成立。上述优先级依据现有残差和缺失控制制定，属于看过历史结果后的设计，不称预注册。

配对数与运行数分别计算。一个 pair 的 thinking／non-thinking、固定／刷新 rollout、四个单域训练都属于不同运行条件。若六对全部做四域即为 24 个训练分支，本提案不默认展开该预算。新实验的 batch、reuse、题量、评估银行和归一化待定项统一遵循[四域 RKL 协议](../protocols/online-four-domain.md)，不把旧 320 更新直接当作新设置的等预算对照。

教师公开型号谱系已知不等于精确父 revision 已验证；新增 student 身份、共同输入和数值验收完成前，配对仍保持建议状态。已有固定模型版本复用原注册表，不在此维护第二份 revision 清单。

<a id="mechanism-8-下一步的优先级与判别实验"></a>

## 迁移差距的诊断候选

当前优先执行已经定下的[双来源 Rollout 四分支重跑](../mechanisms/双来源待执行协议.md#protocol)：每 teacher 分别用 S0/T 训练，完整评估双来源、同题新轨迹与当前学生自由生成。该实验等待用户通知有卡；下列 P0–P3 保留为其后的研究方向，均未因本次文档整理启动。

已完成证据最接近“共享下降方向在后期减弱，剩余误差更依赖具体 state 上的概率修正”。“同源已有可用 feature、异源需学习更深 feature”仍是可检验假设：尚无表示层语义、线性可解码性或目标变化低维性的直接测量，不能把梯度统计当成证明。

<a id="mechanism-p0在真实后期参数上测实际更新的迁移而非只测-raw-gradient"></a>

### P0：在真实后期参数上测实际更新的迁移，而非只测 raw gradient

先取得 E48 一个早期与一个后期 checkpoint 及其 optimizer 状态，另取 E20 作同源参照；若只能恢复权重，所有分支统一重置 Adam 并单独标识。冻结互斥的训练、诊断和最终测试 prompt，覆盖 S0、当前 student 及 teacher 三种来源；保留完整训练长度与位置分层。

对同一次实际 AdamW 更新记录参数位移 $\Delta\theta$，在各验证组测 $g_H^\top\Delta\theta$ 及真实 $R_H(\theta+\Delta\theta)-R_H(\theta)$，再定期测无约束 fresh $J_H$。小步时二者应近似一致；若研究“训练 B 时 A 为何改善”，从同一参数与 optimizer 状态分叉 A/B/新批，并加入零新梯度但保留动量的控制；再用统一 fresh optimizer 重复，区分当前批信息与历史动量。若 raw cosine 低而实际投影良好，不能继续把 raw 噪声当主因；如果投影与有限步下降长期脱节，再检查曲率、数值或预条件。设置早/晚、旧已见/新未见、同题新轨迹/新题三组正交对照，避免把这些变化合在一起。

已有独立的[优化器与精度对照](../../../infra/numerics/optimization/README.md)，P0 应复用其中对工作权重、算术和读出的检查，不重复冷启动步长搜索；那组实验未计入本总览 S/I/B/N 的统计。

L 已补上本机 20 批过程中的 40 个真实首步投影与有限变化，但本机实验仍不等于 E48，且首步不代表整个 16 步区间。先测方向和实际下降，再决定哪类训练改动值得放大。

<a id="mechanism-p1以独立覆盖和-cache-刷新为主变量验证-state-分布反馈"></a>

### P1：以独立覆盖和 cache 刷新为主变量，验证 state 分布反馈

保持 teacher、有效 batch64、reuse16、LR1e-6、prompt 顺序、H7168、T=1 及不截断采样的协议固定，先对 P 比较三个生成器方案：固定分支起点学生快照（冷启动时即 S0）、每 2 个 outer 刷新一次快照、每 outer 当前学生。每个快照生成对应的新 prompt 批，随后各 reuse16；这样 64 更新的 4 个 outer 中，三种方案确实有不同的策略陈旧程度，且独立 prompt 数与训练访问数一致。后期分叉的固定 cache 由该后期起点生成，避免将“冻结”与“沿用很旧的 S0 state”混在一起。J 保留在线与固定 cache 参照，候选效果可重复后再扩到多个 seed；这是一组拟议实验，尚未执行。

每个方案报告新生成 token、独立 prompt/轨迹数、训练访问 token 和更新数，另给同处理量分析。固定 cache 也应覆盖完整推理阶段，不能只截前 1K。周期刷新一次只变一个刷新间隔；混合旧/新 cache 作为后续第二阶段，避免同轮同时改变来源、覆盖和 reuse。固定 teacher cache 的长程配对诊断已列入[双来源重跑协议](../mechanisms/双来源待执行协议.md#protocol)，以确认来源依赖，尚未作为已证实的修复。

判别标准是固定多来源风险、无约束 fresh 风险和任务表现共同看：固定 cache 若改善 fresh 而在线只改善旧 state，更支持访问反馈；新题有效而同题更多 rollout 收益弱，更支持 prompt 覆盖；各方案都只拟合训练 state，则转向 P2 的共享表示与目标可实现性。依据诊断选择策略之后，必须在未参与筛选的最终测试集验证。

<a id="mechanism-p2直接检验共享参数修正与表示限制"></a>

### P2：直接检验共享参数修正与表示限制

在同一初始/后期学生参数和相同 state 银行上，比较 J/P 要求的概率修正是否能由一组共享参数方向解释。先做低成本分层诊断：同一完整梯度拆成 head 与各层块，测训练/留出方向及一步实际影响；这能定位差异，但不能单独证明语义 feature 缺失。

若差距稳定，再对比冻结 backbone 的 readout 拟合、局部线性化的参数响应与全参数非线性更新，使用 matrix-free JVP/VJP避免构造完整Jacobian。各方法按达到的训练风险和实际参数位移对齐，同时评未见state；仅比较相同步数或参数数量会混入容量/优化预算。全参能拟合训练但线性化/非线性都不迁移，指向覆盖或目标复杂性；非线性更新在匹配训练拟合后才带来额外留出收益，才更支持需要改变表示。

<a id="mechanism-p3围绕交集内部概率比例设计有针对性的目标干预"></a>

### P3：围绕交集内部概率比例设计有针对性的目标干预

N4 表明剩余 KL 主要在共同候选内部。优先离线分解这些 state 的 log-prob 比值、entropy 差、位置与推理/答案阶段，并分别测其梯度能否改善独立 state，再决定是否做置信度匹配或 teacher-to-student 目标渐进过渡。原始 teacher 始终作为统一评估目标，避免通过软化目标本身制造“loss 变小”。

这一方向排在前两项之后：温度 1.5、warm FKL/JS已没有表现出共同修复，当前不支持直接扩大SFT、温度或混合目标的搜索。若继续交集策略，需要同时控制采样权重、entropy和普通student top-k；高 overlap 硬筛与保证 token 命中交集不再作为主要成功标准。

<a id="mechanism-后续统一验收面板"></a>

### 后续统一验收面板

| 要回答的问题             | 主指标与控制                                                                  |
| ------------------------ | ----------------------------------------------------------------------------- |
| 相同输入能否下降         | 固定来源×领域×位置的原生 RKL、共享支持 FKL、JS/TV、entropy；旧批重复复测      |
| 能否迁移到当前访问分布   | 无约束 fresh $J_H$，按 prompt 配对；长度/EOS 及参数×state 交叉评分            |
| batch 平均是否实际有用   | raw 方差、完整池方向、实际 Adam 参数位移投影；同更新数与同 token 预算分别报告 |
| 是否学到任务能力         | 完整同协议 Math/Code/IF 功能评测、解析/停止/长度；足够 prompt 及独立训练 seed |
| state/指标选择是否过拟合 | 诊断集与最终封存测试分开；用诊断梯度选择 state 后不可再把该诊断集当最终成绩   |

暂不优先：继续学习率搜索、只打乱小数据池、只增加 reuse、生产 batch 盲目放大八倍、未经配对诊断就将纯 teacher-on-policy 当作修复、按集合 overlap 单指标筛选。它们分别已有负面或不充分证据；不是宣布所有相关方法永远无效。
