# SFT 数据分布处理与教师构造

更新日期：2026-11-09。本文固定下一轮数学 SFT 的数据处理、长回答和训练对照；新生成与训练尚未启动。首轮实际配置、历史曲线和奖励缺陷由[原实验报告](2026-11-08-专家数据中心化与教师吸收对照设计.md)维护；本文替代其中下一轮 SFT 数据处理方案，OPD 暂只保留交叉验证接口。

## 1. 问题与已有证据

研究问题是：同一专家生成的回答经过选择或重采样后，SFT teacher 的任务收益、相对 Base 的概率变化和域外保持如何改变。后续再检验处理后的 teacher 是否接近原 teacher 经 OPD 得到的 student，即处理是否保留了相同的可恢复变化。

RAW 已恢复旧 greedy 协议下的数学分数，但仍有明确的分布残差。下表为永久留出集、每题前 256 个有效 response token 的 full-vocab $D_{\mathrm{KL}}(S\Vert T)$，单位 nats/token；先题内平均，再按域平均。

| 状态来源与领域             |    step0 |  step128 |  step256 | step256 / step0 |
| -------------------------- | -------: | -------: | -------: | --------------: |
| Base 前缀，数学            | 0.288851 | 0.060447 | 0.056787 |          19.66% |
| Base 前缀，四域均值        | 0.135517 | 0.027622 | 0.024670 |          18.20% |
| RAW teacher 前缀，数学     | 0.630840 | 0.022667 | 0.005173 |           0.82% |
| RAW teacher 前缀，四域均值 | 0.245784 | 0.015690 | 0.007802 |           3.17% |

[逐题汇总来源](../../../../../runs/teacher-construction-20261108/llm-v1/analysis-raw256-v1/risk-summary.csv)显示 Base 前缀上的后段下降显著放缓，teacher 前缀仍在下降。训练 loss 最后两个 16-step 窗口均值为 0.007017 和 0.006605，使用固定预算分母且状态随 actor 改变，不能替代 held-out RKL。结论应写为“任务收益恢复与状态相关的持续残差并存”；现有预算没有证明所有状态都能充分恢复，也没有证明残差永远不能继续下降。[训练日志](../../../../../runs/teacher-construction-20261108/llm-v1/opd/RAW/metrics.jsonl)

## 2. 文献与可检验假设

| 来源                                   | 已有操作或理论                                                                 | 本实验采用的部分                                              |
| -------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| RL’s Razor[^razor]                     | oracle SFT 与低 KL 正确目标；研究任务学习与遗忘                                | 用 Base 正确条件分布作为数据处理的理想参照                    |
| GRAPE[^grape]                          | 固定题目，在多个回答中选择 Base 长度归一化 likelihood 最高者；含随机与反向选择 | 主选择基线，避免同时改变题目分布                              |
| RSR[^rsr]                              | 用 token 排名和 surprisal 的比值选择回答                                       | 检查只追求高 likelihood 是否损失学习收益                      |
| DSIR[^dsir]                            | 在特征空间估计目标/来源密度比，再重要性重采样                                  | 密度比软重采样的方法依据；完整 LLM 序列比值是本文的待验证变体 |
| SFT Conflicts, RL Coexists[^conflicts] | 零和 advantage 消去组内共同 score 项，在额外条件下分析跨任务干扰               | 区分目标分布接近与梯度中心化；用真实更新诊断验证              |
| Finetuning with Sampling[^sampling]    | 利用专家轨迹生成新候选并做 projection sampling                                 | 后续生成变换对照；首轮不与固定池选择同时引入                  |

设专家为 $A$、初始 Base 为 $B$，$C_x$ 是给定题目下、在共同长度上限内完整终止且判对的回答集合。以下为总体分布恒等式，假定 $B(C_x\mid x)>0$，且来源分布覆盖目标支持：

$$
B_C(y\mid x)=\frac{B(y\mid x)\mathbf1[y\in C_x]}{B(C_x\mid x)},
\qquad
D_{\mathrm{KL}}(Q\Vert B)
=D_{\mathrm{KL}}(Q\Vert B_C)-\log B(C_x\mid x),\quad Q(C_x)=1.
$$

因此 $B_C$ 是正确集合上离 Base 最近的分布。初始化 $\theta_0$ 处，令 $p_{\theta_0}=B$、$s_B=\nabla_\theta\log p_\theta|_{\theta_0}$，并用 $\mathbb E_B[s_B]=0$，得到：

$$
\begin{aligned}
g_{\mathrm{SFT},B_C}
&=\mathbb E_{B_C}[s_B]
=\frac{\mathbb E_B[\mathbf1_C s_B]}{B(C_x\mid x)}\\
&=\frac{\mathbb E_B[(\mathbf1_C-B(C_x\mid x))s_B]}{B(C_x\mid x)}.
\end{aligned}
$$

这个初始期望方向等于中心化二值奖励的 policy gradient 的正比例缩放；固定数据 SFT 的后续路径仍由当前参数和优化器决定。主假设是：向该条件分布移动能改变 SFT 的概率位移和域外干扰，是否提高后续 OPD 恢复程度需要另测。

正权重均值为 1 不等于零和 advantage。对有限候选，$\sum_j w_j=K$ 时，$K^{-1}\sum_jw_js_j=\bar s+K^{-1}\sum_j(w_j-1)(s_j-\bar s)$，普通加权 SFT 仍保留 $\bar s$。本文称“数据分布处理”，不把它直接解释为梯度已经中心化。完整条件与推导见[教师可学习性](../../theory/teacher-learnability.md)。

本地统一评测数学训练表只有 6,400 行，不能支撑此划分。完整 DAPO 本地源为 17,917 行，NFKC 加空白归一化后有 17,187 个不同 user 题面；benchmark 排除与近重复聚类后的数量仍需验收。[设置核对记录](../../../../../runs/teacher-construction-20261108/sft-setting-audit-20261109.json)保存源路径、hash 和计数口径。数学五类题表合计 12,288 题，剩余独立题用于候选覆盖不足时补充；所有留出先划分，之后只从 train 保留区补题。Code/Science/IF 各另锁定 256 个独立题，前 128 个作 dev、后 128 个作 test，并排除能力 benchmark 重合。

8,192 是有效训练题目标。结果同时报告原始题池和有效题池的难度、专家通过率与排除比例；主要方法比较共享同一有效题池。本文的 RAW-C 指该池中的均匀采样，首轮未过滤 RAW 与新 RAW-C 的质量差异另报。

先用独立的 512 题校准集检查完整回答的长度 P10/P50/P90、正确率、截断率、每题候选覆盖与唯一回答数。24,576 是上限，不要求回答达到某个长度；短而完整的答案保留。若大量回答未完成，先调整共同生成协议或题源后重新冻结；不靠事后缩短 response 降低成本。校准题不进入训练或最终测试。

数据质量使用已有 canonical 数学评分器的冻结版本，同时保存原生答案通道提取结果，抽查 100 条含多行 `Final Answer:`、boxed 与思考标签的分歧。首轮 DAPO 空提取阻止 boxed fallback 的规则不进入新候选选择。判对指最终答案通过验证，完整推理的正确性另用盲审抽查估计。[首轮评分诊断](2026-11-08-专家数据中心化与教师吸收对照设计.md#42-verifier-的格式偏差)

## 4. 同一候选池上的四个 SFT 分支

设题目 $x_i$ 的有效候选为 $y_{ij}$，数量 $K_i$；所有指标都由冻结的初始 Base 计算。

| 分支  | 每次题目呈现时的候选概率 $P_m(j\mid x_i)$                                                               | 作用                                                                    |
| ----- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| RAW-C | $1/K_i$                                                                                                 | 正确性统一后的原始专家分布基线                                          |
| GRAPE | Base 平均 log-probability 最高的四条均匀采样                                                            | 已有 likelihood 选择方法；top-4 是本文变体，论文 top-1 另作离线选择诊断 |
| RSR   | RSR 最低的四条均匀采样                                                                                  | 检验 likelihood 与学习收益的权衡；同为 top-4 变体                       |
| RATIO | $P_\alpha(j\mid x_i)\propto\exp(\alpha d_{ij})$，$d_{ij}=\log B(y_{ij}\mid x_i)-\log A(y_{ij}\mid x_i)$ | 连续分布干预                                                            |

GRAPE 使用 response token 的平均 log-probability；RSR 使用 $\sum_t\min(\operatorname{rank}_B(y_t),r_{\max})/\sum_t[-\log B(y_t)]$，rank 从 1 起，固定 $r_{\max}=100$，并记录 10/1,000 的离线敏感性。GRAPE/RSR 对生成的正文 token 评分，不把终止 token 算入平均；密度比则按下述完整终止事件计算。

RATIO 的总体目标为 $Q_\alpha\propto\mathbf1_C A^{1-\alpha}B^\alpha$；有限候选下仅是在经验池内重采样。用 log-sum-exp 归一化，记录 $\mathrm{ESS}_i=1/\sum_jP_\alpha(j\mid x_i)^2$、最大权重和唯一候选覆盖。校准阶段在 $\{0,0.01,0.03,0.1,0.3,1\}$ 中，选择使校准集 median$(\mathrm{ESS}_i/K_i)$ 最接近 0.5 的单个全局 $\alpha>0$，并冻结；并列取较小值。$\alpha=1$ 保留为离线极限诊断，权重塌缩时不将其称为已经采到 $B_C$。该选择只用候选统计，不看最终能力或 OPD 测试。

完整回答 $y=(y_1,\ldots,y_L,\mathrm{END})$ 的概率定义为：

$$
\log p(y\mid x)
=\sum_{t=1}^{L}\log p(y_t\mid x,y_{<t})
+\log\sum_{e\in E}p(e\mid x,y_{1:L}).
$$

两种终止 ID 合并成同一个 END 事件，避免终止符选择主导密度比。$A$ 使用实际专家模板，$B$ 使用实际 student 模板；两者正文采用相同 token ID 映射和合法支持。评分需要复现采样时的 logits 变换与数值策略；未核对的 HF/vLLM 概率差须报告，不能将代理分数称为精确采样密度比。候选通过正确性和完整性筛选的题内归一化常数在自归一化权重中抵消。

四组冻结每题每轮的候选抽取表，训练随机 seed 使用同一题目顺序与可复核的公共随机数。多轮仍从冻结池中抽取，不随 teacher 更新重新打分。补充一个 RAW-C 的长度匹配对照：按处理组的每题长度区间随机抽样，报告无共同支持的题；它单独回答选择收益是否主要来自回答长度。

## 5. SFT 目标、预算与 teacher 验收

四组均从同一个 $B$ 及 fresh optimizer 开始，response-only CE，prompt/padding 不计损失。每次每题抽一条候选，主目标为题目等权的序列 CE：

$$
\mathcal L_m(\theta)
=-\frac1{N L_{\mathrm{ref}}}\sum_{i=1}^N
\sum_jP_m(j\mid x_i)\log p_\theta(y_{ij}\mid x_i),
\qquad L_{\mathrm{ref}}=8192.
$$

$L_{\mathrm{ref}}$ 是四组共用的尺度常数，不是截断长度。抽样 CE 是该目标的无偏估计；不按每条回答长度分别除，不按每个 microbatch 的有效 token 数分别平均。用正文 CE 加共同 END 的负 log-probability，实现上式的终止合并；packing 须保持样本间 attention 隔离与原 position 语义。

| 项目   | 主设置                                                                                                                          |
| ------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 优化   | AdamW，LR3e-6、WD0、clip1，常数 LR；global batch32，microbatch1，以梯度累积实现                                                 |
| 训练量 | 4 个 question epochs，共 32,768 次题目呈现、1,024 updates；保存 epoch1/2/4 的模型、optimizer、RNG                               |
| 随机性 | seed20261109/20261110 两次独立训练；方法比较共享候选池，关键结果再用新候选池与第三 seed 确认                                    |
| 长序列 | 不截断完整 response；gradient checkpointing、分块 vocabulary CE；microbatch1 仍不足内存时改用序列并行或多卡分片，保持目标与长度 |
| 数值   | 沿用首轮 FP32 master/head/gradient/Adam moments、BF16 backbone、TF32 off；先验证 tied head、EOS 合并及长序列梯度                |
| 成本   | 保存真实 response token、forward/backward token、梯度裁剪频率与 GPU 小时；分清候选池生成和每条训练路径的成本                    |

主对照匹配题目呈现次数和序列目标，各组实际 token 可能不同；另按共同累计 response-token 预算保存读出，分别报告，不能把相同步数称为相同计算量。长度匹配随机对照用于解释分布处理的直接作用。主 seed 以外的波动按训练 seed 报告，题目 bootstrap 区间不代替 seed 方差。

每个 teacher 保存三类验收结果：

- **能力**：MATH-500 每题 4 条、AMC23 与 AIME24/25/26 每题 16 条，temperature1、top-p0.95、cap24576，沿用[长预算评测协议](../../../../../runs/teacher-construction-20261108/capability-reeval-v2/plan.json)。报告平均单次正确率与 pass@k，名称分开；数学同时保存 canonical 与原生评分，主比较固定 canonical。
- **分布与保持**：train 固定审计子集、IID-dev、锁定 IID-test 和 OOD Code/Science/IF 状态上测双向条件 KL、相对 Base 的中心化 log-ratio、长度和停止原因；OOD 能力沿用 GPQA×4、IFEval×1、LCBv5×10。固定状态距离与生成能力分列。
- **更新机制**：在固定训练/留出小批次测梯度均值、方差、有符号跨批/跨域内积及实际 Adam 更新后的域外 loss 变化，检验论文的梯度动机；相同权重均值不作为中心化已成立的证据。

保留全部预定 checkpoint；方法和 checkpoint 的选择只使用 dev，最终测试一次锁定。teacher 的正能力增益、相对 Base 的距离与预算共同展示，避免把弱 teacher 的小距离解释为更好的迁移。

## 7. 留给后续 OPD 的最小接口

保留未处理 teacher $T_R$、处理后 teacher $T_P$，后续统一从 $B$ 初始化得到 $S_R=\mathrm{OPD}(T_R)$、$S_P=\mathrm{OPD}(T_P)$。主问题是 $T_R$ 与 $S_R$ 仍有明显距离时，是否同时观察到 $T_P\approx S_P$ 及 $T_P\approx S_R\approx S_P$。前者检验处理后恢复，后者检验是否保留同一变化；在公共 held-out 状态上比较绝对距离、中心化 log-ratio 的方向与幅度，并分开报告 IID/OOD。

这里不增加 OPD 方法矩阵，不启动新 OPD。SFT 先交付共同长回答候选池、四组 teacher、多 checkpoint、能力与分布读出，再冻结后续 OPD 的统一预算。原 teacher 的早期 checkpoint 同时保留，供后续排除“仅仅弱化 teacher”的解释。
