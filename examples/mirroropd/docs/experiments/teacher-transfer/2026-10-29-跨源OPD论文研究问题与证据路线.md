# 跨源 OPD 论文研究问题与证据路线

更新时间：2026-10-29。当前重点是 OPD 能拟合哪些教师函数及后训练增量。三个主 RQ 依次研究同构教师的充分拟合、跨尺寸拟合的方向性、残差的本质来源。改进算法暂不作为主 RQ；机制实验可以使用干预，但目的首先是区分解释。已有结果、机制假说和建议实验分别标明，未启动新训练。

阅读顺序：[研究问题](#research-questions)、[本地证据](#local-evidence)、[与文献的区别](#prior-art)、[关键实验](#experiments)、[论文组织](#paper-structure)。

## 1. 论文定位与定义

候选标题为 _What Can On-Policy Distillation Learn? Architecture, Scale, and Post-Training Increments_，中文工作标题为“OPD 能够学到什么：架构、规模与后训练增量”。目标是找出可学习边界及其原因，不预先承诺同构模型必然被完全吸收，或不同尺寸永远不能被完全拟合。

“同尺寸且同架构”可以作为主要分组，建议称为同构配对，另列初始化谱系。文献的 same-origin 常指共享具体后训练初始化；若改为同尺寸同构，需声明操作定义并保留文献映射。不能把“能够完全拟合”写进分组定义，再用实验验证同一命题。同构需核对具体前向结构、RoPE、token 语义、参数绑定及数值路径，相同参数量或模型类名不足以保证。

本阶段把函数拟合与能力提升分开：较弱 teacher 仍是合法的拟合目标，不要求其任务分数高于 student。教师有正优势只是在讨论正向能力回收时需要的条件。可表达、可优化到达和跨状态泛化分别研究。严格同构且执行路径一致时，teacher 权重提供可表达性的构造；从当前学生出发能否找到它仍是问题。

“充分拟合”保留为待刻画边界，报告绝对残差、copy 参考、随更新的斜率及训练／留出／fresh／长回答的一致性，不新增通用数值门槛。有限实验不能证明所有同构 teacher 均可收敛，也不能把有限预算平台当作跨尺寸不可表达的证明。

## 2. 一个总问题与三个主 RQ

总问题：OPD 的可学习边界由教师函数的可表达性、师生初始化关系，还是教师修正在学生参数空间中的可达性决定？

| RQ              | 建议表述                                                                              | 关键比较                                                 | 待检验命题                                |
| --------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------------- |
| RQ1：同构拟合   | 核验教师函数可表达后，延长更新能否使学生在多类状态上充分拟合同尺寸同架构教师？        | 近源／早分叉 × RL／SFT；固定覆盖长训与新增覆盖分开       | 同构教师仅靠更多更新总能充分拟合          |
| RQ2：跨尺寸方向 | 大教小和小教大是否存在不同的拟合边界，尺寸差异是否足以解释残差？                      | 同一小 teacher 教小／大学生，同一大 teacher 教小／大学生 | 不同尺寸均不能拟合；失败都来自学生太小    |
| RQ3：残差机制   | OPD 是否优先学习学生可达且可跨状态共享的教师修正，RL/SFT 增量的谱及方向能否解释结果？ | 前后教师、增量与底座分离、谱幅度与方向控制、真实更新传播 | OPD 硬性过滤高秩信息；RL/SFT 标签决定难度 |

### 2.1 RQ1：可表达性与长程优化到达

H1 是待验证假说：同构教师的残差在增加有效优化后持续接近低风险可行参考，且改善不限于一个留出面板。copy 只证明存在可行参数；学习率、Adam 状态、weight decay、数值精度、数据覆盖和批次顺序都可能影响训练残差。

Qwen 的 e3/GRPO-KL 数学留出接近 copy，但旧训练批仍有更大残差及部分反弹。现有 64→320 同时增加题目覆盖，尚不能回答只延长更新是否足够。应分别做固定题目及完整轨迹银行增加更新、相同更新预算增加独立覆盖两种对照；使用平衡访问并复测旧批，再以 fresh 轨迹和较完整回答确认。

64、320、1280 可作为候选检查点，不是收敛保证。长训保留连续 Adam；若现有终点仅有权重，重置 optimizer 的实验独立标记。近源 RL、近源 SFT、Base 分叉 RL、Base 分叉 SFT 四格优先于继续增加相似教师；公开四格仍有数据与预算混杂，严格判断需受控分支。参数距离只在同坐标模型间报告，不当作函数距离。

### 2.2 RQ2：容量方向与跨尺寸配对

小 teacher→大 student 是当前最重要的新增方向。若大模型能充分拟合小教师，便反驳不同尺寸一律不能拟合；若仍困难，学生参数量不足不能解释这组失败，但尚不能直接证明架构不兼容。更大模型并不自动在严格数学意义上包含某个具体小模型的函数族。

优先复用 R1 的两种学生和两组后训练前后教师：

| Teacher → Student | R1-1.5B student        | R1-7B student            |
| ----------------- | ---------------------- | ------------------------ |
| R1-1.5B           | 自教师数值对照         | 新增：小原始教师教大学生 |
| JustRL-1.5B       | 已有近源 RL 对照       | 新增：小 RL 教师教大学生 |
| R1-7B             | 已有跨尺寸原始教师对照 | 自教师数值对照           |
| Polaris-7B        | 已有大 RL 教师教小学生 | 已有近源 RL 对照         |

两个新配对使用共同文本题目，在共同冻结前缀及各学生自己的前缀上分别评分。统一数值路径、归一化和预算后再比较历史结果；旧 64/128 步与新长训不能混排。自教师检查接口与数值，不提供非平凡的学习速度对照。R1-7B 原始 macro5 约 65.78%，JustRL 约 63.38%，后者仍是有效拟合目标；其任务下降可以与更充分匹配同时发生。

Qwen 后续可用 e3-1.7B 教 Qwen3-4B/8B 复核，先完成接口和基线。已有文献报告小 RL teacher 教大学生的任务收益，因此 weak-to-strong 本身不是新概念；任务提升不等于完整教师条件分布已被复制。[^scaling]

更强的容量控制是构造并核验保持小教师前向函数的扩宽／加深学生，将已知可行权重与正常初始化对照。只有实际验证函数保持，才能排除该配对的表达性障碍；不能直接把任意更大的 Qwen 当作这种嵌入。这是后续机制实验建议。

### 2.3 RQ3：RL 增量、有效秩与可达方向

机制假说拆为三条：RL 增量比 SFT 更集中；OPD 对某些修正方向的响应更快；Polaris 比 R1-7B 更可迁移的部分主要来自其 RL 增量。三条分别检验，不能由算法标签直接串成结论。

| 测量对象     | 建议定义                                                      | 解释边界                                      |
| ------------ | ------------------------------------------------------------- | --------------------------------------------- |
| 教师训练增量 | 各层 $\Delta W=W_{\rm after}-W_{\rm before}$ 的奇异值与有效秩 | 需要同坐标父权重；RL/SFT 不预定秩             |
| 函数增量     | 共同状态上的中心化 logit／log-prob 改变量的谱，明确加权度量   | 随状态及输出坐标变化；跨尺寸不直接减权重      |
| 学生响应     | 同一学生、输入和度量下的 Jacobian 响应及目标投影              | 已有 teacher-conditioned 梯度 Gram 不是输出核 |
| 已学习修正   | 参数位移、输出变化与跨题收益                                  | 学生更新低秩不等于教师知识低秩                |

更精确的工作假说是有限时间的方向选择性：教师修正在学生响应强的方向上更容易被学入。低秩但落在弱响应方向的修正也可能很难；高秩但主要位于强响应方向的修正不必然难。在固定输入、固定线性化及二次局部目标下，模态残差按 $e^{-\lambda_i t}$ 衰减，速度由响应特征值及目标投影决定，不由秩标签决定。这里的特征值不能用 loss-gradient Gram 的特征值替代，真实 Adam 与非线性训练也不直接遵循该理想动力学。推导见[谱滤波定义](transfer-mechanism/spectral/2026-10-28-谱滤波诊断与同架构教师对照.md)；近源恢复和方向依赖已有理论，不能将其作为新定理。[^vanishing]

### 2.4 分离 R1-7B 底座失配与 Polaris 增量

固定同一 student 和完整前缀，原始大教师为 $q_B$，RL 后教师为 $q_R$。在学生支持集上核验 token 语义并保留教师原生归一化，定义

$$
d(s,v)=\log q_R(v\mid s)-\log q_B(v\mid s).
$$

这是指定 checkpoint 的函数差异；若精确父权重未核实，不能把它全部归因于 RL 算法。逐项代入 RKL，省略共同 state，得到

$$
\begin{aligned}
D_{\rm KL}(p_\theta\Vert q_R)
&=\sum_vp_\theta(v)[\log p_\theta(v)-\log q_B(v)-d(v)]\\
&=D_{\rm KL}(p_\theta\Vert q_B)-\mathbb E_{p_\theta}d,\\
\nabla_\theta D_{\rm KL}(p_\theta\Vert q_R)
&=\nabla_\theta D_{\rm KL}(p_\theta\Vert q_B)-\nabla_\theta\mathbb E_{p_\theta}d.
\end{aligned}
$$

在同一个学生点上测底座失配梯度、增量梯度、夹角及各自的跨题影响。再测学生输出变化在 $d$ 上的加权投影，保留整体教师残差和正交剩余部分。投影表示该面板上的方向相似，不等于能力量；两个教师各自训练后终点之差也不能作线性可加的 RL 能力。

可进一步把增量放入固定学生锚点，构造诊断目标

$$
q_\Delta(v\mid s)=\frac{p_0(v\mid s)e^{\alpha d(s,v)}}{Z_\alpha(s)},\qquad
Z_\alpha(s)=\sum_up_0(u\mid s)e^{\alpha d(s,u)}.
$$

代入得到 $D_{\rm KL}(p_\theta\Vert q_\Delta)=D_{\rm KL}(p_\theta\Vert p_0)-\alpha\mathbb E_{p_\theta}d+\log Z_\alpha$，最后一项在固定 $p_0,d$ 时对学生参数为常数。这隔离了增量而不要求拟合大教师底座。它不是待提出的新算法：已有 Delta-OPD 使用教师 RL 前后 log-ratio 与学生参考 KL，需直接对照。[^scaling]

若学生变化不集中于增量方向，或增量没有更强的跨题收益，就应拒绝“主要传来 RL 部分”的解释。即使该解释成立，还需独立证明其与有效秩的关系。

### 2.5 区分秩与方向的机制控制

先测同坐标 RL/SFT 增量谱，控制幅度和初始函数差异；再从同构增量构造不同截断秩、以及相同奇异值但不同方向的对照。每个新教师都复测实际函数差异、任务表现和数值接口。SVD 截断不只改变秩，相同矩阵谱也不保证相同函数位移，必须保留这些混杂。

若低秩方向改变后变难，而较高秩且对齐学生响应的目标仍容易学，就不支持硬性过滤高秩的解释。只有在控制幅度、函数距离和方向后，秩仍稳定预测吸收，才支持秩本身的作用。已有 rank-16 子空间干预不构成所有 RL 低秩、所有 SFT 高秩的定理。[^geometry]

本地 RKL 能记忆随机映射，已否定“只允许可迁移信息进入”的严格版本；这不直接否定有限时间谱偏好，但要求把过滤表述为特定状态、预算与优化路径上的选择性。

### 2.6 共同的残差与实际更新读出

每个代表 checkpoint 同时保留以下观测，不将它们合并成一个成功分数。

| 观测                       | 回答的问题                     | 必须保留的控制                              |
| -------------------------- | ------------------------------ | ------------------------------------------- |
| 当前训练批固定风险         | 这批监督是否能被优化           | 完全相同 token、位置、teacher 目标与归一化  |
| 旧训练批固定风险           | 已获得的条件分布拟合是否保持   | 同一旧轨迹复测；不以换批起点推断遗忘        |
| 同题独立轨迹、异题固定轨迹 | 收益是否超越记住当前前缀       | 同来源与异来源分别统计；题目层配对          |
| 当前学生 fresh 轨迹        | 学生实际访问分布是否更接近教师 | 无 top-k 交集限制；参数与轨迹交叉评分       |
| 完整回答与任务评测         | 分布改善是否带来解题收益       | avg@k、pass@k、长度、截断、重复和旧能力保持 |

关键假说是：部分跨源配对在早期共享修正被学入后，当前批仍可继续拟合，但真实更新对未见状态的收益迅速减弱。另一些配对可能主要受旧批保持或完整回答行为退化限制。不同配对允许不同瓶颈，不预设一个机制解释全部实验。

对固定风险 $R_A$ 和另一题组的固定风险 $R_B$，从相同参数与优化器状态出发，在 A 上执行一段更新，记实际参数位移为 $\Delta\theta_A$。一阶诊断为

$$
R_B(\theta+\Delta\theta_A)-R_B(\theta)
\approx \nabla R_B(\theta)^\top\Delta\theta_A.
$$

精确的审计量是该段更新前后的有限差值；内积只用于解释，并通过缩放位移检查线性近似误差。使用真实 Adam 位移，保留动量、预条件、裁剪和权重衰减的作用，不能直接用负梯度代替实际更新。建立 $A\to B$ 影响矩阵：对角线描述当前批拟合，非对角线描述其他题组风险变化。保留两者的绝对值；局部收益接近零时，不报告不稳定的迁移比值。

这些一阶关系与梯度对齐本身是已有工具。潜在贡献在于受控谱系矩阵上的验证、对实际更新和数值读出的核对，以及诊断能否预测独立配对上的后续行为。用留出梯度分析后的投影是 oracle 诊断；若据此选择训练方向，该集合必须改称开发集，并新增从未参与选择的测试集。

对访问分布，令 $R(\theta,\mu)$ 为在来源 $\mu$ 的固定完整前缀上、固定 horizon 与终止规则下计算的风险。交叉评分使用以下恒等分解：

$$
\begin{aligned}
R(\theta_1,\mu_1)-R(\theta_0,\mu_0)
={}&[R(\theta_1,\mu_0)-R(\theta_0,\mu_0)]\\
&+[R(\theta_1,\mu_1)-R(\theta_1,\mu_0)].
\end{aligned}
$$

第一项固定前缀看参数变化，第二项固定终点参数看访问分布变化。它依赖所选参照路径，不能自动解释为唯一因果归因；还应报告交换参照次序的分解。完整词表仅去除给定 state 上的动作抽样误差，仍保留题目、轨迹及优化随机性。

Qwen 的接近 copy 判断仅针对已测数学留出面板，不能推广为全部固定状态都接近教师。第一批完成的教师基线中，e3 是唯一宏平均点估计高于原始学生者，且优势仅约 3.26 个百分点；其他教师仍有分布拟合研究价值，但不能单独构成正向跨源能力迁移证据。原生 non-thinking 教师在共同 thinking 条件下的低分，也不能归因于训练方法本身。

本地 [E50–E53](optimizer-precision/production/2026-10-29-E50至E53完整结果与混合精度对照.md)显示，内层净下降与最终 accuracy 不等价；MirrorOPD 近目标求解尚没有形成跨源任务突破的证据。因此本篇不以“近目标求解更准确必然更好”作为方法前提。[训练信号](../learning-signal/README.md)和 [reuse](../reuse-budget/README.md)负责排除估计器与预算混杂；[rollout-policy](../rollout-policy/README.md)目前的工程验收不计作长程效果结果。

## 5. 关键实验与优先级

### 5.1 P0：先补齐决定论文是否成立的读出

完成现有 Qwen 基线及 64/320 终点任务评测，并保留每个 teacher 的原始优势、置信区间、长度与失败类型。GT-Base-MATH 的优先级高于再增加近源 RL 教师；已有 Co-rewarding-I/II 可帮助寻找强早分叉目标，但其训练差异不能忽略。tocsa RLVR 保留为小改动参照。4B/8B 在同预算 64-step 完成后提供尺寸外推；4B-Thinking-2507 的 RoPE 差别单独标记。

当前优先缺口是小 teacher→大 student，以及分离更新次数和状态覆盖的同构长训。GT/Co-rewarding 即使弱于学生，也保留拟合研究价值。强同尺寸早分叉教师用于后续能力确认，不作为当前拟合实验的准入条件。若改变任务域，另立协议，不能事后选择有利数据集覆盖原宏平均结果。

为确认本地短程现象，建议保留近源正对照、同尺寸早分叉、跨尺寸强教师各一种，并在 R1 与 Qwen 两套学生上覆盖可比问题。两者均属于 Qwen 派生谱系，不能据此写成两个独立预训练家族。最关键的结论配对建议至少三个训练 seed；这是重复设计建议，不是完成状态。

### 5.2 P1：按三个 RQ 完成辨别性实验

建议顺序为：补 R1-1.5B／JustRL-1.5B→R1-7B 的两条反向尺寸配对；代表同构教师做固定覆盖长训；共同学生点分解 R1-7B／Polaris 的底座与增量。谱和截断控制跟随增量诊断，不先做全面低秩扫描。新增训练均为建议。

在原始学生和后期 checkpoint 上，用同一权重及完整 Adam 状态分叉，固定题目和目标，比较重用原轨迹、同题新轨迹、新题轨迹。匹配有效 batch、训练 token 和更新数；存在长度差时以预先定义的 token 采样方案处理并记录剩余差异。分别测当前批、旧批、同题未训练轨迹、异题轨迹与 fresh 风险。

记录实际参数位移与对应影响矩阵，检验改善局部拟合后，异题收益是否仍低。如果新题／新轨迹恢复非对角收益，则支持覆盖解释；若只增大学习率或提高精度恢复局部收益而异题不变，则支持局部求解与泛化分离。梯度谱作为解释性图，避免再建一个与最终干预脱节的大型谱扫描。

Qwen 近源旧批风险反弹另做最小控制：保持相同总样本访问量和更新数，对比 blocked 与混合／重放顺序。检验是否能同时保持旧状态并维持 held-out 改善。若重放占用新题预算，应另列预算权衡，不能把它当免费收益；这项结果仍属于条件分布保持，任务遗忘需独立功能评测。

### 5.3 暂缓的算法改进候选

| 瓶颈证据                               | 优先实验                                       | 必须比较的对照                                                             | 何种结果会否定该解释                             |
| -------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------ |
| 同题新轨迹／新题明显恢复跨批收益       | 状态覆盖或来源日程                             | 固定 S0、普通 online、teacher 来源；等 token 随机策略                      | 只有训练风险改善，fresh 与任务不改善             |
| 同构远源存在低风险可行点，但跨题更新弱 | 完整 SFT cold start 后 OPD；必要时比较表示监督 | 直接 OPD、SFT-only、匹配漂移／任务起点的 warm start；采用表示路线时加 OPRD | 收益全由 SFT 贡献，或任何同幅度扰动都同样有效    |
| 短前缀接近，完整回答退化               | 覆盖推理后段／自然结束的训练                   | 相同训练 token 的短前缀组、相同评测 cap、长度统计                          | 延长覆盖只增加成本，或收益仅来自更长评测预算     |
| 想采用外部教师经同源中介的方案         | 文本条件 self-teacher 或逐阶段教师路径         | BSD／Teacher Assistant 相关方案、直接 teacher、教师成本与 verifier 匹配    | 桥接本身无优势，或优势来自额外奖励／额外教师查询 |

这些算法路线暂缓，不作为本篇完成条件。机制研究中的容量、秩、方向和覆盖干预可以先行，用于区分解释。SFT→OPD 仍是已有基线；未来若转向方法论文，再验证独立配对和任务收益。

### 5.4 能力读出与拟合读出的解释边界

主表报告原始 student、teacher、student-after 的 accuracy、绝对增益及置信区间。GapRecovery 为增益除以教师优势，保留负值、超过 100% 和不稳定分母；教师更弱或优势区间跨零时不将比值作为主排名。avg@k 与 pass@k 同时保留，避免只提高集中度却损失解法覆盖。

将题目按独立基线采样区分教师稳定会、学生尚不会，以及学生稳定会的部分，随后用新的采样评估获取与保持；不能根据最终学生结果倒选题。训练题、调参题、机制开发面板和最终测试题分开。旧机制面板已多次用于研究，不命名为封存测试集；只做题面去重不等于排除教师预训练或后训练污染。

加入一个适用的 teacher-free 对照，明确其是否使用 verifier。若方法使用任务奖励，增加相同奖励和成本的 RLVR 对照。精确 full-vocab 自教师从同一参数出发梯度为零，不能直接充当 OPSA 的实现；各目标、采样噪声与支持集应分别核对。教师条件下更高任务成绩、相对该教师的独立行为变化和适当无教师对照，共同增强迁移归因，单一 accuracy 提升不证明获得了教师独有知识。

所有主比较记录真实 optimizer 更新、独立 prompt 数、新生成 token、重复训练 token、teacher 评分 token 和实际算时。短期冻结 S0 的结果用于机制分析，最终方法需要在线确认，或明确将方法定位为离线学生轨迹蒸馏。长 horizon、不同模型规模和完整词表投影成本不靠等步数自动配平。

## 6. 建议论文结构与图表

| 正文章节                                | 核心内容                               | 建议主图／表                     |

full-vocab、IS、精度与 reuse 用于控制和解释残差，不各占一个主 RQ。局部／未见／fresh／任务的读出继续保留为测量框架；SFT→OPD、表示桥接与路由方法留待后续。

工作假说是可学习性同时依赖可表达性和修正在当前学生中的可达方向，后训练增量的谱与方向可能比算法或来源标签更有解释力。拟合弱教师有助于识别边界，任务提升不是每项机制对照的必要结果。

同构长训的正结果只支持已测范围；稳定残差仍需区分覆盖、数值和优化。跨尺寸失败只约束所测模型与协议。论文可以通过控制、反例和机制预测建立贡献，无须预先找到通用改进方法，也不把有限实验写成全域完全拟合或不可能拟合的证明。
