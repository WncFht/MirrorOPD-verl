# 师生迁移与优化机制

## 背景与 motivation

教师监督有时能被学生持续吸收，有时只降低当前批 loss 而难以积累。这里比较同源/异源关系，并用受控实验定位优化与迁移瓶颈；当前主要使用 acc 等既有指标，“完全蒸馏”的严格定义暂作开放问题。

## Setting 与实验设计

| 分支                | 主变量与控制                                      | 入口                                                                                       |
| ------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 模型与教师配对      | 谱系、规模、后训练和实际功能差异                  | [公共模型资料](../../settings/模型与师生配对.md)、[配对结果](teacher-comparison/README.md) |
| 异源教师方向对照    | E48/E49：Polaris下RKL/FKL                         | [Polaris 正式训练](cross-origin/polaris/README.md)                                         |
| 局部到跨 state 迁移 | 固定前缀、旧批/未见批、来源、覆盖、fresh 交叉评分 | [迁移机制](transfer-mechanism/README.md)                                                   |
| 实际优化能力        | optimizer 历史、步幅、精度、近目标 MDPO           | [优化器与精度](optimizer-precision/README.md)                                              |

小实验、正式训练和 CPU 诊断分别保留各自预算、采样及归一化。师生来源是设置维度，不以训练后是否容易学习反推“异源程度”。

## 实验结果

E49 改善了部分完成行为，但新批分布拟合仍平台。[E50–E53 最新分析](optimizer-precision/production/2026-10-29-E50至E53完整结果与混合精度对照.md)中，E51 完整训练有 255/256 批内层净下降，但最终三项 mean acc 均低于 E50；E52 的 256 批、E53 已有的 103 批也全部净下降。E53 的频繁第一步反弹与整批求解失败应分别判断。Polaris 暖状态受控 FP32 实验当前批 KL 下降 78.81%，held-out 仅 0.75%，说明局部求解改善未自动解除迁移瓶颈。

## 分析

按“当前批拟合→未见固定 state→fresh 访问分布→任务表现”区分证据。优化器与精度实验既解释 OPD，也解释 MDPO；目标正确性由理论/infra 保证。Qwen 的 EOS/模板修复和 E54 异常诊断归[模型兼容性](../../infra/model-compatibility/README.md)，不作为本线核心问题。
