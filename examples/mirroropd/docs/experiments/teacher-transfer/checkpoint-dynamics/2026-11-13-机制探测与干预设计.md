# OPD 吸收差异的机制探测与干预设计

**优先检验：好组是否更早把功能改善集中到可复用的方向，困难组则缺少可表达的纠正方向、存在信号抵消，或训练状态覆盖不足。** 优先复用已完成的 PAC、分量传播和小步干预代码，把新 pair 的残差、实际位移与下一窗口风险串起来；静态功能实验仅补历史未覆盖的条件。用户已选择优先研究域内机制，以 E99/E101 做静态干预和固定请求探测；下文为具体设置讨论稿，实验尚未启动，不改变正在运行的正式训练。

19 篇论文的结果与适用条件见[文献证据核读](../../../literature/teacher-transfer/2026-11-13-OPD几何机制与干预证据.md)。当前数据依据为[十一组全指标综合分析](README.md#已测结果的综合分析)及[完整 bank 换谱干预](谱恢复与RKL.md)。实验目标是区分机制，不预设某个方向一定有效，也不以复现某篇曲线外形作为成功标准。

### 修订后的首轮测量

1. **端点 pilot：E99/E101 的 0 与 640。** 同 initial-bank Math 固定 96 题用于独立 receiver，其中 48 题作 calibration、48 题作最终 test；另取 32 道训练侧 prompt 构造 source，必须核对不与 receiver 题目重叠。完整有效响应 cap7168、B8、seed42。先做一个 B8 数值/耗时 pilot，之后主分析保持 96 题；局部 prefix 小面板仅用于算子验收和定位，不代替完整轨迹。
2. **先测完整轨迹 PAC 与独立传播。** Native/frozen；分开P/L、token响应、题内聚合、题间C、自内积校正和train→cal/test内积。仅在A或传播差异复现时加random-sign分解与parallel/perpendicular四块，避免一开始跑所有kernel谱。
3. **连接自然训练窗口。** pilot 通过后加 128/320，必要时 480，比较 128→320、320→640，或缩成 320→480/480→640。使用真实 delta=theta_b−theta_a，评估−gradL_test(theta_a)·delta 与实测 L_test(theta_a)−L_test(theta_b)。这是窗口净位移的端点一阶近似，不是逐步 Adam 归因；同时测小比例 delta 和有限差分误差。
4. **仅对有证据的方向干预。** 将同一窗口 delta 按起点的早期 frame 分为内/外，保持原幅度并增加等范数对照，在同一 source/cal/test 上比较。早期投影不是 logit 请求的 parallel/perpendicular，必须分名和分别解释。若方向控制不能改善独立 test，停止将该特征发展成训练限制。

训练实际 current-rollout 样本若已保存，优先复用并核对题目、token、模型身份；若未保存，上述 source 只能称训练侧固定 bank。需要新生成 current 状态时另列计算预算，不能把它伪装成原训练样本。

首轮不再安排全 17 条件静态扫描、全局 kernel 谱和所有分量的穷举组合。端点差异足够明确后，random-sign token 响应与分量四块 Gram 用于定位；数值误差或问题定位需要时才增加探针。新计算结果单独维护在本专题，不改写旧 H1024 结论。

以“剩余请求→参数响应→独立传播→真实位移→实际风险变化”为主图顺序；spectrum、frame angle/overlap 和参数残差作为解释变量放在对应窗口旁边。重点比较空间变化是否伴随功能变化，避免把稳定性直接当作吸收质量。

### 后续干预的决策标准

| 新 pair 上的实际结果                                 | 采取的最小干预                                                | 不足以成立的结论                                                |
| ---------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------- |
| 某方向在独立 test 持续有效，但自然窗口位移很少使用它 | 同预算下小幅提高该方向权重，或更换明确阻碍它的 optimizer 处理 | 不能因 missing teacher 方向可直接降低 RKL，就称学到了可部署算法 |
| 窗口空间外更新对功能必要                             | 保留或软调节空间外更新，对照硬固定空间                        | 不预设早期锁定越强越好                                          |
| 共享早期空间足够但实际更新不对齐                     | 先核查归约、Adam 动量和预条件，再比较实际 delta 投影          | 仅 raw gradient cosine 改善不算救援                             |
| 所有局部量正常，拟合却只在 source 上改善             | 扩展状态覆盖/rollout 来源对照，预算不增加                     | 不以 rank 或 C 单指标解释                                       |

干预方向和超参数只能来自训练侧及 calibration，最终 test 梯度仅供诊断，不参与选方向或权重。训练救援必须在原 teacher 目标和独立 test 上比较 native，交换 teacher 降低另一个目标不算救援原目标。当前完成了协议与报告归约重构，尚未启动这轮新的 GPU 机制测量。自然窗口评分与早期 frame 编辑仍需接入；既有 CPU 数值回归通过后，才进入长响应 pilot。

## 二、可否证的假设

| 假设                                          | 预期观察                                                                           | 反证或需要改写的结果                                               | 首选干预                                                                   |
| --------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| H1：好组的功能更新更早集中到少数方向          | 早期空间内分量保留更多匹配改善，优于同 rank 随机方向；在多个 rank 与范数控制下保留 | 只有范数匹配有效，或随机方向同样好；早期与最终空间差距在好坏组相同 | 早期空间内/外加回、终点低 rank、保谱换方向                                 |
| H2：困难组的 teacher 请求不易转成有效参数更新 | 同固定状态上请求仍大，但归一化可达性或一致性低；固定初始请求的响应未随训练增强     | 固定状态响应正常，而差异只在新 rollout 上出现                      | 冻结状态/请求，测梯度、实际小步和接收状态的变化                            |
| H3：部分残差主要来自更新幅度或空间内外配置    | 沿已学方向缩放，或调节两部分相对幅度，能改善校准集并在独立 bank 保留               | 幅度扫描只能过拟合校准题，或所有方向均无明显救援                   | 一维/二维幅度扫描                                                          |
| H4：跨域或跨 bank 缺口主要来自状态覆盖        | 小步能拟合被监督状态，但向别的域/来源广播弱或相冲突；覆盖替换在同预算改善相应缺口  | 扩展覆盖仍无效，固定状态本身也无法拟合                             | source×receiver 响应表、checkpoint×rollout bank 交叉评分；随后才做覆盖对照 |

early→final 的终点是各自实际训练终点，困难组的终点本身也可能欠拟合；因此到自身终点更快只是一种轨迹特征。补充按相近更新范数进度、相近 RKL 改善进度比较的分析，使用已有离散 checkpoint，不插值生成 frame。它用于检查训练速度混杂，真正的功能判断仍由独立 bank 干预结果给出。

H1 与 H2 可以同时成立；H4 与 teacher 远近也可以同时存在。输出匹配目标以绝对 RKL 和相对剩余并列，不增加“完全吸收”阈值。当前不测 accuracy，不把 RKL 改善写成正确率或能力已经恢复。

## 四、阶段 A：静态功能干预，先证明方向作用

### A1. 低 rank 重构与保谱换方向

令终点更新为

$$
\Delta W=U\Sigma V^\top,\qquad
\Delta W_r=U_{:r}\Sigma_{:r}V_{:r}^\top,
\qquad
\widehat{\Delta W}_r=
\frac{\Vert\Delta W\Vert_F}{\Vert\Delta W_r\Vert_F}\Delta W_r.
$$

比较 r 占完整奇异维度的 1% 和 5%，逐矩阵向上取整。原幅度截断回答“删除这些方向会怎样”；范数匹配回答“在相同更新能量下，头部方向是否足够”。两者均保留，不能只画效果更好的那个。

对每个 r，另取同 shape 的随机正交输入/输出基，放入与范数匹配截断完全相同的奇异值。这样 update 的 rank、谱、范数一致，只改变它相对于模型的方向。每个矩阵用可复算 seed42 派生随机数；这是静态随机控制，不新增训练 seed。其低 rank 基为随机正交基，而非打乱 SVD 的符号；联合翻转 U/V 列符号不会改变矩阵，不能当随机方向干预。

目标图：RKL 随 rank 比例曲线、原幅度与范数匹配成对对照、同谱换方向对照。若 top1% 在 accuracy 论文中足够、在我们的 RKL 中不够，应解释为评价目标不同，不改动指标去追求复现。

### A2. 真实窗口更新的早期空间内／外功能拆分

**核心问题是后期新方向在做什么：它们是纠正独立题目所必需，还是只消耗参数位移。** 已有 frame overlap、能量捕获、终点 top-r 与 missing 补回都不能替代这个问题。旧实验的 logit 请求平行／垂直分解也不等于这里的参数更新空间分解。

首轮固定 E99/E101、早期锚点 e=128、窗口 a=320→b=640、k=64，覆盖全部 28 层×7 类投影。先保持设置相同比较两组，不按各自结果调 rank。首轮有明确功能差异后，增加 480→640 检验末段，128→320 提供较早窗口对照；最后才扩 k=16/32/128/256、锚点 64 及其他家族。初始 0 没有更新 frame；所有 frame 都只用窗口开始之前已经形成的更新估计。

#### 分解对象与数值核验

逐矩阵读取真实 FP32 checkpoint，在 FP64 中计算：

$$
E=W_e-W_0=U_e\Sigma_eV_e^\top,\qquad
D=W_b-W_a,\qquad V=V_{e,:k},
$$

$$
D_{\rm in}=(DV)V^\top,\qquad
D_{\rm out}=D-D_{\rm in}.
$$

E 是早期累计更新，D 是后续窗口净更新；不把二者交换，也不使用完整权重 W_e 的 frame。实现不显式构造输入维度平方大小的投影矩阵。核对 D 的重构、Frobenius 正交、内外能量相加，以及换用相同子空间的另一组正交基后结果不变。另记录锚点的第 k/k+1 奇异值间隙，避免把近简并方向的基变化当成物理旋转。

能量占比只作为几何描述。一个低能量分量仍可能通过高敏感输入产生较大函数作用；因此原幅度功能删除是主检验，范数恢复只作附加对照。

#### 保留非目标参数的贡献

把全部参数分为七类投影 M 与其余参数 N。记 D_N=theta_b,N−theta_a,N。定义：

$$
\theta_M(\alpha,\beta)=\theta_{a,M}+\alpha D_{\rm in}+\beta D_{\rm out},
\qquad \theta_N(\alpha,\beta)=\theta_{b,N}.
$$

| 条件          | 参数设置         | 用途                                                    |
| ------------- | ---------------- | ------------------------------------------------------- |
| 真实起点      | theta_a 全部参数 | 自然窗口的原始风险                                      |
| 真实终点      | theta_b 全部参数 | 自然窗口的真实收益                                      |
| 辅助基线      | theta(0,0)       | 仅非目标参数走到终点，显式测 embedding/head/norm 等贡献 |
| 仅空间内      | theta(1,0)       | 保留窗口空间内更新，删除空间外更新                      |
| 仅空间外      | theta(0,1)       | 保留窗口空间外更新，删除空间内更新                      |
| 完整重构 gate | theta(1,1)       | 必须重构真实终点，不能让非目标参数策略制造差异          |

每个条件都从不可变 checkpoint 恢复，不能在前一个条件上继续累积编辑。编辑和 no-edit 使用相同评分精度与引擎；记录 BF16 前向实际扰动的范数、投影泄漏与舍入偏差。无编辑重载及完整重构 gate 先通过，才解释很小的 RKL 差值。

#### 功能贡献和交互分别报告

以固定 bank 的同一损失 L 评分，真实窗口收益为：

$$
G_{\rm natural}=L(\theta_a)-L(\theta_b).
$$

以辅助基线为共同起点，定义：

$$
G_{\rm in}=L(\theta(0,0))-L(\theta(1,0)),\qquad
G_{\rm out}=L(\theta(0,0))-L(\theta(0,1)),
$$

$$
G_{\rm both}=L(\theta(0,0))-L(\theta(1,1)),\qquad
I=G_{\rm both}-G_{\rm in}-G_{\rm out}.
$$

I 描述这组有限编辑的非加性交互，不把两种正交参数能量误当成可加功能收益。还直接报告删除空间外造成的损伤 L(theta(1,0))−L(theta_b)，以及删除空间内造成的损伤 L(theta(0,1))−L(theta_b)。损伤为负意味着删除该部分改善了这套固定 bank，仍需独立题目确认。

主表使用绝对 RKL 和绝对成对差值。只有 G_natural 明显大于数值误差时才报“保留窗口收益比例”；好组末期收益可能很小，此时比例会不稳定，不能强行排序。

#### 原幅度之后再检查幅度与方向

原幅度条件回答自然训练实际积累了什么。若差异清晰，增加空间内、空间外分别恢复到同一完整窗口投影参数范数的对照；另保留逐矩阵能量和缩放倍数，避免把范数恢复当作无扰动编辑。某分量接近零时不做发散的范数放大，标为不可用。

随机右 k 维子空间使用相同矩阵形状、rank 与固定派生 seed42，分别记录投影能量，并用范数匹配比较方向特异性。窗口 D 自己的右 top-k 作为使用未来信息的离线最优低秩能量参照；它不是训练可用的早期 frame，也不是功能最优上界。首轮不把这些控制展开为全 rank 穷举。

有限差分优先沿真实窗口和内／外方向取小比例，再与比例 1 的完整窗口区别。以 theta_a 为起点时，一阶收益分解包含非目标参数：

$$
-g_H(\theta_a)^\top D_{\rm total}
=-g_{H,M}^\top D_{\rm in}-g_{H,M}^\top D_{\rm out}-g_{H,N}^\top D_N.
$$

这三个项相加只对应起点一阶预测。有限差分须使用相同起点、相同方向和同一损失；不能把在辅助基线测的有限收益与 theta_a 的导数直接对账。长窗口误差大时先缩短窗口，不靠修改指标使两者一致。

#### Bank、判断标准与图表

静态预定条件使用现成完整 initial/teacher 双 bank，每套 Math128/Code64/IF64，cap7168；主要判断分别看两套 Math，其他域作为副作用读出。题内有效 token 平均、域内题均值、all 三域等权，保留逐题差值与按 prompt 配对的区间。两套 bank 若共享 prompt，重抽样按共同 prompt 关联，不把两条轨迹当独立题目。

预定条件可以完整报告全 bank；若后续根据结果挑 rank/系数，则先冻结校准/测试 prompt 划分，共享 prompt 的 initial/teacher 轨迹分到同一侧，并只在 calibration 上选。前面的 PAC96 receiver 协议另有固定清单，不能与这里的全 bank 分数无标注混算。

### A5. 后续精确组件干预

在同尺寸组，以完整 thin-SVD 的初始坐标拆解：

$$
W_0=U_0\Sigma_0V_0^\top,\quad C=U_0^\top\Delta W V_0,
$$

$$
D=U_0\operatorname{diag}(\operatorname{diag}C)V_0^\top,
\quad O=U_0(C-\operatorname{diag}(\operatorname{diag}C))V_0^\top,
\quad N=\Delta W-U_0CV_0^\top.
$$

精确核对 Delta=D+O+N 与三部分 Frobenius 正交。测 D-only/O-only/N-only、去 D/去 O/去 N，原幅度优先，范数匹配作解释对照。完整方阵满秩时 N=0；矩形矩阵 N 可非零，不能把 top64 之外全部命名为 null。D 不等于 ISO 的 Sigma 变化，off-diagonal 也不是所有有限旋转的精确等价物。若旋转/通道的作用主要在某层段，再按浅/中/深和 Attention/MLP 作局部干预，先避免全层编辑掩盖跨层补偿。

## 五、阶段 B：固定状态和 teacher 请求，解释方向为何形成

### B1. 用本项目的 full-vocab 目标定义请求

固定 prefix x，student 概率 p、teacher 概率 q，局部 reverse-KL 为

$$
L_x=\sum_vp_v\log(p_v/q_v),\qquad
b_x=-\nabla_zL_x
=-p\odot\left(\log(p/q)-L_x\mathbf1\right).
$$

上述式子温度为 1，仅对固定 prefix 求导；不包含 rollout 分布导数。实际实现如使用温度/额外缩放，须用同配置 autograd 并核对有限差分，不能改用 forward-KL 的 q-p。主实验保留原生 full-vocab 梯度，词表 top-k 只可作带误差测量的工程近似。

以 J_x 为 student logits 对参数的 Jacobian，g_x=J_x^T b_x 为下降方向，固定加权 prefix 集合满足

$$
P=\mathbb E\Vert b_x\Vert^2,\quad
A=\frac{\mathbb E\Vert g_x\Vert^2}{P},\quad
C=\frac{\Vert\mathbb E g_x\Vert^2}{\mathbb E\Vert g_x\Vert^2},
\qquad
\Xi=AC=\frac{\Vert\mathbb E g_x\Vert^2}{P}.
$$

P 是纠正请求的强度，A 是该请求转成参数下降方向的强度，C 是不同 prefix 梯度能否相互加强。分母为 0 时记未定义，不能填 0。对单 prefix 梯度才可称 prefix-level coherence；按响应或 microbatch 估计时须明确分组，因为 C 随分组改变。全参数与选定层的 A 是不同对象，报告覆盖。

### B2. 局部探针备选设置

- 首先 E99/E101，共享同 student 的初始 bank；Math32 个 prompt，固定相对位置 10%/50%/90% 的三个有效 token，最多 96 个 prefix；长度过短/停止位置规则事先固定。小样本用于机制 pilot，不替代完整 bank 结果。
- checkpoints 取 0/16/64/128/320/640；仅在完整轨迹主测量需要定位时启用局部 probe，不能替代本页首节的 96 题 receiver 与独立 source 协议。逐响应梯度与逐 prefix 梯度结果分别命名。
- 每个 teacher 在共享初始状态上计算自己的 b0，冻结坐标、权重和请求。每个 checkpoint 交叉作用于“自身 teacher 的 b0”和“另一个 teacher 的 b0”；由此分开 teacher 请求改变与 student 响应几何改变。live 请求 bt 另画曲线，不与冻结 b0 混称。
- 不构建全模型 Jacobian 或完整 Fisher。用 VJP 逐样本算 J^T b，流式聚合范数与均值；需要局部谱时先用矩阵自由乘法做少量 Lanczos 方向，验证近似误差后再扩展。
- 逐层记录下降方向能量，与既有更新 frame 的内外投影关联；该梯度几何不等同于完整权重的 SVD frame，也不把 NTK eigenframe 旋转与权重 frame 旋转混作同一种角度。

### B3. 小步功能响应与 optimizer 控制

在训练侧校准 source 状态上取下降方向 d，不改变 checkpoint 原文件。用三档递减小步长测 receiver 状态的 KL 变化，检查一阶预测

$$
\delta L_{\rm recv}\approx\nabla L_{\rm recv}^{\top}\delta\theta.
$$

报告预测与实际差值，找到局部近似有效区间，再比较完整 d、早期空间内/外 d、随机方向及等范数方向。receiver 包含未用于构造 d 的 Math 状态和 Code/IF 状态，以及两种 bank 来源。图为 source 域×receiver 域的改善矩阵，加上归一化响应强度；不只画余弦。

Adam 分析优先读取真实 optimizer state，比较 raw gradient、预条件化更新、包含动量与 decay 的实际 delta，并测投影泄漏。若现有 FP32 导出不含 optimizer state，不能由两 checkpoint 差值恢复它；先做 SGD 局部响应并明确标记，后续训练分支才记录 native Adam 更新。

### B4. 欧氏残差为何大而功能差异小

同尺寸组取 e=theta_T-theta_S，以固定状态上的局部 Fisher 能量衡量

$$
Q_S(e)=\mathbb E_x\operatorname{Var}_{v\sim p_S(\cdot\mid x)}[(J_xe)_v].
$$

用 JVP 或小 epsilon 的对称功能扰动近似，不生成全 Fisher。Q 小而欧氏残差大支持“该状态分布上低敏感”；Q 大但端点 KL 小提示非线性、多层补偿或局部近似不适用。先用小 epsilon 检查 epsilon^2 标度，不能把沿 teacher 残差直接走一步改善 RKL 当成机制救援；teacher 同尺寸端点本身就是目标模型。

## 六、阶段 C：固定状态与 rollout 变化分开

已有 initial/teacher bank 可比较来源敏感性，但它们不是各训练时刻的 current rollout，不能从这两套 bank 直接还原训练状态迁移。先检查历史生成缓存是否完整包含题目、token 与生成模型身份；没有缓存时，后续按同 32 个训练侧 prompt，在 step0/128/320/640 各新生成一份 current bank，cap 仍 7168，采样协议不变，独立于 held-out bank。

交叉评分 M_ij=模型 j 在 bank i 的平均局部 KL。相邻 a,b 的对称分解为

$$
R=\tfrac12[(M_{ba}-M_{aa})+(M_{bb}-M_{ab})],\qquad
D=\tfrac12[(M_{ab}-M_{aa})+(M_{bb}-M_{ba})].
$$

R+D=M_bb-M_aa 精确成立；R 是更换 bank 的分布贡献，D 是固定 bank 更换模型的拟合贡献。对 token 权重、prefix 位置、响应长度使用统一规则。这是所选 readout 的有限差分归因，不是完整生成质量的因果分解。没有生成正确性标签时，不写“走向失败轨迹”；只写访问分布改变和固定状态匹配改善/恶化。

| B 显示 coherence 低而局部可达性正常 | 固定数据预算的梯度分组或冲突控制，与原聚合规则对照                             | 净功能响应和独立 bankRKL 同时改善；仅 raw cosine 增大不算           |
| B 显示 fixed-b0 可达性持续下降      | 原始 OPD vs 有限离线准备后 OPD，匹配总更新与 token 预算                        | 准备提高请求响应并改善后续匹配；不把额外预算当准备收益              |
| C 显示跨域广播不足，A 不能解释      | Math-only vs 固定总量替换部分为 Code/IF，teacher 不变                          | 相应域在未训练题上改善；Math 损失同时报告；不与 replay 到 base 混淆 |

训练分支默认单 seed42；从 outer 边界续接，不改 outer 内部代码。选择 step128 时，剩余 512 更新；每个分支总训练预算仍按完整 640 计，前 128 作为共享历史。正式可恢复训练要求 native optimizer、scheduler、RNG 与数据游标均在；若现有九快照仅为分析用 FP32 权重，就不能声称严格 resume，须重跑可恢复前段，或将所有分支统一重置 optimizer 并标成新协议。运行前检查该条件。

投影作用于实际 optimizer delta，或采用明确的低维参数化并说明 optimizer 改变；只投影 gradient 不保证 Adam 实际 delta 受限。decay 策略、有效 token、当前 rollout 更新周期、学习率和两 bank 评分保持匹配。随机空间分支与早期空间分支需报告实际范数及方向泄漏。新 rollout 随模型不同而不同是 on-policy 干预的一部分，不能要求训练轨迹完全相同。

主问题仍按用户选择，优先 E99/E101 的域内机制。历史复核后撤回 17 条件整套扫描作为首轮安排，改为复用 PAC 与传播代码，连接自然 checkpoint 窗口的实际更新，再针对缺口干预。保持 RKL-only；若要论证能力恢复，另定任务正确率与自由生成协议，不把分布匹配改善替代为能力结论。
