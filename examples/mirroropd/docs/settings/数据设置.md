# 数据设置

数学训练使用的 DAPO 及三集/五集验证必须按实际 run 记录版本与题目范围。2026-10-27 记录的默认数学协议为 MATH-500、AMC23、AIME24/25/26；早期三集运行不回填新集合。

下文维护数据来源与题面重合，[数学验证设置](验证设置.md)维护采样与评测预算；[资产准备](../infra/training/资产准备.md)维护转换与检查方法。原 DAPO 17917 条记录含重复题面，原始标签冲突会影响训练正确率诊断；纯蒸馏中是否使用任务奖励以实际 config 为准。

固定 prefix 小实验还需记录 prompt 拆分、完整 token 来源、horizon、mask、归一化和 teacher 缓存身份。共同题池不等于独立 seed；这些实验特有设置写在对应报告，不能套用正式长训练的分母。

## 数据来源与检查

AIME24 使用 [Maxwell-Jia/AIME_2024](https://huggingface.co/datasets/Maxwell-Jia/AIME_2024/tree/8d88b2876a82a080e2f172cc9b25d0d9d2cb4792)，覆盖 I、II 卷各 15 题，数据仓库声明 MIT。AIME26 使用 [MathArena/aime_2026](https://huggingface.co/datasets/MathArena/aime_2026/tree/d61f486805306e6e6b5913504c07763a99e1b112)，共 30 题；MathArena 声明其题面经提取、LaTeX 转换和核验，数据许可为 CC BY-NC-SA 4.0。上游名为 `train` 的存储 split 在本项目只用于验证，转换后标为 `test`。

准备脚本固定这两份数据的上游 revision，检查完整 source ID 集合、题目数、答案范围和唯一记录 ID。转换保留源顺序，不自动删重。2026-10-27 本机检查：两集均无重复题面；使用 Base tokenizer 的 chat template 检查时，最大提示长度分别为 363、360 token，均低于 1,024。完整新数据集中没有验证提示超长。

与当前 DAPO 训练集做题面完全匹配，MATH-500、AMC23、AIME24、AIME25、AIME26 分别重合 2、5、0、0、1 题。**AIME26 有一道训练题面重合，不能将该集描述为完全无污染测试。** 完全匹配只能发现文本相同的题目，不能证明其余题目没有语义重合或模型预训练泄漏。保留完整竞赛集；需要去重对照时另建版本，不改写标准评测结果。

数据路径默认位于仓库同级 `data/`。已有三集和 DAPO 可以离线导入，再单独增加两集：

```bash
python examples/mirroropd/assets/prepare_math_data.py \
  --source-root /已有的/MD-OPD/data --datasets DAPO MATH-500 AMC23 AIME25
python examples/mirroropd/assets/prepare_math_data.py \
  --download --datasets AIME24 AIME26
python examples/mirroropd/assets/check_assets.py --data-only
```

可通过 `AIME24_FILE`、`AIME26_FILE` 覆盖文件路径；原 `AIME_FILE` 继续表示 AIME25。训练和独立验证共用同一默认文件列表与判分路由。旧运行保留当时的三集记录，不能用新增集数回填历史结果。

## DAPO 重复题面与标签核对

按完整 prompt 内容精确比较，17917 条记录有 17255 个不同 prompt，多出的重复记录为 662 条，约 3.69%。这是三组共有的数据条件，不宣称每条记录对应唯一问题。

其中 12 组相同题目有不同 ground truth，共 24 条记录。已回查本机上游原始 parquet，题面和标签与处理后的记录一致，冲突并非本地转换引入。逐题核对后的答案如下，ID 省略 `DAPO-`：
