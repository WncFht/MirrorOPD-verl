# 数据设置

数学训练使用的DAPO及三集/五集验证必须按实际run记录版本与题目范围。2026-10-27记录的默认数学协议为MATH-500、AMC23、AIME24/25/26；早期三集运行不回填新集合。

[数学验证设置](验证设置.md)维护数据来源与训练/验证题面重合；[资产准备](../infra/training/资产准备.md)维护转换与检查方法。原DAPO 17917条记录含重复题面，原始标签冲突会影响训练正确率诊断；纯蒸馏中是否使用任务奖励以实际config为准。

固定prefix小实验还需记录prompt拆分、完整token来源、horizon、mask、归一化和teacher缓存身份。共同题池不等于独立seed；这些实验特有设置写在对应报告，不能套用正式长训练的分母。
