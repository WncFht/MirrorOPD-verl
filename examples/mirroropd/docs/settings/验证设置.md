# 数学验证协议

数学训练与独立验证入口默认使用五个数据集。每题采样 16 次，共 630 题、约 1.01 万条回答；准确率、pass@k、多数投票、长度、截断比例和失败数按数据集分别记录。每集都保留全部题目。

| 数据集   | 题目数 | 每轮回答数 | 指标前缀        | 数据目录                     |
| -------- | -----: | ---------: | --------------- | ---------------------------- |
| MATH-500 |    500 |      8,000 | `eval/math500/` | `math/MATH-500/test.parquet` |
| AMC23    |     40 |        640 | `eval/amc23/`   | `math/AMC23/test.parquet`    |
| AIME24   |     30 |        480 | `eval/aime24/`  | `math/AIME24/test.parquet`   |
| AIME25   |     30 |        480 | `eval/aime25/`  | `math/AIME25/test.parquet`   |
| AIME26   |     30 |        480 | `eval/aime26/`  | `math/AIME26/test.parquet`   |

公共设置为温度 0.7、top-p 0.9、top-k -1、采样开启，回答上限 31,744 token。模型提示模板、non-thinking 设置和数学判分器沿用现有配方。题目只输入问题正文；答案和完整解题过程不进入提示。AIME 答案规范化为 0–999 的十进制整数字符串，例如 `033` 与 `33` 使用相同标准答案。

## TrOPD 评测参考的范围

核对 [TrOPD 仓库](https://github.com/Xingrun-Xing2/TrOPD/tree/a55eda4ced93235b4c8c86125aa777d80b94b576) 后，公开的 [TrOPD 训练脚本](https://github.com/Xingrun-Xing2/TrOPD/blob/a55eda4ced93235b4c8c86125aa777d80b94b576/tropd/recipe/tropd/run_tropd_deepseek_1.5b.sh)默认读取本地 `aime-2024-cleaned.parquet`，验证采样为温度 1.0、top-p 0.7、n=1，响应上限 8,192。仓库未提供该 cleaned 文件的完整可复现构建链，也未找到 AIME26 的 TrOPD 专用评测配置。

因此，本项目借鉴其加入 AIME 的评测覆盖，继续使用本项目统一采样与判分协议，不声称复现 TrOPD 分数。其 README 中 Qwen3-1.7B 对照使用先经过 SFT 的 student；本项目 E54 直接从 Qwen3-1.7B-Base 开始，也不是相同初始化。
