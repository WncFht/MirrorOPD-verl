# 终止动作对齐的配置与实现

E41 的 Full-KL 默认启用终止动作对齐：将 151643 与 151645 视为同一个停止动作，其他 token 仍分别计算 KL。数学目标与已完成的 20 步受控对照一致；正式实现通过配置传递，不依赖实验快照里的临时环境开关。

## 使用方式

原有入口与训练预算保持不变：

```bash
bash examples/mirroropd/run_math_opd_ablation_fsdp2.sh E41
```

复现原始词表 KL 对照时显式关闭：

```bash
FULL_KL_TERMINATION_TOKEN_IDS='[]' \
  bash examples/mirroropd/run_math_opd_ablation_fsdp2.sh E41
```

也可使用最高优先级的 Hydra 覆盖：

```bash
bash examples/mirroropd/run_math_opd_ablation_fsdp2.sh E41 \
  distillation.distillation_loss.full_vocab.termination_token_ids=[]
```

GPU 分配、模型和数据路径仍使用原有启动约定。E41 正式预算没有因此改成 20 步；本目录的效果证据只覆盖 20 步、单 seed、无独立 valid 的实验，不保证默认长程预算下的稳定性或数学准确率提升。

## 两个字段的职责

| 字段                                                              | E41 设置                          | 作用                                |
| ----------------------------------------------------------------- | --------------------------------- | ----------------------------------- |
| `actor_rollout_ref.rollout.stop_token_ids`                        | `[151645]`，另保留模型原生 151643 | 生成器看到结束 token 时停止         |
| `distillation.distillation_loss.full_vocab.termination_token_ids` | `[151643,151645]`                 | 训练 KL 比较两种停止 token 的总概率 |

终止动作对齐不修改 tokenizer、原始模型文件、生成 token 或 teacher 输入序列，也不增加重复惩罚。它保留停止总概率，只去掉停止动作内部的 token 身份差异项，公式与证据见[机制诊断](2026-10-26-终止动作与循环退化诊断.md)。

该配置的通用默认值为空列表，只有 E41 的`full_kl`方法默认启用。其它预设及独立验证不自动启用；E41 切换到其他方法时也不自动继承此默认。若比较 E30 与 E41 的 reuse 效果，需要显式让两者的终止对齐设置一致，避免把目标差异混入 reuse 对照。

## 支持范围与检查

当前支持单轮 shared-sync、teacher-only Full-KL 及其等价端点、`precompute` backend，以及相同输出词表宽度。带 anchor 的 MDPO、BPO、sampled 目标和其他 backend 不支持该选项，不能静默忽略。

配置拒绝负数、bool、字符串、重复 ID 和不足两个成员的非空组。模型初始化时，使用实际 tokenizer、模型词表和生成停止集合检查每个 ID，避免把普通 token 误当作停止动作。启用时不允许`ignore_eos=True`；现有 shared-sync 校验还要求单轮 agent 并关闭多轮生成。

模型之间的 token→ID 映射仍须按原有协议对齐，不能根据跨家族 ID 数字相同推断语义相同。停止等价类只适用于这些 token 确实具有相同下游终止行为的任务。

## 指标与实现边界

| 指标                           | 含义                                     |
| ------------------------------ | ---------------------------------------- |
| `optim/actor/loss`             | 实际优化 loss，保留原有全局 token 归一化 |
| `distill/termination_equiv_kl` | 停止动作对齐后的 KL                      |
| `distill/full_kl`              | 未修改的原始词表 KL                      |
| `distill/eos_identity_kl`      | 原始 KL 减去对齐 KL                      |
| `distill/full_kl_position/*`   | 原始词表 KL 的位置分桶，保持与原实验可比 |

核函数返回可微优化目标和分离的原始 KL 观测；engine 将两者分别传给 loss 和指标。原始位置分桶不被改名为新的优化目标，关闭配置后保持原来的目标和梯度。
