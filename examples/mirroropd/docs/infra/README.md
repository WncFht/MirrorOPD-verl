## 当前结论

| 证据 | 结果 | 适用边界 |
| --- | --- | --- |
| A800，旧 4+4 与 shared，匹配 step2–12 | 145.82→148.54 秒，未加速；actor 阶段和 FSDP allocator 峰值改善 | 两侧均为 eager；共享 run 只有 12 步，无完整验证 |
| One-Shot 历史，21 个 run 中选 3 个完整训练 | 生成占纯训练约 80%；完整验证占已计时工作约 43%–51%；生成 busy 约 32%–38% | A800/A100、算法与数据设置不同；系统采样约15秒 |
| H800 共享四卡，batch64，eager/Graph 各 5 步 | 稳态整步 94.36→35.93 秒，2.63 倍；生成 busy31.71%→88.92% | 编译与 Graph 联合变化；不是目标八卡的实测倍数 |
| H800 共享四卡，32 题×16 验证 | testing804.66→177.53 秒；按实际输出 token 归一化吞吐 4.31 倍 | 子集单次自然生成；独立作业含启动为 2.45 倍；未跑全量 570 题 |
| 固定 seed 与 32×2048 输出 token 的概率开关对照 | 省略概率输出吞吐约 +5.14%，六次 token ID 一致 | 单卡诊断，不能将自然生成长度差全部归因于概率开关 |
| H800 共享四卡，prompt/mini64→128 | 有效 token 吞吐 +53.3%；单步 35.93→47.40 秒 | 改变学习配置，尚未证明达标时间或最终质量改善 |

## 已落地与尚待验证

当前默认是 shared 八卡、FSDP2、V1/TQ、编译＋Graph、验证窗口 32；训练仍为 prompt64、mini64、n1、epoch1。并发 32、推理 token 预算 8192、显存比例 0.5 及 actor 动态 micro 预算 32768 保持原值。验证省略概率，训练保留。这里的“默认”描述源码，不证明接收端已解包到该版本。

验证窗口 64/128、跨窗口持续投喂、并发 64 的常规启用，以及更大的训练 batch 均未设为默认。优先保持训练 64/64，按[验证调优顺序](2026-10-21-批量大小与GPU利用率调优.md#5-验证rollout调度优化)比较窗口，再评估持续投喂。当前没有空闲 GPU 时只进行代码和冻结数据分析，不产生新的 GPU 性能结论。

目标八卡完整 570×16 验证、含保存/恢复的完整周期、长期质量仍未验收。优势/IS 消融与实际 optimizer 更新计数已有实现；新指标的字段、采集粒度和测试边界统一见[训练指标](../metrics/README.md)。
