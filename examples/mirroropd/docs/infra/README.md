## 当前结论

| 证据 | 结果 | 适用边界 |
| --- | --- | --- |
| A800，旧4+4与shared，匹配step2–12 | 145.82→148.54秒，未加速；actor阶段和FSDP allocator峰值改善 | 两侧均为eager；共享run只有12步，无完整验证 |
| One-Shot历史，21个run中选3个完整训练 | 生成占纯训练约80%；完整验证占已计时工作约43%–51%；生成busy约32%–38% | A800/A100、算法与数据设置不同；系统采样约15秒 |
| H800共享四卡，batch64，eager/Graph各5步 | 稳态整步94.36→35.93秒，2.63倍；生成busy31.71%→88.92% | 编译与Graph联合变化；不是目标八卡的实测倍数 |
| H800共享四卡，32题×16验证 | testing804.66→177.53秒；按实际输出token归一化吞吐4.31倍 | 子集单次自然生成；独立作业含启动为2.45倍；未跑全量570题 |
| 固定seed与32×2048输出token的概率开关对照 | 省略概率输出吞吐约+5.14%，六次token ID一致 | 单卡诊断，不能将自然生成长度差全部归因于概率开关 |
| H800共享四卡，prompt/mini64→128 | 有效token吞吐+53.3%；单步35.93→47.40秒 | 改变学习配置，尚未证明达标时间或最终质量改善 |

## 已落地与尚待验证

当前默认是shared八卡、FSDP2、V1/TQ、编译＋Graph、验证窗口32；训练仍为prompt64、mini64、n1、epoch1。并发32、推理token预算8192、显存比例0.5及actor动态micro预算32768保持原值。验证省略概率，训练保留。这里的“默认”描述源码，不证明接收端已解包到该版本。

验证窗口64/128、跨窗口持续投喂、并发64的常规启用，以及更大的训练batch均未设为默认。优先保持训练64/64，按[验证调优顺序](2026-10-21-批量大小与GPU利用率调优.md#5-验证rollout调度优化)比较窗口，再评估持续投喂。当前没有空闲GPU时只进行代码和冻结数据分析，不产生新的GPU性能结论。

目标八卡完整570×16验证、含保存/恢复的完整周期、长期质量仍未验收。优势/IS消融与准确optimizer更新计数也仍是[待实施方案](../opd-objective/2026-10-21-优势与IS消融及更新计数实现方案.md)，不要把文档示例当作已经可用的环境变量。
