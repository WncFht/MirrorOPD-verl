# 固定谱优化器：用经过验收的极分解替换重复 SVD

ISO frame optimizer 的主要成本是每一步对 U、V 各做一次 FP64 SVD，再取其极分解。**本轮把靠近正交框架时的极分解改写为 GPU 矩阵乘，并保留精确 SVD 回退。** 18 种真实 checkpoint 框架形状的算子基准全部通过；三种形状的四步完整 FactorAdam 对照快约 8.4–17.2 倍，权重相对偏差不超过 1.11×10⁻⁷。

## 改了什么

| 路径             | 原实现                             | 新实现                                                      | 对实验定义的影响                     |
| ---------------- | ---------------------------------- | ----------------------------------------------------------- | ------------------------------------ |
| U/V 回缩         | 对每个框架重新 SVD，取左右框架之积 | FP64 Newton–Schulz 求 Gram 逆平方根；通过正交误差检查后使用 | 求同一个薄极分解；未通过则回退原 SVD |
| 仅谱梯度         | 计算完整 UᵀGV，再取对角线          | 按矩阵长宽选择 `(G@V)*U` 或 `(G.T@U)*V`，沿列求和           | 同一链式梯度，省去一次无用矩阵乘     |
| CPU offload 检查 | 只检查 U 的列范数                  | 同时检查 U/V                                                | 补齐原检查范围                       |
| 旧运行与默认值   | SVD                                | 默认仍为 SVD；新任务可指定 `--retraction newton`            | 冻结队列和已有证据不变               |

实现位于 [retraction.py](../../../../research/studies/spectral/iso/retraction.py)、[training.py](../../../../research/studies/spectral/iso/training.py)。精确完整权重谱和更新谱仍使用 SVD，这项优化只针对训练中的极分解回缩。

## 数值方法和回退条件

对高矩阵 X，薄极分解为 `Q=X(XᵀX)^(-1/2)`。输入框架经过小 Adam 更新后通常仍接近正交，因此 Gram 接近单位矩阵。实现先要求 `||XᵀX−I||F≤0.5`，再迭代计算逆平方根，最后检查完整 `QᵀQ−I` 的最大元素误差不超过 10⁻¹⁰。超出邻域、未在六次内收敛或最终检查失败，都使用 FP64 `gesvd`。宽矩阵转置处理，再还原形状。

这与用 QR 获得任意正交框架不同：基准直接比较新旧极分解和重构权重。迭代阶段使用 FP64，最后按原训练流程舍入为 FP32。远离正交框架的随机输入也已验证触发 SVD 回退。

## GPU 实测

H800、两次同步计时；真实 R1-Distill 1.5B/7B、Qwen、Llama、MiMo 第 0 层 q/k/up 框架，按形状去重，共 18 种。对框架添加逐元素标准差 10⁻⁵ 的合成扰动，测回缩而不包含初次 checkpoint SVD。

| 验收           | 结果                                                   |
| -------------- | ------------------------------------------------------ |
| 真实形状覆盖   | 18 种，全部通过                                        |
| 极分解算子加速 | 3.5–38.9 倍，按形状分别统计                            |
| 误差检查       | 极分解相对误差、完整正交误差、重构权重相对误差均 ≤10⁻⁹ |
| 最大显存分配   | 5.69 GB，包含初次分解与基准临时张量                    |
| 回退           | 非正交随机输入触发 SVD，与参考一致                     |

完整优化器另外使用固定 seed 的随机权重和同一组随机梯度，每个形状四步、学习率 10⁻⁵。它覆盖梯度链式计算、AdamW、回缩和权重重构；计时包含第一次状态分配。

| 权重形状  | SVD 四步总耗时 | Newton 四步总耗时 |   加速 | 最大权重相对偏差 |
| --------- | -------------: | ----------------: | -----: | ---------------: |
| 256×1536  |         .573 s |           .0495 s | 11.58× |                0 |
| 1024×2048 |        3.775 s |            .220 s | 17.15× |        8.64×10⁻⁸ |
| 2048×2048 |       12.594 s |           1.496 s |  8.42× |        1.11×10⁻⁷ |

第一行受首次状态分配影响较大，去掉首步后约 27.1×；其余约 16.9×/8.3×。表中保留全部测量，不只报告暖态最快值。实际长训练还包含模型前向、KL、反向、采样、初始化和读出，因此这里的倍数是**优化器步骤**收益。

## 真实 DAPO 两步读出：局部等价与低精度放大

另用 Qwen GRPO 配对、第 13 层 k_proj、seed37，在 DAPO 前八题中按相同随机顺序抽两题，各生成最多 128 token、更新两步。两条路径的生成 token 完全一致，更新前训练 RKL 分别同为 .0106788、.0160659。含生成、读出与更新的循环墙钟为 25.55/21.03 秒，约 1.21×；不含模型加载和优化器初始化。

固定 12 行读出在第 0/1 步完全一致；第 2 步平均 RKL 为 SVD .0211589、Newton .0212025，最大逐行差为 .0009722。为定位差异，独立重复并捕获了真实梯度与每步权重：

| 捕获检查                             |     第一步 |     第二步 |
| ------------------------------------ | ---------: | ---------: |
| 两路径梯度                           | 逐元素相同 | 逐元素相同 |
| 更新后 FP32 权重相对偏差             |  4.28×10⁻⁹ |  2.59×10⁻⁸ |
| 转为 BF16 后不同的权重元素 / 2097152 |          1 |         32 |
| 同一后端独立重复的最终逐题 RKL 差    |          — |          0 |

FP64 算子和 FP32 权重的一致性通过，但少量权重跨过 BF16 舍入边界后，完整模型读出已出现可测差异。因此保留默认 SVD，新后端显式启用；后续比较长训练时同时记录实际 KL 和回退率，不要求随机轨迹逐 token 永久相同。[配对读出](data/polar-20261111/online-paired.json)、[真实梯度与权重比较](data/polar-20261111/online-captured-comparison.json)、[BF16 舍入计数](data/polar-20261111/online-bf16-rounding.json)保留完整数字。
