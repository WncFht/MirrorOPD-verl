## 当前能力与交付状态

统一开发分支为 `feat/rollout-composition`；实施清单见[统一接口实施计划](2026-10-31-Rollout统一接口实施计划.md)，命令见[启动说明](usage.md)。原生代码尚未全部交付回 main；主仓库里的文档更新不等于主仓库已经能接受开发分支的新字段。

| 能力                                                 | 当前状态                                               |
| ---------------------------------------------------- | ------------------------------------------------------ |
| 单个 current、initial、teacher、指定 checkpoint 生成 | 已实现                                                 |
| Current＋固定 B，逐轨迹混合或逐 token 融合           | 统一使用 left/right 引用；验证进度见实施计划           |
| Initial＋固定 B                                      | 已实现；initial 始终指 learner 原始初始化              |
| 任意固定 A＋固定 B                                   | 已写入独立左右绑定；GPU 验证进行中                     |
| 概率算术融合与 logit/log-prob 几何融合               | 已实现                                                 |
| 常数/线性系数与批内固定版本、seed                    | 已实现                                                 |
| Batch 配额某侧为空时只执行另一侧                     | 已实现                                                 |
| Token alpha=0/1 自动成为单模型执行                   | 计划与运行时已归一化；GPU 验证进行中                   |
| 两侧任意模型引用的新统一字段                         | 已替换公开 schema；旧字段明确报错                      |
| 单节点 FSDP2、TP1/TP2、双 replica 基础路径           | 已有实现与分范围证据；不外推为所有组合完整交付         |
| 普通主入口的推荐默认值与最终发布                     | 待后续计划收尾；开发入口的能力不能直接算作 main 已交付 |

生成用 B 不必是监督 teacher；改变 rollout 来源不改变 learner、监督目标、anchor 或更新预算。两种 mixture 统一使用模型引用，alpha 表示右侧权重。目标语义在端点自动归一化为 single(left/right)，无需用户另改 mode。
