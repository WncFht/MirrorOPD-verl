## 配置迁移

新运行只接受 `model/left/right/right_weight`；不增加旧字段自动转换层。`single` 的默认模型为 current，mixture 的默认左右引用为 current 和 teacher。明确指定配置时，single 使用 model，mixture 使用 left/right，禁止混用。

| 原字段                                    | 新字段                                                 |
| ----------------------------------------- | ------------------------------------------------------ |
| `source=student, student=current/initial` | `model.kind=current/initial`；mixture 使用 `left.kind` |
| `source=teacher`                          | `model.kind=teacher`                                   |
| `source=checkpoint, model_path=A`         | `model={kind: checkpoint, ref: A}`                     |
| `teacher_model_path=B`                    | `right={kind: checkpoint, ref: B}`                     |
| `teacher_weight`                          | `right_weight`                                         |

Fusion 默认选择 vLLM；HF 为显式参考后端。历史运行配置与数据不改写，复现时使用其冻结代码。资产 ID 解析保留；历史路径投影只用于读取历史材料。必要的 vLLM 子模型配置适配保留。

## 实施记录

核心提交为 `1913418f`（统一引用、计划和运行时）、`7c84f5f8`（归一化预检与资产检查）、`1032d17f`（恢复后的固定来源驻留）、`3ae4d80f`（单模型阶段保持公共采样边界）、`5cc0750c`（从配置读取 checkpoint 位置）和 `9ca998f0`（具名采样器控制 RPC）。代码未增加性能调参、自动失败重试或新的研究设置。

策略与后端 CPU 回归 236 项通过；实际 Ray/TQ 的成功、scorer 失败和取消检查 3 项通过。入口、资产和历史报告检查共 315 项，其中 2 项旧模型目录名断言改为规范资产身份后复测通过。单模型采样器切换与具名 RPC 的定向检查 24 项通过，checkpoint 位置与报告检查 16 项通过。三个文档命令分别完成最终配置解析。

GPU 5 上，右侧 current 已完成两轮更新、保存、手动恢复及第三轮更新。系数依次为 1、0.5、0，实际执行依次为右侧单模型、双模型融合、左侧固定模型。模型、Adam 状态、RNG 和学习率调度器均从第 2 轮恢复，成功更新计数推进到 3。固定 A/B 的概率融合与 batch fusion、固定模型＋右侧 current 的 batch fusion、默认 single 均完成各两轮真实更新。两组 batch 检查逐轮验证五个来源，共 40 条有效验证记录。六段生命周期合计 11 次有效 optimizer 更新，统一审计通过。GPU 配对为 R1-1.5B learner 与 JustRL-1.5B；固定 A/B 检查将 JustRL 放在左侧，R1 固定权重放在右侧。配置为单卡、batch2、response cap16；不把结果外推为其他配对、长上下文或多卡的新验收。

恢复检查曾复现固定模型启动失败：actor 恢复后尚占设备存储，旧 frozen 路径又强制要求 85% 显存比例。修复先卸载 actor，并继承公开配置的显存比例；原失败日志保留。另一个独立反例是两个相等 logits、top-p=0.5：原生默认过滤与既有 fusion 过滤保留的支持集不同。实际 vLLM RPC 又拒绝直接序列化 Python 函数，因此控制调用改为注册的方法名，保留原序列化限制。归一化单模型阶段现在使用公共策略采样器及 processed behavior log-prob，释放 current 阶段时恢复原采样器和 log-prob 模式；默认 single 与验证保留原设置。

运行证据集中在 `runs/rollout-composition-20261031/`。源码、命令、配置、CPU 日志、失败尝试、GPU 验收、环境路径迁移和 main 合并前备份分别留有记录，不将这些流水复制到研究报告。
