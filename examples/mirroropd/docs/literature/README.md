# 外部研究与来源

这里维护论文、公开源码审阅及模型卡原文，明确版本与核验范围；不将外部结果计入本项目已完成实验。

- `learning-signal/`：估计器、支持集与陈旧数据研究。
- `teacher-transfer/`、`transfer-generalization/`：师生谱系、能力获取及 SFT/RL 相关研究。
- `optimization/`：数值精度与优化文献。
