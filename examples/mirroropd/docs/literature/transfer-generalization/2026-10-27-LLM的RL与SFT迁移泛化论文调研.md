## 2. 先统一“泛化”的含义

| 研究对象               | 典型问题                                         | 最容易混淆的情况                       |
| ---------------------- | ------------------------------------------------ | -------------------------------------- |
| 同分布泛化             | 在同一任务分布的新样本上有效吗？                 | 测试集换了题目，并不自动构成 OOD。     |
| 规则或表面形式泛化     | 换符号、卡牌映射、指令模板、视觉外观后还有效吗？ | 输出格式失效可能被计为推理失效。       |
| 难度或长度泛化         | 短推理能否迁移到更长依赖链、更大搜索空间？       | 生成文字更长不等于依赖链更长。         |
| 组合泛化               | 已学原子技能能否组成没训练过的策略？             | 新组合与新知识不是同一件事。           |
| 跨领域迁移             | 数学训练能否提高代码、科学、规划等表现？         | 更少遗忘与相对底模的正迁移要分开。     |
| 跨语言／工具／环境迁移 | 换语言、工具接口或任务环境后是否有效？           | 单一工具下换题与换工具接口的难度不同。 |
| 能力边界               | 在足够采样预算下能解决哪些问题？                 | pass@1 提高不意味着大 k 的覆盖率提高。 |

RLHF 使用学习得到的偏好奖励，RLVR 通常依赖答案或执行结果验证。两者奖励误差、目标和评估方法不同，不应将一类的结论直接套用到另一类。DPO 属于偏好优化，不能在讨论 on-policy 探索时直接等同于在线 RL。

## 3. A 类：SFT 与 RL 的直接比较及反证

### A1. Does Math Reasoning Improve General LLM Capabilities? Understanding Transferability of LLM Reasoning

Maggie Huan 等，2025，arXiv:2507.00432。总优先级 1。[^a1]

论文先评估 20 多个推理模型，再从 Qwen3-14B-Base 出发，用同一批数学问题做 SFT/RL 对照，评估数学、其他推理和非推理任务。该设置中 RL 的跨域表现与通用能力保留更好。更有价值的是第 5 节：把 on/off-policy、训练目标和 KL 拆开后，on-policy SFT 也比离线 SFT 更能保留通用能力。

阅读重点：第 2.2 节控制实验、第 5.2 节消融。同一批问题不意味着相同监督：SFT 使用教师完整 CoT，RL 使用标准答案奖励。表示漂移与性能的对应关系也不单独构成因果证明。应与 A2 配对，避免将其训练配置下的结果推广成 SFT 的固有限制。

### A2. Rethinking Generalization in Reasoning SFT: A Conditional Analysis on Optimization, Data, and Model Capability

Qihan Ren 等，2026，COLM 2026；arXiv:2604.06628。总优先级 2。[^a2]

论文直接复查短训练下的 SFT 泛化失败。主要配置使用 Qwen3-14B/8B、经答案验证的 20,480 条长 CoT 数学数据，并从 1 epoch 延长到 8 epochs。部分跨域任务呈现先降后升的轨迹，延长训练后可超过底模。数据质量、模型能力同样影响结果；较弱模型可能主要模仿长输出。

阅读重点：第 3 节完整训练曲线、第 4–5 节数据与模型因素。它支持“某些失败来自欠优化”，不支持“训练越久越好”。安全评估还显示推理收益可能伴随安全退化。与 A5 的早期最优现象合看，实验应同时容纳欠拟合和过拟合，而非预设单调曲线。

### A3. SFT Memorizes, RL Generalizes: A Comparative Study of Foundation Model Post-training

Tianzhe Chu 等，ICML 2025；arXiv:2501.17161。总优先级 3。[^a3]

使用 GeneralPoints 算术卡牌任务和 V-IRL 导航环境，考察规则与视觉变化。其设置中，结果奖励 RL 比 SFT 更能适应未见变体；SFT 的格式学习又帮助后续 RL 起步。它的贡献是提供了可控的分布变化，而非只比公开排行榜。

阅读重点：任务设计、第 5.1–5.4 节、限制章节。任务含多模态与交互成分，不能直接覆盖全部纯文本 LLM。正文也报告，极端欠拟合或过拟合的 SFT 初始化会限制 RL。标题应作为该论文的经验结论理解，随后阅读 A4 和 A5。

### A4. Debunk the Myth of SFT Generalization

Xiaofeng Lin 等，2025，arXiv:2510.00237。总优先级 4。[^a4]

在 Sokoban 和 General Points 上，把指令变化与难度变化分开。固定训练指令让 SFT 忽视测试时的新规则；作者用“提示新规则、按旧规则打分”的假环境验证这一解释。提示多样性改善规则泛化，CoT 示范改善更大棋盘、更多箱子或更多卡牌等难度泛化。

阅读重点：第 5 节假环境诊断和第 6 节难度外推。CoT 数据来自经过任务 RL 微调的 Qwen3-8B，并做拒绝采样；因此是强教师知识通过 SFT 迁移的证据，不能解读为整条数据生产链无需 RL。对照时也要计入数据生成成本。

### A5. RL Fine-Tuning Heals OOD Forgetting in SFT

Hangzhan Jin 等，2025，arXiv:2509.12235；采用 2026-05 更新的 v3。总优先级 6。[^a5]

在多个 SFT checkpoint 上接 RL，发现其测试设置中 OOD 表现可能在 SFT 早期达到峰值，随后在 ID 继续上升时退化。RL 往往恢复这段损失，却未超过早期峰值；过度 SFT 后恢复也受限。主实验之外还补充 Open-R1 SFT→DAPO 等证据。

阅读重点：完整 checkpoint 扫描，而非仅比较两个终点。谱分析把现象关联到奇异向量旋转。早期最佳 OOD checkpoint 是事后诊断参照，实际训练不能用最终 OOD 测试集选择模型；需要独立验证集。这篇最适合指导实验基线设计。

### A6. Understanding the Effects of RLHF on LLM Generalisation and Diversity

Robert Kirk 等，2023，arXiv:2310.06452。RLHF 方向优先阅读。[^a6]

在摘要与指令跟随中分析 SFT、奖励模型、RLHF 和 best-of-N。RLHF 在研究的若干 OOD 设置中优于 SFT，同时降低输出多样性。正文的摘要迁移实验里，各方法的 ID–OOD 差距相近，不能把更高 OOD 绝对分数一概解释成更小的泛化差距。

它补齐推理 RLVR 文献缺少的开放式生成视角。阅读时分开看质量、分布变化造成的下降、输出多样性和推理成本；best-of-N 用了更多测试时计算。

## 4. B 类：能力边界、组合泛化和难度外推

### B1. Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?

Yang Yue 等，NeurIPS 2025；arXiv:2504.13837。总优先级 5。[^b1]

跨模型、RL 算法和数学／代码／视觉任务，使用较大 k 的 pass@k 检查可解题覆盖。受测 RLVR 模型在小 k 更好，但底模在大 k 可追平或反超；蒸馏则能引入教师的推理模式。它把“更容易采到正确答案”与“能解决更多类型的问题”拆开。

阅读重点：第 2.2 节指标、第 4 节分析、第 7 节限制。有限采样只能测操作性的能力边界，不能证明某类轨迹绝不存在；结论针对受测公开模型与 RLVR 配方。B2、B3、B4 提供不同探索或课程条件下的补充证据。

### B2. Atomic Skills are the Prerequisite: When Reinforcement Learning Synthesizes Compositional Reasoning, and When It Only Amplifies

Sitao Cheng 等，2025，arXiv:2512.01970；v3 标为 Work in Progress。总优先级 7。[^b2]

使用合成人物知识图谱，区分从参数取知识和从上下文取知识两个原子技能，再测试二者组合。受测设置中，先用 SFT 掌握两种原子技能再 RL，有助于学出组合策略；直接监督复合任务可能在严格未见关系／路径条件下失败。

它的价值是清楚控制知识与路径的可见性。表 2 的 IID、Composition、Structural Zero-shot 必须分别看，不能把约 18% 的严格 zero-shot 成绩写成所有组合测试成绩。原子技能先决条件是此任务体系的证据，不是已经证明的全体 LLM 定理。

### B3. From Reasoning Traces to Reusable Modules: Understanding Compositional Generalization in Language Model Reasoning

Lingjing Kong 等，ICML 2026。[^b3]

用分层潜在选择模型刻画原子技能及信息路由，讨论 RL 探索覆盖与组合泛化。受控实验支持模型从复合轨迹提取可复用模块，再用于新组合；提出让 SFT 覆盖原子模块、RL 探索未覆盖组合的训练思路。

适合与 B2 配对：两篇都关注技能覆盖，但“原子技能覆盖”不等于“只能用孤立原子题训练”。这篇也报告复合轨迹训练在某些设置下更有利。理论需要连同潜变量模型和覆盖条件阅读。

### B4. h1: Bootstrapping LLMs to Reason over Longer Horizons via Reinforcement Learning

Sumeet Ramesh Motwani 等，2025，arXiv:2510.07312。[^b4]

把短题组合为更长依赖链，以自动增加复杂度的课程配合结果奖励 RL。论文报告更难数学、部分 OOD 推理及长上下文任务的收益，并在高 pass@k 下比较，提供超出单纯小 k 提升的证据。

适合研究长度外推与稀疏奖励。关键变量是组合数据和课程，不宜把结果归因于仅仅更换 RL loss。理论样本复杂度结果也依赖其任务假设。

### B5. Reinforcement Learning for Reasoning in Large Language Models with One Training Example

Yiping Wang 等，2025，arXiv:2504.20571。[^b5]

少至一个训练样本的 RLVR，在受测模型中可以带来广泛数学评测收益，并出现训练正确率饱和后测试仍改善的现象。最新版显式讨论格式修正及非格式收益。

建议把它作为分析底模先验、探索与奖励信号的实验入口。一条题目不意味着一次更新、一次 rollout 或极低训练成本；跨数学类别也不等同于广泛跨领域迁移。

### B6. Spurious Rewards: Rethinking Training Signals in RLVR

Rulin Shao 等，2025 首发，ICML 2026；arXiv:2506.10947。[^b6]

部分 Qwen 模型即使接受与正确性关联很弱、随机或错误的奖励，也能获得数学基准收益；其他模型家族不稳定复现同样现象。论文讨论对已有行为的放大。

阅读价值在于基线审计：随机／格式奖励、不同底模家族与真实奖励应作对照。它不证明正确奖励没有价值，而是说明单一底模上的提升不足以识别训练机制。

## 5. C 类：跨领域、跨语言和工具迁移

### C1. When Domains Interact: Asymmetric and Order-Sensitive Cross-Domain Effects in Reinforcement Learning for Reasoning

Wang Yang 等，2026，arXiv:2602.01365。总优先级 10。[^c1]

系统比较数学、科学、逻辑、谜题的单域、顺序和混合 GRPO。迁移有方向性；换训练顺序可改变收益和遗忘，单一策略不能统治所有域。

最适合参考其迁移矩阵和顺序实验。作者限制章节承认，尚未充分拆解预训练覆盖、领域知识重叠和优化动态的原因。因此，把它作为现象地图更合适，不将某一最优顺序普遍化。

### C2. Transferability for General Reasoning: An Automated Curriculum for Multi-Domain RLVR

Yongjin Yang 等，2026，arXiv:2606.25178。[^c2]

TAC 用局部可学习性与梯度方向估计的跨域收益共同调节采样。在六域 GURU 设置、Qwen3 与 Llama 小模型上比较固定采样、人工课程和只看可学习性的课程。

这是从“观察迁移”到“按迁移设计课程”的直接方法。所有域都参与训练时，跨域联合优化成绩不等同于对完全未见领域的零样本迁移；需要检查 held-out 的层级。梯度对齐也是迁移的代理量。

### C3. Absolute Zero: Reinforced Self-play Reasoning with Zero Data

Andrew Zhao 等，2025，arXiv:2505.03335。[^c3]

AZR 自行提出可执行代码任务，并通过执行器检验任务和答案，联合学习出题与解题。测试包含代码和数学，可用于研究自生成课程的域外价值。

“Zero Data”指后训练不依赖外部人工题库，不包括预训练，也不排除执行器提供的反馈。相较静态数学题库 RL，它更适合研究环境反馈能否支持持续扩展。

### C4. Can Tool-Integrated Reinforcement Learning Generalize Across Diverse Domains?

Zhengyu Chen 等，2025，arXiv:2510.11184。[^c4]

在数学任务上训练带代码解释器的 agent，测试不同推理领域；TGRL 结合统一工具接口、奖励分解和结构化提示。

适合做 agent 迁移。需分清工具本身扩展了解题能力、工具使用策略迁移，以及纯参数推理能力变化。也应控制各模型的工具访问、调用次数和输出预算。

### C5. ReasonXL: Shifting LLM Reasoning Language Without Sacrificing Performance

Daniil Gurgurov 等，2026，arXiv:2604.12378。[^c5]

以多语言平行推理数据和 SFT→RLVR，把推理过程转到目标语言，并研究能力保留、跨语言迁移和层级表示变化。

它把“用目标语言思考／输出”和“答题正确”分别作为研究目标。当前主要覆盖英语、德语、法语、意大利语、西班牙语，不能直接外推到中文或低资源语言。

## 6. D 类：机制、遗忘与泛化友好的 SFT

### D1. Why Does Reinforcement Learning Generalize? A Feature-Level Mechanistic Study of Post-Training in Large Language Models

Dan Shi 等，ACL 2026；arXiv:2604.25011。总优先级 8。[^d1]

用 Sparse Crosscoder 将 base、SFT、RL 放进共享特征空间，分析特征演化。作者识别一小组泛化相关特征：在 RL 模型中抑制它们会降低表现，在 base 中增强它们会改善部分表现，并测试未用于特征识别的任务。

优先读第 7.1 节干预，证据强于单看 PCA 距离。但这些干预支持的是所测模型中的功能作用；Sparse Crosscoder 的特征空间不保证完备，也尚未直接推出可用的训练目标。

### D2. Proximal Supervised Fine-Tuning

Wenhong Zhu 等，2025 首发，ICLR 2026；arXiv:2508.17784。[^d2]

PSFT 将 trust-region 思路用于 SFT，限制策略漂移，在数学和人类价值相关设置中研究 ID、OOD、熵及后续优化。它适合作为检验“标准 SFT 配方是否偏弱”的方法基线。

不要因其推导与 policy gradient 联系，就把它与真实 on-policy 奖励探索视作同一过程。也需要分开统计监督信息和训练计算。

### D3. SFT Doesn’t Always Hurt General Capabilities: Revisiting Domain-Specific Fine-Tuning in LLMs

ICLR 2026.[^d3]

较小学习率在其设置中能显著缓解通用能力下降，同时保持相近领域收益；进一步研究 TALR，以及 LoRA、L2、模型平均等基线。

这篇直接帮助修正不公平的 SFT 对照。与 A2 合看，小学习率和训练时长必须联合调节：降低步长却保持短训练，也可能加重欠优化。作者没有声称彻底消除领域适应与能力保留的权衡。

### D4. Clipping Low-Probability Tokens in SFT Yields a Generalizable Initialization for RL

Tian-Shuo Liu 等，ICML 2026。[^d4]

研究底模赋低概率的专家 token 对更新和遗忘的影响，通过 token 级 clipping 改善 SFT 泛化及后续 agent RL。

与 D2 同属约束更新方向，但更关注 token 级学习优先级。不能把低概率直接等同于坏监督：真正的新知识也可能低概率。E5 对“模型兼容性”和“学习价值”的区分可作为补充。

### D5. SFT Conflicts, RL Coexists: A Theoretical and Empirical Analysis of Multi-Task Learning for LLMs

Kejian Zhu 等，2026，arXiv:2608.03573。[^d5]

从多任务梯度干扰研究 SFT/RL 差别，报告 RL 更新更稀疏、任务方向近似正交，并提出 Parallel-RL。

适合从机制角度连接 C1/C2。理论的方差、优势归一化和 on-policy 条件应逐项检查；题目中的“coexists”不能解释成 RL 总无负迁移，C1 已提供需要解释的顺序与干扰现象。

## 7. E 类：SFT→RL 衔接与近期方法

### E1. Selecting Diverse SFT Traces Improves Post-RL Generalization

Dylan Zhang 等，2026-09，arXiv:2609.33780。总优先级 9。[^e1]

固定候选池、样本预算、训练配置与 checkpoint，对比推理路径多样和相似的 SFT 子集；再施加相同 RL。多样路径选择改善困难题和未见环境覆盖，包含单教师条件，减少了教师质量混杂。

阅读重点：第 3.4 节 RL 前的 mixed-reward 诊断，以及等预算筛选。较高 SFT 平均准确率未必意味着更多问题能产生有效的组内优势。这是优先推荐复现实验的一篇；目前是较新的预印本，外部复现仍值得补充。

### E2. Learning What Reinforcement Learning Can’t: Interleaved Online Fine-Tuning for Hardest Questions

Lu Ma 等，2025 首发，ICLR 2026；arXiv:2506.07527。[^e2]

ReLIFT 以 RL 为主，遇到困难问题时获取高质量示范进行 SFT，再继续 RL。目标是同时利用示范的信息注入和 RL 的优化作用。

适合研究低成功率任务的学习瓶颈。比较时必须把外部教师提供的新信息和成本算进去；它是混合训练优势的证据，不是纯 RL 自发获得这些知识的证明。

### E3. When RL Fails after SFT: Rejuvenating Model Plasticity for Robust SFT-to-RL Handoff

Runze Liu 等，2026，arXiv:2606.09932。[^e3]

分析过度 SFT 后 RL 难以提升的情况，关联到过度自信的输出与参数景观；用锚定底模的融合和定向神经元重置恢复可塑性。

适合与 A5、E1 合看 SFT checkpoint 的可训练性。需要测试恢复可塑性是否损失刚获得的领域技能，以及是否优于提前停止等简单基线。

### E4. Finetuning with Sampling: SFT Learns Better Than You Think

Aayush Karan, Sitan Chen, Yilun Du, 2026-10, arXiv:2610.02140.[^e4]

用 MCMC 逐步把 off-policy 专家轨迹变得更符合参考模型的分布，再做 SFT。实验覆盖化学技能、数学及开放式医学问答，并分别评估目标域学习与旧能力保留。

这与 A1 的 on/off-policy 消融形成直接联系：问题可能部分来自示范分布与学生不匹配。应计入采样改写成本；截至检索日为近期预印本，推荐跟进，不因新近结果就推翻已有整条证据链。

### E5. What Should SFT Learn? Conditional Information Gain for Generalizable Post-Training

Yuxuan Gu 等，2026-10，arXiv:2610.12995。[^e5]

CIG-SFT 比较冻结参考模型在有无任务输入时对示范 token 的似然，估计任务条件信息增益，再用于加权 SFT。测试数学与代码泛化，无需在线 rollout。

适合与 D4 配对：底模不熟悉的 token，可能是分布不匹配，也可能正是该学的决策。它提供一种区分方式，但近期预印本的跨模型稳定性、额外参考前向成本仍需检验。

## 9. 如何理解相互冲突的结论

以下是对上述证据的综合判断，不是某一篇论文证明的统一定理。

1. **SFT 的泛化由数据和优化共同决定。** A3 的受控任务显示 RL 优势；A4 改变提示和监督后改变结果；A2 展示长 CoT 学习可能有非单调动态。它们的实验干预不同，不能只按标题投票。
2. **RL 的收益至少分成选择、保留／恢复和学习新组合。** B1 研究采样效率与覆盖；A5 研究恢复；B2/B3 研究组合。三者可以同时发生，不能用一个总准确率识别。
3. **保留底模结构与学习新知识存在张力。** D2/D4 约束漂移，E2 用示范注入新信息，E4/E5 试图提高监督与学生的匹配或学习价值。应同时评估 acquisition 和 retention。
4. **迁移是有方向的。** C1 的顺序效应意味着“数学提升”不能作为所有领域改善的替代指标；C2 进一步将迁移信号用于课程。
5. **SFT 的价值还包括给 RL 提供可探索的起点。** E1/E3 表明，当前最高准确率与后续最可训练性不必一致。

## 10. 阅读和复现时最值得检查的实验条件

| 条件       | 推荐记录                                            | 原因                                       |
| ---------- | --------------------------------------------------- | ------------------------------------------ |
| 初始化     | 精确 checkpoint；base、instruct、distilled 是否混用 | 底模已具有的能力与探索成功率影响极大。     |
| 监督信息   | 题目、答案、完整 CoT、工具反馈、教师身份            | 同题不代表同信息。                         |
| 数据生产   | 教师生成、拒绝采样、改写和验证预算                  | 离线数据也可能隐含大量 RL 或教师计算。     |
| 训练预算   | 总生成 token、优化 token、步数、时间                | 一个样本不等于便宜；相同步数不等于等计算。 |
| 测试预算   | 温度、最大 token、采样数、工具调用数                | pass@k 相同也不一定等 FLOPs。              |
| checkpoint | 全过程 ID/OOD/通用能力曲线                          | 避免只拿过拟合 SFT 终点或欠优化点比较。    |
| 验证划分   | ID 验证、开发 OOD、最终 OOD 严格分离                | 不用最终 OOD 测试集选择最优模型。          |
| 指标       | pass@1、pass@k、格式有效率、长度、多样性            | 分离可用性、覆盖和格式。                   |
| 能力保留   | 相对底模及相对 SFT 初始点均报告                     | 区分新收益与遗忘恢复。                     |
| 跨模型     | 至少两个不同预训练家族                              | B6 显示奖励现象可能依赖模型家族。          |

对于可独立采样、二值奖励的 GRPO，一个提示在组内同时出现成功和失败的概率为：

$$
P(\text{mixed}\mid x)=1-p(x)^G-[1-p(x)]^G,
$$

其中 $p(x)$ 是单次成功率，$G$ 是组大小。全成功或全失败时，标准组内中心化的奖励优势为零；这不排除实现中的 KL 等其他损失仍产生梯度。该式解释了为什么平均正确率不足以预测 RL 信号，应进一步测每题的成功率分布和 mixed-group 占比。E1 对这一诊断提供了实验关联，但它不是泛化的充分条件。[^e1]

## 11. 我建议优先做的研究问题

1. **完整训练动态的公平对照。** 同底模、同题池，联合调节 SFT 学习率和时长；比较 vanilla SFT、on-policy／拒绝采样 SFT、PSFT、RL、SFT→RL。检验 A2 的晚期恢复与 A5 的早期峰值分别出现在哪些数据和能力条件下。
2. **SFT 轨迹覆盖能否预测后续 RL 迁移。** 在固定候选池中控制正确率、长度、教师和样本量，只改变路线多样性；比较 SFT 分数、pass@k、mixed-group 比例对最终 OOD 的预测力。以 E1 为起点。
3. **预先掌握的原子技能如何影响迁移方向。** 使用可追踪的数据生成器，分别控制技能掌握、组合覆盖与领域知识；测试 B2/B3 的条件能否解释 C1 的非对称迁移。

这些是由文献提出的研究建议，尚未在本调研中验证。
