## RQ1：SFT/RL 的泛化差异来自算法、数据还是优化？

### 现象与需要区分的效应

“SFT 记忆、RL 泛化”描述了一组实验现象，却还没有指定原因。SFT/RL 对照经常同时改变示范来源、可见信息、采样分布、目标、梯度估计器、学习率和训练量。相同 prompt 也不等于相同监督：教师完整 CoT 与最终答案奖励提供的信息不同。[^a1][^a3]

最值得保留的是能够改变结论的干预：换提示和示范、延长训练、改变 KL 方向或数据来源后，域外表现如何变化。T0/Flan 的未见任务泛化也说明，狭域长 CoT 微调的失败不能代表全部监督学习。[^f3][^f4]

### 证据怎样推进

| 证据链                                                  | 实际探索                                                           | 支持的结论与边界                                                               |
| ------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| SFT Memorizes → Debunk → Rethinking SFT                 | 从规则/视觉 OOD 对照，推进到提示多样性、CoT 监督、长训练与数据质量 | SFT 泛化具有条件性；不能由某一短训练终点定性算法本身[^a3][^a4][^a2]            |
| Retaining by Doing → Preference Fine-Tuning             | 近策略/初始策略数据；on-policy 与负梯度的作用                      | 数据来源与概率质量重分配是候选机制；偏好优化结果不直接等于数学 OPD[^h01][^n01] |
| Distillation Dynamics 与 Decoupling KL and Trajectories | 独立变化前缀来源、FKL/RKL、学习率及长度                            | 同一采样来源可配不同目标，来源优势依赖目标和优化条件[^h11][^n09]               |
| Towards On-Policy SFT 与 Finetuning with Sampling       | 通过 loss 加权或采样改写，使监督更匹配模型分布                     | 存在折中于离线示范与实时生成的方法；它们并非都实时从当前学生采样[^n03][^e4]    |

沿 Rethinking SFT 的引文补查的 Preference Fine-Tuning、Towards On-Policy SFT，分别从负梯度与分布匹配解释部分差异；它们没有共同建立一个覆盖所有训练目标的统一因果定理。Distillation Dynamics 的控制设计进一步提示：学习率造成的遗忘差异不应全部归为 on-policy/off-policy。[^n01][^n03][^h11]

### 仍然开放的追问

“更少遗忘”可能来自更温和的参数更新，也可能来自更有选择性的学习。二者要在相近目标任务学习程度上比较。若方法几乎不学习目标任务，较小的旧任务下降不能单独证明更好的泛化机制。

近策略 SFT、FKL 蒸馏和 RL 的比较还应记录监督信息量。外部教师改写、拒绝采样和验证的成本属于数据生产预算。将这些成本隐藏在离线数据里，会把“更强的监督”混入“更好的优化”。

### 能区分解释的实验

固定学生起点与题池，将前缀来源、KL 方向和学习率作为可区分因素；保留同批数据的多次更新数与 current-student 概率是否刷新。以目标学习程度、域外变化和总生成/优化 token 共同比较。这个设计受 H11/N09 启发；它不是要求立即执行所有因素的全排列。

## RQ2：RL 学到新能力，还是提高已有解的概率？

### 三种不同的“新”

至少区分单次成功率提高、有限采样预算内能解的题目增多，以及掌握未训练的组合或信息。前两者可以来自概率重新分配；第三者需要任务结构或信息入口的控制。B1 的大 k 覆盖、ProRL 的长程训练、From f(x)… 的组合划分研究的对象并不相同。[^b1][^h03][^g1]

### 从能力边界争议追到可控任务

| 研究                                        | 控制与观察                                     | 对争议的贡献                                                                             |
| ------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------- |
| B1 与 Decomposing Problem Solving           | 大 k 采样；规划/执行/验证分解                  | 某些 RL 收益主要表现为已有解执行更稳定；有限采样不能证明其余解不存在[^b1][^g3]           |
| ProRL、BroRL、How RL Reshapes               | 训练时长、任务多样性、采样宽度及策略选择       | 条件改变后覆盖可扩大，也可在其他任务收缩；覆盖变化不唯一对应支持集变化[^h03][^h04][^h05] |
| From f(x)… 与 Atomic Skills                 | 显式提供原子技能，再控制新组合与新路径         | 先验原子技能是重要条件；具备原子技能仍不自动保证任意组合[^g1][^b2]                       |
| Reusable Modules 与 Compositional Reasoning | 复合轨迹中提取模块；分解任务与组合任务双向迁移 | 复合训练可促进原子能力；仅练原子任务到组合任务的迁移可能较弱[^b3][^n06]                  |
| Causal Reasoning Testbed                    | 查询层级×相关子图规模×模型尺寸                 | RL 优势依赖初始边缘化/计算能力，可把复杂度变化与任务语义变化分开[^n07]                   |

新的数据结构研究使用 Array、BST、Bloom Filter、Hashmap、Heap 等可验证任务，观察到“分解→组合”与“组合→分解”不对称。它与 From f(x)… 并不矛盾：先掌握原子能力是一种前提，不是“只训练原子题足够”的充分条件。[^n06][^g1]

### 仍然开放的追问

新组合成功可能依赖原子操作，也依赖路由、状态表示和中间结果复用。若训练与测试只随机分题，模型可能见过相同组合结构；若直接换整个任务族，又会把知识缺口和组合难度混在一起。应分别定义未见实例、未见组合、未见结构与未见原子技能。

因果推理 Testbed 提供了更细的拆分，但它检验的是因果图上的概率推断能力；模型在这类任务上变好，不等于训练算法对所有任务获得普适因果理解。[^n07]

### 能区分解释的实验

先建立并测量原子技能，再以相同函数/规则构造 IID、新组合、更深组合、结构变化和缺失原子技能五组。同步测每题成功率、大 K 覆盖及局部执行错误。用 G1/B3/N06/N07 的控制方式说明迁移对象，比仅增加竞赛数学年份更有解释力。

## RQ3：新知识能否进入参数、用于推理并保留旧能力？

### 从“会答”追问到“会用”

SE-Bench 用随机 API 映射与闭卷测试隔离知识入口；SDFT 在新事实、科学、医学和工具任务上同时检查 acquisition 与 retention。它们已经超出只看数学推理分数，但知识可回忆与可用于组合推理仍须分开。[^g2][^h07]

### 后续证据

| 研究                                | 实际改变或测量的对象                                                             | 解释边界                                                                               |
| ----------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| SE-Bench                            | 随机 API 名称、文档可见性、单函数与组合调用                                      | API 映射新，库功能未必新；原文的 RL 配方不是全体 RL 的代表[^g2]                        |
| Knowing–Using Gap                   | 支持事实作记忆 QA，多跳 chaining/intersection 作留出题；self-patching 与层间蒸馏 | 直接记忆可先饱和，组合使用仍落后；激活干预支持路由假说，但不证明所有网络同一机制[^n08] |
| Distilled RL                        | 引入教师 token 监督并与 RL 更新组合，含受控新知识案例                            | 新信息由教师提供，不能写成仅靠终局奖励发现了未知事实[^n18]                             |
| SDFT 与 SDPO                        | 示范/反馈条件化自教师，密集监督及旧能力保持                                      | 特权信息、反馈来源和教师更新规则都是额外条件[^h07][^h08]                               |
| Mapping Forgetting 与 Continual RFT | 逐题得失、连续任务及更新选择性                                                   | 后者的主要证据来自多模态连续训练，不能直接覆盖纯文本固定轨迹 OPD[^h02][^n22]           |

Knowing–Using Gap 让问题从“知识是否存在”推进到“知识是否接入有效计算路径”：作者在知识注入后做跨层 self-patching，再以层间表示蒸馏尝试改善组合使用。对当前项目，更有价值的是加入单事实回忆与组合使用两组读出；其具体层间方法是否适合当前模型仍待验证。[^n08]

### 仍然开放的追问

限制策略漂移可以减少旧能力损失，也可能阻碍新映射学习；底模低概率 token 既可能是有害的不匹配，也可能承载必须学习的新信息。PSFT、低概率 clipping、CIG-SFT 分别从更新限制和监督价值处理这一张力，尚无足以统一替代三者的判据。[^d2][^d4][^e5]

“闭卷能回忆”和“完整解决未见组合题”还需要分别与旧任务保持对照。新知识泛化提高也不保证无遗忘；总平均分相近可能掩盖大量逐题替换。

### 能区分解释的实验

保持 teacher 可见文档、student 部署时闭卷的条件一致，分别评测文档内直接查询、闭卷单映射、已学映射的新组合、未提供映射和旧能力面板。比较硬标签、软目标和结果奖励时，逐项记录信息入口。仅凭 GPQA/MMLU 的增益不足以证明模型获得了本实验提供的新知识。

## RQ4：推理训练为什么产生非对称跨域迁移？

### 从“数学泛化”追到迁移方向

Math Transfer 提供数学训练后的科学、代码、规划与通用能力读出；When Domains Interact 将问题推进到训练域×评测域及顺序对照；Every Coin 把教师来源、多域强弱和域外影响纳入 OPD。三者分别约束“数学变好意味着什么”“向哪个域迁移”“是谁的能力被迁移”。[^a1][^c1][^h16]

### 新的六域证据与已有线索

| 证据                                           | 观察                                                                           | 不能直接推出的结论                                           |
| ---------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| Guru 六域研究                                  | Math、Code、Science、Logic、Simulation、Tabular 的迁移不同，某些域需要域内训练 | 作者对预训练覆盖的解释不是对真实预训练语料的完整审计[^n05]   |
| When Domains Interact                          | 单域、混合及顺序训练给出非对称增益与遗忘                                       | 同一最优顺序普适于所有模型/预算[^c1]                         |
| Every Coin                                     | prompt 域外的教师能力/弱点也会影响学生                                         | 所有同源教师总优于跨源；来源标签单独解释全部差异[^h16]       |
| Synthetic Multi-hop 与 Logic-RL                | 合成关系/逻辑训练可以改善真实多跳或数学                                        | 模型从虚构事实学到了真实测试事实，或所有方向都有效[^g5][^g6] |
| Agent Generalization Tax 与 Tool-Integrated RL | 状态信息、规划复杂度、工具可用性和思考模式影响迁移                             | 动态工具带来的能力增量等于纯参数推理迁移[^h15][^c4]          |

沿 From f(x)… 的参考文献追到 Guru 后，可把已有“数学/代码/科学”面板扩大为六域假设地图。Simulation 和 Tabular 尤其适合检验迁移是否只发生在相近的公开推理题型之间。不过，这不意味着要立即把六域都加入训练；纯数学训练首先只估计迁移矩阵中的一行。[^g1][^n05]

### 语言迁移还要测输出行为

ReasonXL 区分目标语言推理/输出与答题正确；Every Coin 评中文数学与长程组合。改变语言而保持题义，仍应检查题目配对、输出语言、格式和推理预算。Global-MGSM 与原始 MGSM 的差别由 benchmark 对应表单独维护，不能混成一个结果。[^c5][^h16]

### 仍然开放的追问与可区分设计

迁移方向可能由共享原子技能、初始目标能力、训练域的搜索需求、教师多域能力或参数干扰共同决定。先在相近目标难度与明确教师能力差下比较，再做多方向训练，才能判断某种机制是否比“目标域原本更容易”多解释了现象。

以逐域 S0 参照和训练域×评测域矩阵报告结果；同时记录 teacher 在各域的能力。机制层若考察梯度迁移，应使用实际参数位移：当目标风险 R 在更新附近二阶可微且 Hessian 有界时，Taylor 展开给出：

$$
R(\theta+\Delta\theta)-R(\theta)
=\nabla R(\theta)^\top\Delta\theta+O(\lVert\Delta\theta\rVert^2).
$$

该式只是局部风险近似。Adam 的实际位移一般不等于负学习率乘原始梯度；固定分布风险的梯度对齐也不直接等于任务成功率变化，更不能代替跨域实测。

## RQ5：更强教师为何不一定更可学，局部 KL 何时有用？

教师前序/参考的相对变化已有独立专题：[Delta OPD 分类与研究问题](../teacher-transfer/2026-10-31-Delta-OPD论文分类与研究问题综述.md)，集中比较 Direct/Proxy/W2S、OPD²、Compass、选择性增量及多教师构造；本节保留一般的可学习性问题。

### 把教师价值拆成三个问题

教师单独解题是否更强、教师在学生前缀上能否给出有价值的纠错、学生是否能通过有限更新学到纠错，是三个不同问题。Rethinking OPD 的师生思考模式与增量能力分析提供起点；Every Coin 的来源比较进一步显示教师影响会越过训练领域。[^n10][^h16]

### 从兼容性追到干预和未来轨迹

| 研究                       | 对原问题的推进                                           | 主要证据边界                                                                  |
| -------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Rethinking OPD             | 教师分数不足以预测蒸馏收益，分析高概率重叠与冷启动       | 主配置包含 student top-k 估计器，不能直接视为所有 full-vocab 方法的限制[^n10] |
| Token Teachability         | 固定上下文下检查 KL 改善，将分歧与局部可达质量结合       | top-K 是操作性局部支持，不是整个模型的真实零概率支持[^n11]                    |
| Supervision Fidelity Decay | 长学生前缀上教师信号减弱，以后一步信号改善局部指导       | 教师置信度是代理量，不等于答案正确或长期价值[^n12]                            |
| Controlled Token Flips     | 在学生轨迹分歧处直接干预，再观察正确率和 fork resolution | 解码时可恢复价值不等于参数训练能吸收同样收益[^n15]                            |
| FutureBridge 与 LENS-OPD   | 让学生接着教师 bridge 继续走，检验未来轨迹与内化         | 需要额外生成/环境预算；教师相对正信号仍不必等于外部任务奖励[^n13][^n20]       |
| Offline Learnability       | 从成功题蒸馏得到的 likelihood 变化估计失败题监督价值     | 属于操作性代理，存在选择偏差与额外蒸馏阶段[^n14]                              |

Controlled Token Flips 的价值在于提供训练过程之外的教师能力证据：保持学生参数不变，只改变某些决策。如果干预可恢复而训练无法恢复，瓶颈更接近可学习性或优化；若干预也无效，则需重新判断教师在这些学生状态上是否有效。此推断还依赖干预预算、选择规则和继续生成的策略。[^n15]

### 对 full-vocab 固定状态的特殊边界

当前协议已经在固定学生前缀上对全词表求 RKL，因此不能直接套用“教师偏好落在学生 top-k 之外、没有进入估计器”的解释。但全词表有梯度并不保证梯度在有限预算内有效，也不保证教师的局部偏好与任务收益一致。Vanishing Learning Signals 的主实验与其 full-KL 理论/补充对照也需分别解读。[^n21]

应把全文中的“不可达”拆成未进入截断估计器、概率极小、有限预算不易学、策略类不能表达、教师纠错不提升任务五种情况。它们需要不同证据；同架构、存在共同初始化、低 KL 和高 overlap 不能互相替代。

### 能区分解释的实验

在共同固定前缀与共同 token 支持口径上，分别测初始局部分歧、一步/多步拟合、held-out 风险、当前学生任务评分；如果需要判断教师纠错价值，再对少量代表题做受控分支干预。把“监督有价值”与“监督可吸收”分开，避免以单一 overlap 分数结束机制解释。

<a id="rq6"></a>

## RQ6：fresh rollout 何时必要，固定轨迹何时更好？

### 学生与教师都存在分布问题

fresh student rollout 对当前学生是近策略数据，但可能进入教师不熟悉或无法有效纠错的前缀；固定初始学生轨迹避免某些漂移，同时越来越偏离当前学生。在线/离线标签无法单独决定两者的净收益。Semi-OPD 和可实现性研究分别从实证与理论给出条件化解释。[^h12][^h10]

### 现有探索与进一步延伸

| 研究                             | 处理的变量                                      | 留下的问题                                                          |
| -------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------- |
| Semi-OPD                         | 固定初始轨迹；当前学生项每次重算；跨师生配对    | 主要数学证据是否延伸到 Code/Science/IF，full-vocab 时是否相同[^h12] |
| Online IL under Misspecification | 学生策略类是否可表达教师；在线互动的信息作用    | 表达能力、有限优化可学习性和真实任务误差如何对应[^h10]              |
| Decoupling 与 Dynamics           | 前缀来源×目标；学习率和长度                     | 单独变化来源时，目标学习程度及生成成本如何对齐[^n09][^h11]          |
| Offline Learnability             | 固定轨迹里保留教师失败题的可用信号              | 失败题筛选/加权的收益是否能与额外蒸馏阶段解耦[^n14]                 |
| Interpolated Policy Distillation | 每 token 显式混合师生分布，并保持采样分布的实现 | 混合系数、教师调用成本和训练目标间的交互[^n19]                      |
| FTB/LENS 的桥接与验证            | 在状态漂移后短暂介入，再测学生继续轨迹          | 收益来自更好状态覆盖、更多教师信息还是验证筛选[^n13][^n20]          |

IPD 提供一种比“整条轨迹来源二选一”更细的连续控制；它的 speculative 实现也不能直接与只改 prompt 比例或分段接管混称同一种采样机制。效果比较要同时给出教师前向、生成 token 与学生优化 token。[^n19]

### 仍然开放的追问

固定轨迹拟合好但 fresh 失败，可能是访问分布漂移、局部任务价值不足，也可能是截断、格式或生成预算造成。需要在同一题上同时做 fixed 与 fresh 观测，才能定位是哪一层变化。

既有同一数学任务的离线优势也不保证跨域更好：固定数学前缀可能保留某类稳定行为，也可能缺少迁移目标所需状态。对当前项目，这正是补独立 Code/Science/IF 任务评分的理由。

### 能区分解释的实验

比较固定 S0、周期刷新与逐步 fresh 时，至少选择一种明确预算口径，再附其他成本。所有分支的概率刷新、教师缓存、每 rollout 更新数和长度上限独立记录；评测统一由当前学生无约束生成。不要把固定初始轨迹与“所有 teacher/student 概率都冻结”混为一谈。

<a id="rq7"></a>

## RQ7：什么样的 SFT 初始化最有利于后续 RL/OPD？

### 终点分数与可训练性不是同一排序

Quagmires、路线多样性与可塑性研究都提示：更高的 SFT 分数未必意味着更好的后续收益。Rethinking SFT 的晚期恢复与 Heals 的早期峰值又说明，比较必须追踪过程，而不是预设“越早越好”或“训练越久越好”。[^h06][^e1][^e3][^a2][^a5]

### 沿数据与优化问题继续追查

| 研究                           | 所控制的因素                                              | 对初始化选择的含义                                                  |
| ------------------------------ | --------------------------------------------------------- | ------------------------------------------------------------------- |
| Reasoning Patterns             | 相同问题、两个教师来源的验证 CoT；比较分支/探索行为       | 更低 SFT loss 不等于更好的推理模式；来源风格可影响泛化[^n02]        |
| Data Repetition                | 固定更新预算，改变独立数据量与重复次数；测 AIME/GPQA      | 重复小题池可优于单遍大池；并不推出 OPD 或所有分布也应减少覆盖[^n04] |
| Diverse SFT Traces             | 相同候选池/预算，改变推理路线多样性，再做相同 RL          | 初始化要测每题解覆盖及组内奖励差异，而非只看均分[^e1]               |
| Quagmires                      | 多模型/数据，比较 SFT 分数、held-out loss、大 k 与后续 RL | 可以研究预测量，但预测相关不证明干预该指标就导致收益[^h06]          |
| PSFT、低概率 clipping、CIG-SFT | 改变更新约束或 token 学习权重                             | “少漂移”与“学到新监督”仍要同时测[^d2][^d4][^e5]                     |

Data Repetition 将“见过更多独立题目是否总更好”变成可检验的预算问题。它对你反复使用题池的研究有启发，但其主要设置是 long-CoT SFT：不能直接用于推翻当前只展示 0–320 更新的协议，也不能把 SFT token accuracy 的停止条件当作 OPD 的既定规则。[^n04]

对于组内中心化、独立采样、二值结果奖励，单题成功率 p、组大小 G 对应组内同时有成功和失败的概率：

$$
P(\mathrm{mixed}\mid x)=1-p(x)^G-[1-p(x)]^G.
$$

全成功或全失败时该结果奖励优势为零；KL 或其他损失仍可产生梯度。因此平均成功率不足以说明后续 RL 信号密度。这个诊断不能直接套给以密集教师 log-ratio 为监督的 OPD，也不是泛化的充分条件。[^e1]

### 能区分解释的实验

对共同 SFT 深度记录目标分数、逐题成功率分布、pass@K、格式/长度、独立题覆盖、teacher-state/fixed-state 风险及后续训练后的多域变化。比较路线多样性时控制教师、正确性和长度；比较重复与覆盖时显式对齐预算。将这些量用于预测 OPD 收益仍是待验证问题。

<a id="rq8"></a>

## RQ8：多教师按领域路由能否隔离干扰并整合能力？

### 从“谁教”追到“教什么、教多重”

MOPD 提供共享起点领域专家到统一学生的整合范式；Every Coin 显示，教师影响并不局限于其负责的 prompt 域；Open-MOPD 又将整合差距与 token 预算、收敛速度和奖励刷新联系起来。三者要求把领域路由与干扰控制分开。[^h17][^h16][^h18]

### 机制竞争与后续工作

| 候选机制                         | 代表证据                                                          | 还需要的对照                                                               |
| -------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 长度/计算份额不平衡              | Open-MOPD 的 token-share 与 gap-aware 调度                        | 固定域内实际 token、每域处理量及优化次数[^h18]                             |
| 信号尺度不平衡                   | DN-MOPD 按反馈 spread 归一化；相近固定权重也有效                  | 调低某域与提高另一域分开，不把所有收益归为动态算法[^n16]                   |
| 梯度/更新干扰                    | SFT Conflicts 的多任务分析与跨域顺序效应                          | 同一初始化、参数化、估计器和实际 Adam 位移[^d5][^c1]                       |
| 教师终点继承了不必要的 base 偏好 | Delta-MOPD 固定教师选择，改为 teacher-minus-base shift 并重新锚定 | 同状态、同路由、同尺度的 endpoint/shift 比较；依赖 teacher-base 可得[^n17] |
| 表达与可实现性限制               | Online IL 的策略类条件及跨尺寸教师比较                            | 不能用同架构或高 overlap 单独代理可实现性[^h10]                            |

Delta-MOPD 分开研究同一状态上组合教师与跨阶段/交错路由，作者报告 shift target 的优势依赖设置；交错路由下并非普遍更强。因此“只蒸馏训练增量”是一个可测设计轴，不是已经替代终点教师的通用结论。[^n17]

DN-MOPD 与 Open-MOPD 对 IF 的失衡方向和具体诊断应在各自设置内理解。一个论文里的“IF 被长轨迹域淹没”与另一个设置中的“IF 信号尺度主导更新”并非逻辑冲突：token 份额和每 token 信号尺度是不同因素。[^h18][^n16]

### 能区分解释的实验

优先保留 S0、每位教师、单教师学生及统一多教师学生四类参照。再依次观察路由、token 份额、信号尺度、刷新、目标构造和参数位移的作用。多个领域都参加训练时应称能力整合；只有另留未训练领域/任务族时，才能另外讨论对应 OOD 迁移。

<a id="rq9"></a>

## RQ9：什么证据足以称为泛化、迁移或新能力？

### 把主张与证据逐一对应

| 主张               | 最低需要的读出                                       | 常见误判                                     |
| ------------------ | ---------------------------------------------------- | -------------------------------------------- |
| 拟合教师条件分布   | 同一前缀/支持口径上的风险与留出风险                  | 将 KL 降低直接写成任务能力迁移               |
| 同域泛化           | 不参与本轮及已核查历史更新的独立题                   | 换一次 rollout 就称未见题                    |
| 跨域迁移           | 未训练领域的当前学生任务评分，相对 S0                | 多域都训练后的总分被称为零样本迁移           |
| 旧能力保持/恢复    | 原始模型、SFT 起点与全过程参照；逐题得失             | 只超过退化起点就称新增能力                   |
| 新组合             | 原子能力测试、新组合/结构/深度划分                   | 随机分题但组合结构仍重合                     |
| 新知识内化及使用   | 新信息入口、部署时信息撤除、直接回忆与组合使用       | 预训练可能已见的事实题提高被称为新知识       |
| 覆盖扩大           | 同题相同采样/长度预算的 pass@K 曲线                  | avg@K 与 pass@K 混用或将有限失败当作概率为零 |
| 教师监督有因果价值 | 受控 token/turn 干预，观察学生后续轨迹与外部任务结果 | 教师熵、overlap、正 log-ratio 单独证明正确性 |

### 三组最值得保留的判别量

固定状态风险可记为：

$$
R_{\mu}(\theta)=\mathbb E_{s\sim\mu}
D_{\mathrm{KL}}\bigl(p_\theta(\cdot\mid s)\Vert q(\cdot\mid s)\bigr),
$$

其中 μ 是事先固定的前缀分布、q 是固定教师。它与当前学生轨迹上的期望奖励分别依赖状态分布与目标；二者没有由定义自动得到的单调关系。当前项目既有 H1024 分母、EOS 和支持口径继续按公共协议解释。

对相同 n 道题的等权、二值配对评分，记 n01 为“原错后对”、n10 为“原对后错”，则：

$$
\Delta A=(n_{01}-n_{10})/n.
$$

平均分不变也可能伴随大量得失。随机解码时应重复采样并按题目聚类；一次 1→0 不是知识永久消失的充分证据。Mapping Forgetting 的 MCQ chance-adjusted 指标还带有其特定假设，不能直接套给代码执行。[^h02]

独立同分布采样且单次成功率为 p 时，至少一次成功的理想化概率为：

$$
\operatorname{pass@}K=1-(1-p)^K.
$$

avg@K 则估计单次成功率 p。跨题分布改变后，二者的平均变化可以不同。若独立采样 m 次均未成功，单侧 95% 二项置信上界为 1−0.05^(1/m)，并不能断言 p=0；长度截断和采样策略改变后，所估计的 p 也改变。[^b1][^h13]

### 复查工作如何改变阅读结论

Does self-distillation improve reasoning? 把代码训练题与留出题、科学学科间的迁移及 thinking mode 分开后，得到与只看训练表现不同的判断。这个案例支持加强划分与对照，而不是把结论扩大成全部自蒸馏无效。[^h09]

对公开 benchmark，去重最多支持已经检查的训练阶段；HF 的 split 名、题目日期较新或换了 seed 都不证明预训练未见。代码、数学、IF 各用对应评分器，记录 think 块处理、解析失败、空回答、截断和执行超时。输出变长、反思词变多、格式改善都可能参与分数变化，不能单独作为机制证据。

## 对当前 transfer-mechanism 最值得继续验证的问题

按新增证据的区分力排序，建议保留三个主问题：

1. **教师的有效纠错在哪里，为什么有的教师难吸收？** 联合 RQ5/RQ6，对共同固定前缀观察局部风险与 held-out 变化，再用当前学生 fresh 任务评分确认；如需识别监督价值，再做少量受控分支。先排除估计器支持口径、格式和预算差异。
2. **数学上的条件拟合能否转为跨域任务收益？** 联合 RQ4/RQ9，优先补科学、代码、IF，再补非数学知识、逻辑和同题跨语言；记录教师各域能力和学生的逐域得失。现有纯数学训练不宣称完整双向迁移矩阵。
3. **吸收困难来自当前状态、初始化还是目标本身？** 联合 RQ1/RQ7，在共同 SFT 深度与优化预算上区分 fixed/fresh、FKL/RKL、学习率及监督模式。若后续主张新技能/新知识，再按 RQ2/RQ3 添加受控原子技能或闭卷映射实验。

这些问题各自对应可以反驳的解释，benchmark 作为检验工具归入问题，而不是以新增多少个数据集作为研究结论。
