# SFT 与 RL 精选阅读单

更新时间：2026-10-28。按当前关注的合成数据、新知识／新技能、迁移与泛化，从已有调研中精选：SFT 和 RL 各 3 篇必读、1 篇按需阅读。分组表示阅读问题；部分论文同时比较两种训练方式。

## 1. SFT：数据、训练动态与知识内化

| 顺序 | 论文                                       | 核心问题                                              | 推荐等级                 |
| ---: | ------------------------------------------ | ----------------------------------------------------- | ------------------------ |
|   S1 | Debunk the Myth of SFT Generalization      | 泛化失败是 SFT 本身的问题，还是提示与示范设计的问题？ | 必读，合成任务优先       |
|   S2 | Rethinking Generalization in Reasoning SFT | 训练多久、用什么数据、底模多强，分别影响什么？        | 必读，实验基线优先       |
|   S3 | SE-Bench                                   | 新信息能否进入参数，撤掉文档后还能不能用？            | 必读，知识注入／OPD 优先 |
|   S4 | Proximal Supervised Fine-Tuning            | 如何调整 SFT 目标，缓解遗忘与策略漂移？               | 按需，做方法时读         |

### S1. Debunk the Myth of SFT Generalization

2025, arXiv:2510.00237.[^s1]

在 Sokoban 和 General Points 上区分指令变化与难度变化。提示多样性改善模型对新指令的适应，CoT 示范改善更复杂任务的表现。值得优先读它的假环境诊断与数据消融：它直接展示哪些控制变量能改变“SFT 不泛化”的结论。

读后应能提出一个更公平的 SFT 基线：训练指令是否多样、推理示范是否足够、格式错误是否与推理错误分开。CoT 数据来自经过任务 RL 的教师，须计入教师监督，不能把学生使用 SFT 解读成整条流程没有 RL。

### S2. Rethinking Generalization in Reasoning SFT: A Conditional Analysis on Optimization, Data, and Model Capability

2026, COLM 2026. arXiv:2604.06628.[^s2]

部分长 CoT SFT 设置中，跨域表现先下降，再随训练恢复并超过底模。数据质量、底模能力又影响是否出现这种恢复。推荐原因是它直接影响 baseline 选择：仅比较短训练终点可能把欠优化误判为方法限制。

读后应能设计完整 checkpoint 曲线，并联合调整学习率与时长。它不保证训练越久越好，也不保证推理收益与通用行为、安全表现同时改善。合成 Countdown-CoT 是其子实验，主线仍是较广泛的推理 SFT。

### S3. SE-Bench: Benchmarking Self-Evolution with Knowledge Internalization

2026, arXiv:2602.04811.[^s3]

把 NumPy API 随机重命名，测试模型在撤掉文档后能否调用新接口。带文档生成示范、无文档做更新的 Closed-SFT 在受测条件下能内化部分映射。把它列在 SFT 线，是为了研究监督如何将外部信息转入参数。

这对 OPD 很直接：可以固定 teacher 能看文档、student 最终不能看的条件，再比较硬标签与软分布监督。原论文没有完成这一整套 OPD 对照；其中 RL 结果还受条件分布变化及实现选择影响。

### S4. Proximal Supervised Fine-Tuning

2025 首发，ICLR 2026；arXiv:2508.17784。[^s4]

PSFT 将 trust-region 思路用于限制 SFT 策略漂移，研究 OOD、能力保留及后续优化。若准备提出新 loss 或构造更强 SFT baseline，它值得读；若当前只想理解新知识与泛化机制，可先完成 S1–S3。

## 2. RL：新组合、原子技能前提与收益来源

| 顺序 | 论文                                                      | 核心问题                                          | 推荐等级                   |
| ---: | --------------------------------------------------------- | ------------------------------------------------- | -------------------------- |
|   R1 | From f(x) and g(x) to f(g(x))                             | RL 能否学到未见技能组合，并向更难或其他任务迁移？ | 必读，优先级最高           |
|   R2 | Atomic Skills are the Prerequisite                        | RL 获得组合能力需要哪些预先掌握的技能？           | 必读，参数／上下文知识优先 |
|   R3 | Decomposing Elements of Problem Solving                   | 提升来自新规划、执行稳定性，还是覆盖增加？        | 必读，机制诊断优先         |
|   R4 | Learning from Synthetic Data Improves Multi-hop Reasoning | 合成世界中的训练能否迁移到真实问答？              | 按需，跨域迁移时读         |

### R1. From f(x) and g(x) to f(g(x)): LLMs Learn New Skills in RL by Composing Old Ones

2025，arXiv:2509.25123，刘知远参与。[^r1]

先通过 RFT 学会字符串原子函数，再在组合任务上做 RL，测试未见组合、更深嵌套和 Countdown 迁移。推荐原因是技能定义清楚，并且控制了目标任务原子能力是否预先存在。

读后应能区分原子知识注入与组合能力形成。它支持特定条件下的新组合学习，不证明 RL 凭空获得尚未提供的函数定义。建议优先读任务协议及第 4.1–4.4 节。

### R2. Atomic Skills are the Prerequisite: When Reinforcement Learning Synthesizes Compositional Reasoning, and When It Only Amplifies

2025 首发，2026 更新；arXiv:2512.01970。[^r2]

用合成传记与知识图谱，将参数内知识、上下文知识及其组合分开。与 R1 的字符串操作相比，它更接近检索增强和知识更新中的问题：模型已知一部分，输入补充另一部分，能否联合使用？

重点看原子技能缺失与具备时的差异，以及 IID、未见组合和更严格零样本设置。原子前提是受测任务中的证据；当前版本仍标注 Work in Progress。

### R3. Decomposing Elements of Problem Solving: What “Math” Does RL Teach?

2025, arXiv:2505.22756.[^r3]

将解题拆成规划、执行、验证，用合成解题树控制探索难度与伪相关。受测 GRPO 的收益很大一部分来自执行更可靠，但改变条件也可扩大覆盖。

推荐与 R1、R2 合读，形成机制上的制衡。读后应能分辨平均正确率提高与新路径覆盖，避免仅凭总分上涨就判断学到了新知识。合成 Transformer 与自然数学 LLM 实验要分别解读。

### R4. Learning from Synthetic Data Improves Multi-hop Reasoning

ICLR 2026, arXiv:2603.02091.[^r4]

在虚构关系世界、逻辑题和计算图上做 RL，测试向真实多跳问答迁移，并加入格式奖励对照。若关心合成训练能否带来外部基准收益，优先读它；若关心能力从哪里产生，先读 R1–R3。

## 3. 最省时间的阅读路线

只读四篇：**R1 From f(x)… → S1 Debunk → S3 SE-Bench → R3 Decomposing**。分别回答新组合、SFT 数据因素、知识内化与收益分解。

完整核心六篇：在上述四篇后加入 **S2 Rethinking SFT** 与 **R2 Atomic Skills**。前者补齐优化动态，后者补齐能力前提。

准备改训练方法时加读 S4；准备检验合成到真实任务迁移时加读 R4。更广的文献关系、作者版本说明与实验边界，见[合成任务专题](2026-10-27-合成数据与RL新知识新技能论文专题.md)和[总调研](2026-10-27-LLM的RL与SFT迁移泛化论文调研.md)。
