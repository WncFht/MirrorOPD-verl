合成任务专题区分三件事：随机新事实／API 映射的参数内化，已知原子技能的新组合，以及从合成任务迁移到其他领域。教师生成的 CoT、题目改写或翻译另列为监督数据合成，不自动视为无预训练污染的控制实验。
