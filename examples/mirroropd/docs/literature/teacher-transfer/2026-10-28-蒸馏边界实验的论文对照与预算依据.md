## 2. 最直接的实证对照

### 2.1 Rethinking OPD：大教师起点与额外 RL 分开

Rethinking OPD v2 固定 R1-1.5B 学生，在§4.1 比较 JustRL 与 R1-7B：前者报告回收超过 80% 的任务成绩差距，后者没有明显改善。§3.2 进一步比较 R1-7B 与其 RL 派生模型 Skywork-OR1-Math-7B，后训练教师更有效。[^rethinking-opd]

这给出一个可检验的区分：跨尺寸原始教师的低任务收益，不意味着其 RL 派生教师同样无效。TB1-R/S 正是复用这一对照，再与现有 Polaris 比较。本文不把作者关于 thinking pattern 的解释视为已隔离容量、数据和优化因素的因果结论。

论文默认是 student top-16 监督、LR1e-6、global/mini batch 均 64、每题 4 条 rollout、response cap7168、1 epoch。四条回答和 minibatch 含义使论文 step 不能直接等同于本仓 reuse16 的全批更新。该论文另有 0.5K 至 15K 的长度实验；短前缀筛查和完整回答能力验证必须分开。[^rethinking-opd]

### 2.2 Every Coin：同教师换学生、同学生换 SFT/RL 教师

Every Coin v3 图 6 的同源/跨源 overlap 曲线在前 10–30 个论文 step 已分开；R1-7B 与 Polaris 教 1.5B 的曲线较平，同源 Nemotron 等明显提高。图 9 固定 R1-7B 学生：Polaris 的任务成绩约 10 步已接近其教师参考线；Light-R1-7B 的 SFT 教师也可取得接近教师的任务水平。图中坐标是平滑后读图近似，不作为逐更新原始数字。[^coin]

由此，TB2-P7 与 TB2-L7 可作为有文献依据的直接同源对照；“SFT 教师一定难教”缺少支持。图 6 的 Nemotron 未给精确 SHA，不能写成 v1/v2/BroRL 版本比较。完整的同域、跨域、模型与参数整理沿用[已有精读](2026-10-26-策略蒸馏泛化的双重性实验与设置.md)，不在本文重建第二份全量综述。

论文最多 200 steps，多数配置 100–200 内收敛；每步 128 题×4 回答，LR1e-5，sampled-token PG-style 目标；R1 相关模型组最大序列长度可达 96K。原文的 sequence length 不直接改写为 response cap。每批真实 optimizer 更新次数未完整披露。[^coin]

### 2.3 Semi-OPD：冻结初始学生轨迹的收益具有配对依赖

Semi-OPD 比较离线初始学生轨迹与在线学生轨迹，使用相同 sampled-token RKL。表 3 的最终方法差值如下，指标是四项数学基准 avg@32 的均值。[^semi]

| Teacher → Student                   | 初始 top64 overlap | Semi-OPD − OPD 末步 | 归一化 AUC 差 |
| ----------------------------------- | -----------------: | ------------------: | ------------: |
| Polaris-7B → R1-1.5B                |              69.7% |             +0.1 pp |      +0.24 pp |
| Polaris-7B → R1-7B                  |              86.8% |             −2.6 pp |      −0.68 pp |
| Qwen3-4B-Instruct-2507 → Qwen3-1.7B |              62.5% |             +9.5 pp |      +7.09 pp |

这些数值不支持“换成固定 S0 就能修复 Polaris”的预期，也不把较大 overlap 当成普遍成功阈值。完整 17 组仍由[既有 CSV](sources/semi-opd-17-pairs.csv)维护。

论文每步 128 题×1 回答，14116 题约 110 steps 为一 epoch；这不意味着所有曲线恰好止于 110。配对表的 non-thinking 训练 cap4K、thinking16K，均与验证 32K 分开。固定 S0 的主要工程价值是复用生成和评分，但 full-vocab 缓存成本与其 sampled-token 实现不同。[^semi]

### 2.4 Scaling Properties：早期迁移速度与后期峰值分开

该研究从统一 SFT 后的 Qwen2.5 系列构造 RL 教师，覆盖 0.5B/1.5B/3B/7B/14B 的 25 个 Vanilla-OPD 组合。它观察到早期任务收益与相对初始学生的平方根 KL 近似线性，后续可能继续改善、平台或退步；小学生并不总从更大教师受益。[^scaling]

每条最多 580 updates，batch256、cap2048；拟合用前 30 个观测点，不是 30 次更新。全部配置单 seed，部分终点右删失，不能直接将其拟合律用于预测 R1 长推理模型的最终分数。对本计划的用途是把早期迁移速度、后期可达水平和实际策略位移分开报告，并用短程筛查挑出值得继续确认的配对。[^scaling]

### 2.5 Transfer-Stratified OPD：教师 RL 增量与学生获取量

TS-OPD 使用 Qwen3-0.6B/1.7B/4B 学生，以及 Qwen3-8B 在 GRPO 前后的教师。原文简称`base-8B`指 GRPO 之前的 Qwen3-8B，不能自动替换成`Qwen3-8B-Base`。标准 OPD-r/f 一遍 MATH 训练集，共 118 更新，64 题×1 回答、cap8192。[^ts-opd]

1.7B 学生在原始教师和 GRPO 教师下，OPD-r 的八基准均分分别为 29.22% 与 39.04%；这两个终点之差不是自动成立的完整能力回收率。论文采用不同基准集合定义 transfer gap，需沿用其定义。其方法还涉及筛题、KL 方向和 token gating，不能把综合收益孤立归给 FKL。[^ts-opd]

该实验支持以大教师的前后训练终点成对研究，并说明约百次更新可产生有用的任务对照；它没有证明百次更新就是普遍收敛预算。

## 3. 更新数、数据覆盖与 token 预算的可比范围

| 实验               | 明确的预算单位            | 输入或复用                             | 对本项目预算的含义                          |
| ------------------ | ------------------------- | -------------------------------------- | ------------------------------------------- |
| 本地 L 短前缀      | 64 真实更新               | 4 批×16 题，每批 reuse16，H1024        | 训练仅 64 题；适合局部/跨批筛查             |
| 本地 E20/E48       | 256 outer / 4096 真实更新 | batch64、n1、reuse16、cap7168          | 不能把 64 outer 误写为 64 更新              |
| Rethinking OPD     | 默认 1 epoch              | batch64、n4、student top16、cap7168    | 需核对 minibatch 实现，不能直接按 step 对齐 |
| Every Coin         | 最多 200 论文 steps       | 每步 128 题×4 回答，sampled-token 目标 | 原文未完整披露每批 optimizer 更新次数       |
| Semi-OPD           | 约 110 steps 遍历一次题池 | 每步 128 题×1 回答                     | 相同 step 通常覆盖远多于 L 短探针的题目     |
| TS-OPD 标准 OPD    | 118 updates，一 epoch     | 每步 64 题×1 回答                      | 短预算任务参考，不是全词表协议              |
| Scaling Properties | 最多 580 updates          | batch256，cap2048                      | 早期观测点与更新数、长 CoT 设置分别处理     |

论文设置分别见上述来源附录。[^rethinking-opd][^coin][^semi][^ts-opd][^scaling] 本地预算依据见[训练协议源码](../../../research/studies/cross_batch/protocol.py)与[早期风险摘录](sources/boundary-plan-20261028/local-early-transfer.csv)。

TOP-D 提供另一个容易混淆的例子：论文 global batch512、每题 8 条回答，分为 16 个不同的 32-prompt minibatch，训练一轮；标准 OPD 列为一个 minibatch。本项目 reuse16 是在同一批轨迹上重复更新 16 次，不能把两者叫作相同的数据复用设置。[^topd]

预算比较至少保留五列：真实参数更新、独立训练 prompt 数、新生成 response token、重复访问的训练 token、teacher 评分 token。模型规模和完整词表投影成本不同，所以等更新不等于等 FLOPs 或等 GPU 小时。

## 4. 从外部证据到本地实验预期

当前可提出的预期是：JustRL 为强迁移参照；Polaris 教 1.5B 容易出现局部与留出分化；R1-7B 原始教师的低任务收益值得复核；Skywork 提供同一个大教师起点的 RL 增量对照；Polaris/Light 教其直接祖先 R1-7B 有正证据。Nemotron 版本序列和同 run SFT 阶段仍属于边界探索，不能预填成失败组。

本项目的新问题落在 full-vocab 目标与受控 state 上：同样的任务排序是否对应跨批风险传播；匹配训练银行拟合程度后，差异是否还在；更换学生、增加完整推理覆盖或改变训练阶段是否移动这个有限预算边界。新增实验不会仅靠复现已有终点排序就解释机制。

先用 64 更新比较斜率和局部/留出分化，再对代表配对做独立题目重复、延长和在线确认。需要保留局部优化不足、任务优势不足、模板或数值失配等独立解释；只有固定输入、访问分布与任务评估共同支持时，才讨论更广的迁移限制。
