# Delta OPD：论文分类、研究问题与证据综述

更新与检索截止：2026-10-31。本文系统整理语言模型中“迁移相对策略变化”的 Delta OPD：以 teacher/expert 与 reference/base 的差异监督学生，而不是只拟合教师终点。主线覆盖 **15 篇**，另列 **8 篇相关方法、2 篇解码前驱与 6 项排除记录**。范围、版本与逐篇归类可在[论文索引](data/delta-opd-20261031/papers.csv)核对。

优先阅读：**Direct-OPD → OPD² → W2S-OPD → Rethinking Relative Policy Differences → CompassOPD → S²D/Waypoint → Delta-MOPD**。分别建立增量奖励、大教小实现、小教大代理教师、SFT/尺度差对照、异家族参考、监督选择和多教师组合的认识。OPRD、RIDE、RISE 则把问题扩展到梯度、隐藏表示和递归自增量。

这里的“所有”按明确范围理解：截至检索日，通过关键词、精确题名、前后引用及本地 Awesome-Paper 设置库找到并核验的增量迁移主线。相关文献命名未统一，预印本与实现仍在变化；不把仅含 delta/weak-to-strong 字样的工作自动纳入，也不宣称检索可以证明绝对无遗漏。普通 OPD 的 broader generalization 见[泛化迁移 RQ 综述](../transfer-generalization/2026-10-31-泛化迁移研究问题与证据综述.md)。

## 1. 分类边界与术语

### 1.1 三层纳入标准

| 层级              | 纳入依据                                                                  | 本文处理                                    |
| ----------------- | ------------------------------------------------------------------------- | ------------------------------------------- |
| 核心主线          | 在输出、梯度、表示或自身训练轨迹上，显式使用两策略/检查点的相对变化做训练 | D01–D15，按 RQ 比较，注明直接用例与限制     |
| 结构扩展/相关对照 | 冻结极限可恢复对比目标，或使用偏好/条件对比、可靠性外推、风格残差         | R01–R08；不全部称 teacher-minus-predecessor |
| 前驱与排除项      | 解码期代理调优，或 delta 实际指师生差、tail mass、rollout 混合等          | F01–F02 与 X01–X06；保持用途区分            |

“delta”并非单一方法名。严格的训练增量需要实际前序检查点；更广的对比方法也可能使用两个独立模型、同模型的不同条件，或人为构造的弱参考。以下统一先写“参考”，确认谱系后才称“前序”。

### 1.2 容易混淆的名称

- **OPD²** 指 Heo 等的 On-Policy Delta Distillation；MiMo-V2.6 的 **MOPD²** 是多前缀/多教师流程，不能因上标相同就当作同一 delta 公式。[^d04][^x02]
- **Direct-OPD** 与 **W2S-OPD** 是不同论文。weak-to-strong 既是方向描述，也出现在不同方法的标题里。
- Park 等的 **OPRD** 是 On-Policy Reverse Distillation；RIDE 比较的另一种 OPRD 是 representation-space matching 基线，两者缩写相同、方法不同。[^d13][^d14]
- 模型描述中的 **base/reference/anchor** 不一定表示仓库名带 `-Base` 的预训练模型。例如 Direct-OPD 的 R1-Distill-1.5B 已是蒸馏后模型，只是在该 RL run 中充当前序。[^d02]
- teacher–student 的 log-ratio 是普通 OPD 信号；只有明确区分 expert/reference 及 student anchor 后，才能判断它是否属于本文讨论的增量迁移。

## RQ1：Delta 到底减去什么，为什么可能比终点更合适？

### 先区分四个角色

设 T 是教师/专家，B 是与其比较的参考，A 是冻结的学生初始化，pθ 是当前学生。它们在同一文本前缀 s 上评分；共同词表/事件定义与温度口径一致时，定义：

$$
\Delta(s,a)=\log T(a\mid s)-\log B(a\mid s).
$$

普通 OPD 的 token 信号可以恒等分解为：

$$
\log T(a\mid s)-\log p_\theta(a\mid s)
=\Delta(s,a)+\log B(a\mid s)-\log p_\theta(a\mid s).
$$

因此终点教师同时传入 T 相对 B 的变化，以及 B 相对学生的差异。后项可能包含需要保留的知识，也可能是与目标无关的先验或风格差异；代数分解本身不证明后项一定有害。D11 的 base-pull 诊断与 D12 的跨家族偏移研究才提供具体经验依据。[^d11][^d12]

### 理论上什么时候 log-ratio 对应奖励？

在固定 prompt x、完整响应 y 的 KL 正则分布优化中，令真实奖励为 r(x,y)、系数 τ>0。考虑：

$$
\max_T\ \sum_y T(y\mid x)r(x,y)
-\tau\sum_y T(y\mid x)\log\frac{T(y\mid x)}{B(y\mid x)},
\qquad \sum_yT(y\mid x)=1.
$$

假设 B 在所讨论支持上为正、归一化项有限。拉格朗日一阶条件给出：

$$
r(x,y)-\tau\left(\log\frac{T^*(y\mid x)}{B(y\mid x)}+1\right)+c(x)=0,
$$

从而：

$$
T^*(y\mid x)=\frac{B(y\mid x)\exp(r(x,y)/\tau)}{Z_B(x)},
\qquad
\log\frac{T^*(y\mid x)}{B(y\mid x)}
=\frac{r(x,y)}{\tau}-\log Z_B(x).
$$

这解释了 Direct-OPD、Proxy OPD 和 D10 为何将前后策略差解释为隐式奖励。**前提是对应的 KL 正则优化及其解；有限步 GRPO/SFT checkpoint 不自动等于这个最优解。** 按自回归链式分解，完整响应 log-ratio 是逐 token log-ratio 的和；单个 token 的差通常还包含未来价值与条件归一化的影响，不能不加条件地叫原训练的即时奖励。[^d02][^d03][^d10]

### 一个统一的固定状态代理目标

在固定 s 下，考虑 α≥0、β>0 的局部目标：

$$
J_s(p)=\alpha\mathbb E_{a\sim p}[\Delta(s,a)]
-\beta D_{\mathrm{KL}}(p\Vert A).
$$

令 κ=α/β，构造：

$$
q_\kappa(a\mid s)
=\frac{A(a\mid s)\left[T(a\mid s)/B(a\mid s)\right]^\kappa}{Z_\kappa(s)}.
$$

代入 KL 可逐项得到：

$$
D_{\mathrm{KL}}(p\Vert q_\kappa)
=D_{\mathrm{KL}}(p\Vert A)-\kappa\mathbb E_p[\Delta]+
\log Z_\kappa(s),
$$

故：

$$
J_s(p)=\beta\log Z_\kappa(s)-\beta D_{\mathrm{KL}}(p\Vert q_\kappa).
$$

固定状态分布、冻结 A/T/B 时，最大化前者等价于最小化到 qκ 的 KL。在共同 softmax 温度下，也可用 logits 写作：

$$
q_\kappa=\operatorname{softmax}\bigl(z_A+\kappa(z_T-z_B)\bigr).
$$

logit 与 log-probability 的差只相差对动作无关的归一化项，构造归一化目标后该项消失。温度不同、词表事件不同或采用额外 gate/top-k 时，不可直接照搬等价关系。这个统一式用于比较 D02/D03/D05/D10/D11 的设计思想；不表示它们的估计器、baseline、clipping 和训练预算完全相同。[^d02][^d03][^d05][^d10][^d11]

若前缀分布随当前策略改变，完整目标梯度还涉及访问分布/未来回报；固定前缀局部等价不自动等于论文中所有 sampled-token、zero-discount 更新的完整序列等价。

### G-OPD 的 reference 同时进入奖励与 KL，不能与上述锚定式混同

G-OPD 的原目标使用同一个 R 作为奖励分母与 KL reference：$\lambda\mathbb E_p[\log(T/R)]-D_{\mathrm{KL}}(p\Vert R)$。其原文响应分布优化在相应归一化条件下给出：

$$
q_{\rm G}(y\mid x)\propto T(y\mid x)^\lambda R(y\mid x)^{1-\lambda}.
$$

默认 R=A；reward correction 分支设 R=B。因此后者是 $q_{\rm G}\propto B(T/B)^\lambda$，一般**不是** $A(T/B)^\kappa$。当λ=1 时两种 reference 选择均退化为 T；reference 校正的作用与外推强度一起解释。固定前缀局部代理目标可做类似代数，但完整响应分布的条件化还涉及未来归一化，不能未经论证将两者视为相同序列目标。将各篇出现的 teacher−base 奖励单独抽出来，也不能证明完整算法相同。[^d01]

### “Base”的节点决定你究竟减去了什么

| 参考 B 的实际含义                | 差异包含什么                                                      | 对应例子                                      |
| -------------------------------- | ----------------------------------------------------------------- | --------------------------------------------- |
| 同一教师的 pre-RL/SFT checkpoint | 该次 RL 及其实际执行带来的净变化                                  | Direct-OPD、Scaling Properties、S²D、Waypoint |
| pre-instruction 预训练 `-Base`   | 从 Base 到 reasoning-tuned 模型的整个后训练差异，可能含 SFT/RL 等 | OPD²、Multilingual OPD²                       |
| 小模型或不同阶段/代际 reference  | 任务变化与模型/训练差异的混合                                     | W2S 的 scale pair、D10 替代参考               |
| 同家族弱参考/减少 MoE 激活       | 相对于该参考的能力/行为差，不是实际训练路径                       | CompassOPD                                    |
| 正/反偏好或不同提示条件          | 偏好方向或条件效应，不是 teacher 前后权重变化                     | AlignDistil、CCE/COPD                         |

**当前证据支持“转移相对行为变化”，尚不支持“精确提纯出独立的 RL 知识模块”。** 即便 B 是真正前序，差异也可能含风格、校准、熵、长度、遗忘与任务能力的共同变化。

## RQ2：小教师能否提升更强学生，提升是否只来自大模型先验？

### 直接支持的结果

- **Direct-OPD**：R1-Distill-1.5B→JustRL-1.5B 的变化，改善 R1-7B、Qwen3-1.7B/4B；其中 R1-7B 与 Qwen3-4B 的初始能力已超过 JustRL。Nemotron→QuestA 是额外来源稳健性实验，作者明确说明并非全部属于能力意义上的 weak-to-strong。[^d02]
- **Proxy OPD**：以 Qwen3-4B 在 DeepMath/Eurus 上做 RL 的相对更新改善 Qwen3-8B，进一步比较跨阶段和代际；学生保留自己的 reference，而不是以弱 proxy 的终点为唯一目标。[^d03]
- **W2S-OPD**：在 8B anchor 上分别加入 4B RL 增量、4B 与更小模型的差、同一 4B 的正确/错误 hint 差，并研究多教师。三种来源的信息含义不同。[^d05]
- **Scaling Properties**：Qwen2.5 的完整 Vanilla 网格覆盖 25 对，Delta 分支为 17 对；作者观察到受测弱到强 pair 的峰值超过教师，且 Delta 在部分条件有更大收益。**Vanilla 也可超过弱教师，超过教师不是 Delta 独有的证据。**[^d07]

### 哪些因素还未被隔离

更大学生已有的预训练/SFT 能力，完全可能使同一方向产生更大任务收益；这与增量迁移成立并不冲突。要证明“教师提供了什么”，应比较学生初始点、Vanilla endpoint、增量方向、无教师或打乱方向等控制，而不只比较训练后学生与弱教师。

Direct-OPD 还比较小模型 RL 加迁移与大模型直接 RL，并研究串行叠加多个变化。但总成本必须包括教师 RL 与目标模型评分，不能把已训练教师当作无成本来源；步数对齐也不等于算力对齐。[^d02]

Scaling Properties 的弱到强 bootstrapping 链在受测配置中没有胜过直接从小专家迁移，表明“先教一个中等模型，再教大模型”不是自动获益的阶梯。峰值选择是轨迹内最优描述，还应与固定终点和开发集选模区分。[^d07]

### 最有用的结论

有证据支持较小模型产生的任务相关变化能帮助更大的、甚至任务成绩已更高的学生；没有证据支持所有弱教师变化都可提升任意强学生，更没有“全部 RL 内容已经迁移”的结论。

## RQ3：大教小和同尺寸下，Delta 是否稳定优于普通 OPD？

### Strong-to-weak 的主要证据

G-OPD 默认先使用学生自身 reference 做奖励外推。其 §4.2.3 另外用 4B 领域 RL 教师及其实际 pre-RL 4B reference 教 1.7B，验证 reward correction；30B-A3B-Instruct-2507 的精确 pre-RL 不可得，因此不能把该校正分支说成已经直接核验所有 30B 主实验。[^d01]

OPD² 使用 Qwen3 与 Gemma4 的 reasoning-tuned 教师及预训练 Base，明确比较 thinking/non-thinking。它以 teacher-minus-base 为主要信号，并加 centering 与同普通 OPD 优势方向一致的 gate；不能简写成“不带约束地最大化 delta”。[^d04]

| 同一论文内的例子                    | 比较                                                 | 结果与解释                                                                                 |
| ----------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| OPD²，Qwen3-1.7B non-thinking，表 2 | OPD→OPD²                                             | MATH500 81.0→83.9，AIME24 36.7→41.0；都是百分点分数，不能混用采样次数[^d04]                |
| OPD²，同一 1.7B 设置的代码/科学表   | 多域训练后分别评领域                                 | 数学、科学、代码均有读出；这些域都参与训练时首先是联合能力学习，不是纯数学零样本迁移[^d04] |
| Multilingual OPD²                   | 英/韩/日 100K prompt-only；30B-A3B→1.7B/8B，100 更新 | OPD² 相对 OPD 有优势；English-only 准确率迁移仍可能伴随回答转向英语[^d06]                  |
| Scaling Properties §6.1             | 17 个 Delta 与匹配 Vanilla cells                     | 10 W2S、5 same-base、2 S2W；不能把 25 个 Vanilla cells 当成 25 个 Delta 结论[^d07]         |

Scaling Properties 的 matched-KL 比较中，15/17 cells 的大部分共享进度范围由 Delta 领先，但最大峰值/峰值增益的领先只覆盖其中 12 个；两个最小学生等条件有例外。其每 cell 主要为单 run 轨迹，且早期有用区间与后期饱和/退化不同。它支持条件性的改进，不支持普适优势或完全吸收。[^d07]

### 同尺寸与完全吸收的边界

同源同尺寸可以减少表达目标的障碍，但目标相同不代表当前优化已经到达它。RIDE 的四组 base/RL pair 是同组架构匹配，不是把任意大教师的隐藏状态直接回归到小学生。OPRD 还通过 verifier 梯度研究同尺寸/不同容量方向，而不是以低 KL 宣称复制了教师。[^d14][^d13]

外推或增量目标往往故意不同于教师终点；因此“学生超过教师”与“完整复制教师分布”是两种不同主张。固定任务、固定预算里的提升不能证明全领域行为已被吸收。

<a id="rq4"></a>

## RQ4：SFT、RL、尺寸差和异家族差异，哪些可迁移？

### SFT 增量已有直接实验，不能只讨论 RL

D10 固定 Qwen3-8B target，在共同目标/设置下比较 9 种 proxy pairs。其表 2 中，Qwen3-4B-SFT / Qwen3-4B 的差将 target 数学均分从 18.43 提升到 36.62；另有 R1-Distill-7B / Qwen2.5-Math-7B 的 SFT/蒸馏阶段差异。评测覆盖八个数学集、每题16次；这些是该论文的协议与分数，不可与其他论文同名模型分数直接拼接。[^d10]

这比“普通 OPD 能拟合 SFT 教师”更直接：它测试了以 SFT 相关策略差作监督。不过 SFT 阶段差可以包含离线教师的推理知识、格式与行为；实验提升不意味着这些内容已被逐项分离。

### 纯尺寸差的证据尚不统一

W2S-OPD 用不同规模模型的对比构造代理教师，报告正向结果；D10 的四个 scale-induced pairs 收益明显弱于任务训练 pairs，部分几乎不变或下降。二者在 pair、target、增量系数、top-k、任务与预算上不同，现有材料不足以把分歧全部归为某一个实现因素。[^d05][^d10]

D10 还发现实际前序并非唯一可能的有效参考：替代 reference 可保留更有用的差异。这说明“提取有效迁移方向”与“识别该次训练的因果净变化”是两项不同任务，后者对谱系要求更严格。[^d10]

### Cross-origin 与 cross-family 分别看

Delta-MOPD 主比较的 Polaris-7B 相对 DS-R1-7B，与 1.5B anchor 是同一早期谱系但不同尺寸/训练来源；不能把它简化为完全不同 tokenizer 的教师。其附录另有 Qwen3 的 tokenizer 投影扩展。[^d11]

CompassOPD 则直接研究不同家族：Qwen3.5/Qwen3/Mistral 教师，经文本单元对齐后，对 Granite、Qwen3、OLMo 学生转移同教师家族的 likelihood shift，同时以学生自己的 reference 约束更新。它还从同一 MoE 教师减少专家激活构造低能力 reference。该参考不是训练前序，作者提升的是可用信号，而不是恢复一段真实 RL 历史。[^d12]

### 与“异源难学”的关系

这些结果支持把问题分成：参考是否过滤了不必要的先验、剩余变化是否任务相关、学生是否已有可利用它的计算/知识、当前优化与状态覆盖是否足够。它们不支持“size 不同必然不能迁移”，也不支持“所有跨尺寸困难完全由 pretrain/SFT 不同造成”。

## RQ5：Delta 的大小能否代表学习价值，怎样筛选和稳定？

### 三种 gate 分别回答不同问题

| 方法         | 被检查的量                                        | 选择/稳定规则                                               | 未证明什么                                               |
| ------------ | ------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------- |
| OPD²         | centered teacher−base 与 centered teacher−student | 两种优势同号时保留 delta，否则置零                          | 同号不是正确性的外部验证[^d04]                           |
| S²D-OPD      | teacher/reference 的 JSD                          | 每响应保留高 JSD 的 top10% 状态                             | 变化大不等于变化正确，罕见但有用的信号也可能被过滤[^d08] |
| Waypoint-OPD | 同一 RL 训练早/晚两段变化的方向一致性             | student 局部 top-k 上中心化后正余弦 gate；低范数有 fallback | 方向一致不等于任务奖励更高[^d09]                         |

OPD² 在 full-vocab 形式下先减去学生分布下的期望基线：

$$
A_\Delta(s,a)=\Delta(s,a)-\mathbb E_{v\sim p_\theta}[\Delta(s,v)],
\quad
A_{\rm OPD}(s,a)=\log\frac{T(a\mid s)}{p_\theta(a\mid s)}
-\mathbb E_{v\sim p_\theta}\left[\log\frac{T(v\mid s)}{p_\theta(v\mid s)}\right].
$$

其实际优势取 $A_\Delta\mathbf1\{A_\Delta A_{\rm OPD}>0\}$；期望基线在实现中用 student top-1024 近似。top-1024 是 centering 近似，不等于整篇只蒸馏 1024 个动作。纯 delta 奖励若无 anchor 或 gate，局部最优可能集中到最大 delta 动作，而不是在学生等于教师时停住。[^d04]

### Log-ratio 很大，也可能只有很小的绝对变化

S²D-OPD 给出反例。为解释其核心现象，可看二动作分布 $B=(\epsilon,1-\epsilon)$、$T=(c\epsilon,1-c\epsilon)$，其中固定 c>1 且 0<ε<1/c。第一动作的 delta 恒为 log c，但ε→0 时两个分布趋近，KL/JSD 均趋零。若学生仍在第一动作上有明显质量，delta 更新不一定随教师实际变化一起消失。[^d08]

该论文在两教师 pairs×四学生的八种数学设置中，7 种优于 dense Direct-OPD、1 种相当；使用 AIME24/25 选 checkpoint，再在 AIME26 与 HMMT 留出题评估。选择器不增加模型前向，但 JSD 计算本身仍依赖已得到的教师/reference 分布，不是完全无成本。[^d08]

### 中间检查点提供终点差看不到的信息

Waypoint 满足精确望远镜分解：

$$
\Delta_{B\to T}=\Delta_{B\to W}+\Delta_{W\to T}.
$$

同样的终点差可以由前后相同方向得到，也可以先过冲再回退。论文在当前学生 top-k 上对两段向量按学生概率中心化，使用 max(0,cosine) gate；若任一范数≤1e-8，则 gate 设为 1 保留终点信号，另有 batch 尺度稳定化。它没有把两个阶段分别蒸馏给学生，也没有改变终点差的代数和。[^d09]

4B 教师教 8B/14B/30B-A3B 的数学/代码六组中，作者报告域平均最高；这不意味着每个单 benchmark 都最佳。额外评分成本需与更短响应、截断率和 wall-clock 一起看，不能只数模型前向次数。

<a id="rq6"></a>

## RQ6：多教师增量能否相加，并隔离继承偏好与域间干扰？

### 相加的是目标分布中的相对偏好

对固定 teacher/reference pairs 与共同 anchor A，广义组合可写为：

$$
q(a\mid s)\propto A(a\mid s)
\prod_i\left[\frac{T_i(a\mid s)}{B_i(a\mid s)}\right]^{w_i}.
$$

在共同 logit 口径下为 $z_A+\sum_iw_i(z_{T_i}-z_{B_i})$。这是归一化后的 product/contrast 目标，不是参数 task vector 相加，也不保证每个教师贡献可独立识别。不同温度、置信尺度及方向抵消仍会影响结果。

W2S-OPD 将多个弱领域专家的对比方向加到强 anchor；Direct-OPD 研究顺序迁移多个变化；Delta-MOPD 将“多个教师同状态共同评分”与“按域路由”分开。三种组合机制不能当成同一实验。[^d05][^d02][^d11]

### Delta-MOPD 的直接证据

其 anchor 为 DS-R1-1.5B；同源 Nemotron/JustRL 的前序就是 anchor，Polaris 的前序则为 DS-R1-7B。因此在对应比较里，endpoint 与 shift 的主要变化来自是否把 Polaris 的 base 差也传入。论文控制 teacher 选择、prompt、更新预算与评测；两臂的当前 rollout 仍会随训练分叉，不是始终完全同一轨迹。[^d11]

作者报告 shift target 在同状态多教师组合和某些分阶段路由中更有价值；两教师与三教师、分阶段与交错路由结果不同，交错设置可以与 endpoint 相近。减少 base pull 并不自动解决信号尺度、域间梯度、状态覆盖或教师弱项的迁移。

OPRD 的多教师实验则依靠外部 verifier 的学生梯度，teacher shift 只改变其方向分量的更新强度；它不能作为“只靠静态 delta 相加就整合全部能力”的证据。[^d13]

<a id="rq7"></a>

## RQ7：除输出差以外，能否迁移梯度、表示或自身变化？

### OPRD：用教师方向加速学生自己的奖励优化

Park 等在 logit 空间把 verifier 驱动梯度分解为 teacher shift 方向与正交部分，对前者做正缩放。其驻点保持与一阶增益结论依赖这种特定变换及理论空间，不应扩大成任意参数化、随机 PPO/clipping 下所有驻点完全相同。实验覆盖弱到强、多教师，也测 8B→1.7B 数学与 8B→0.6B 逻辑。[^d13]

它与 Direct/Proxy/OPD²的区别是：监督不只是 delta，任务 verifier 决定哪些更新受支持。学生超过教师时，收益可能同时来自教师加速与自己的 RL 探索；样本效率提高不等于总算力严格更低。

### RIDE：在隐藏空间外推教师训练残差

RIDE 逐层构造 $h_{\rm target}=h_B+\lambda(h_T-h_B)$，λ>1 时超出教师，再回归当前学生的对应隐藏状态。四组中，student 都从各自 base 初始化，组内架构、tokenizer 和 head 相同，跨组才是不同模型家族。其目标对照包括隐藏 teacher matching 与输出 ExOPD。[^d14]

作者报告四组均值达到或超过教师，但三组优势在一个训练 seed 标准差内；不能写成已在全部条件显著超过教师。输出空间有用方向可能被 head 衰减是其解释之一，也不意味着隐藏残差天然只有“能力”而无风格或遗忘。

### RISE：从自身 RL 轨迹构造动态教师

RISE 比较当前 RL 更新与 trailing anchor，在权重或 logit 空间外推，再对自身进行 token 级蒸馏。它同时使用 RLVR 来提供正确性依据；无外部 teacher 不等于无外部奖励，也不同于使用固定的一对小教师跨尺寸迁移。数学/STEM/代码/Agent 结果支持这种联合循环的实用性，具体收益仍需与额外 wall-clock 和对照算法一起看。[^d15]

### WDL-OPD：静态 delta 可作为极限，而非完整描述

WDL 的 anchor policy 在此文中是可训练的 rollout 策略，不能与本文冻结 A 混为一谈。它与辅助策略做几何混合后匹配冻结教师，两个策略都更新。冻结辅助时可恢复与对比 proxy 相关的构造，但真实 co-training 增加了动态自由度；论文也指出若干对照存在课程/初始化差别，结果主要支持稳定化假说。[^r01]

## RQ8：对本项目异源教师与 fixed/full-vocab 实验意味着什么？

### 可以直接借用的研究问题

1. **异源 endpoint 难拟合，是否因为额外学习了 B 相对学生的差异？** 用 D10/D11/D12 的视角，区分终点与相对目标，而不是只比较“同源/异源”标签。
2. **SFT 差异与 RL 差异是否同样可用？** D10 已有直接 SFT 增量迁移证据；在本项目中仍需真正的前序/后继 pair，而非用不相干的同尺寸 Base 代替。
3. **训练变化有用，是否也会被学生吸收并迁移到留出任务？** 联合固定风险、held-out 风险、当前学生 fresh 任务评分；不把 delta 范数、JSD 或方向一致性直接当作吸收率。
4. **增量目标变近，是否只是因为更新幅度变小？** 比较 endpoint、原始 shift、匹配目标距离/更新尺度的对照及打乱/零 shift，而非只比较一个学习率下的终点。

### 两个应成立的代数退化对照

在共同支持、同温度、未另加 gate/clipping 的归一化 target 下：

$$
A=B,\ \kappa=1\quad\Longrightarrow\quad q_\kappa=T;
\qquad
T=B\quad\Longrightarrow\quad q_\kappa=A.
$$

因此同源真实前序就是学生初始化时，单位强度的 anchored delta 与 endpoint 目标相同。若两臂仍显著不同，应检查估计器、baseline、clipping、mask、长度归约、reference 处理和状态来源，不能将差异一概解释成“提纯了 RL 内容”。

T=B 的零 shift 使合成目标回到 A，但训练过程仍可能存在 weight decay、额外损失或数值项；应区分目标恒等式与实际参数是否完全不动。

### 当前协议与文献的差异

当前项目在固定 S0 前缀上做 full-vocab RKL；多数主线使用当前学生生成、sampled-token PG 或 top-k 近似。直接在固定前缀拟合 qκ，适合隔离目标构造，但不等于复现完整 Direct/W2S/OPD²算法。RIDE 需要层对齐，OPRD/RISE 需要任务奖励，Waypoint 还需要同 run 的中间 checkpoint，不能只替换一个 loss 就声称完成全部对照。

参考固定身份也重要：Qwen SFT step80/step640 是教师自己的两个阶段；Tulu 的 SFT/DPO/RLVR 和学生不一定共享同一精确父权重。若 B 不是 T 实际前序，可以作为参考选择实验，但不能直接把差叫“该次 SFT 或 RL 新增知识”。[当前协议](../../experiments/teacher-transfer/transfer-mechanism/protocol.md)、[阶段对照](../../experiments/teacher-transfer/transfer-mechanism/2026-10-30-SFT深度与后训练阶段对照计划.md)。

### 优先级与尚未回答的问题

优先保留一个完整可核验的 teacher pair，在共同 fixed bank 上比较 endpoint、anchored shift 和退化对照，再看独立 Math/Code/Science/IF 任务。之后再引入 SFT/RL 来源、跨尺寸/家族、选择 gate 与多教师组合。这里提出的是后续研究设计，没有启动新训练。

截至这些论文的证据，仍无法回答“任意 RL/SFT 内容是否可以被完全吸收”。多数工作展示任务提升或条件性迁移；它们往往故意不复制教师终点，更没有覆盖教师的全部任务、输入和轨迹。

## 5. 结论强度与未解决的分歧

| 已有支持                                             | 仍不能推出                                             |
| ---------------------------------------------------- | ------------------------------------------------------ |
| 任务训练产生的相对变化可跨尺寸、阶段或家族被利用     | 所有教师增量都对所有学生有效                           |
| 弱模型可通过增量监督帮助更强学生，SFT 差也有直接例子 | 弱模型保存了完整可迁移技能模块，或 RL/SFT 可被全部吸收 |
| 选择 reference、gate 及锚定方式会改变结果            | raw delta、JSD 或 overlap 单独就是正确性/学习价值指标  |
| 某些配置下 Delta 优于 endpoint，且有跨域/语言读出    | Delta 普适优于普通 OPD，或所有提升属于未训练领域泛化   |
| 输出、梯度、隐藏、动态自身增量均有方法探索           | 这些方法是同一 loss 的可互换实现                       |

纯尺寸差的可用性、对不相关 reference 的稳健性、固定与 fresh 状态下的差别、跨 tokenizer 事件对齐、超长轨迹及多域持续保持，都还缺少足够统一的控制。论文报告的“所有受测设置”只限定各自表格，不可扩展为全部模型和数据。
