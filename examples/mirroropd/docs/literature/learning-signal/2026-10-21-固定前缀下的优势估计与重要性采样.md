# 固定前缀下的优势估计与重要性采样

2026-10-22 将重复数学推导集中到[理论目录](../../theory/README.md)。本页保留论文实验、实现刷新时机与历史验算；原路径及章节锚点继续作为跳转入口。符号遵循[统一约定](../../theory/符号约定.md)。

在固定 prefix、目标为当前 student 的 reverse KL、采样分母正确且不做截断时，重算 current advantage 的 IS 梯度与目标梯度一致。固定 advantage 加 IS 优化另一个局部目标；它在参照策略处具有相同的一阶梯度，但不能在反复更新后继续视为相同目标。固定信号可以与明确的 KL 正则组成等价目标，也可以用于受约束的局部策略改进。

本文只研究固定前缀下的 next-token 分布。前缀可有多个，但其集合及权重保持固定；不对前缀采样分布求导或做 IS。资料核对日期为 2026-10-20；2026-10-21 仅统一符号，本仓源码基点为 `f5c017eae`。系统调度和运行参数另见 [infra 总览](../../infra/README.md)。

## 6. 论文与实现证据

### 6.1 直接对照与实验边界

AsyncOPD 第 5 节直接比较固定/重算 advantage 与有/无 clipping。其 Qwen3-4B-Base←Qwen3-30B-A3B-Instruct 实验报告重算且不 clip 的退化更慢。下表是准确率对 $\log_2(\mathrm{staleness}+1)$ 的拟合斜率，越接近 0 表示退化越慢，不是最终准确率。[^asyncopd]

| 基准   | 固定 A，clip | 固定 A，无 clip | 当前 A，clip | 当前 A，无 clip |
| ------ | -----------: | --------------: | -----------: | --------------: |
| AIME24 |        -1.44 |           -3.99 |        -1.64 |           -0.69 |
| AIME25 |        -1.42 |           -3.69 |        -1.88 |           -0.38 |
| AMC    |        -3.06 |           -8.00 |        -4.06 |           -1.12 |

论文的固定前缀推导直接对应本文范围；端到端实验还包含实际轨迹变化，不能视为本项目 1.5B 配方的固定前缀性能验证。

### 6.2 其他论文提供的证据

| 来源             | 与本文的关系                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------- |
| PPO              | 固定 advantage、多轮优化 surrogate 的出处；不是 current reverse-KL 无偏性的证明                             |
| GKD              | 固定生成序列后，对 teacher/student 的词表分布直接求 divergence 梯度；选择 reverse KL 时可作为局部全词表参照 |
| MiniLLM          | 单步项通过词表求和减少 Monte Carlo 方差；本文只参考其 single-step decomposition                             |
| Semi-OPD         | 固定初始 student 回答与 teacher 分数，每步重算 student 概率及 advantage；不等于精确 IS 修正                 |
| Lightning OPD v3 | 离线 teacher 缓存与训练时 student 信号；论文区分 surrogate gradient，源码还需检查刷新粒度                   |
| Dr. OPD          | 带权散度及显式采样标量目标；本文仅取固定动作权重为 1 的特例                                                 |

各来源分别见原文。[^ppo][^gkd][^minillm][^semiopd][^lightning-paper][^dropd] 不将这些论文统称为四种方案的直接对照。

### 6.3 刷新时机比变量名更重要

2026-10-20 审阅的本仓配置采用 temperature=1、top-p=1、`bypass_mode=False`，rollout IS/RS 均未开启，使用了行为分布与训练端锚点近似相同的假设。该记录保留原审计口径，不表示后续所有实验都使用相同设置。字段生产位置见 [old 概率计算](../../../../../verl/trainer/ppo/v1/trainer_base.py)和 [rollout correction](../../../../../verl/trainer/ppo/rollout_corr_helper.py)。

| 实现 / 审阅版本             | A 的生产位置                                                          | 一次训练调用内多次更新时         |
| --------------------------- | --------------------------------------------------------------------- | -------------------------------- |
| 本仓 verl / `f5c017eae`     | `distillation_loss()` 内读取当前训练 forward                          | 重算 current A；当前配方有 clip  |
| AsyncOPD / `e3f79e9`        | `policy_gradient_kl()` 的 `online_advantage` 分支                     | 显式支持两种 A                   |
| Tinker cookbook / `ad3b5c5` | `incorporate_kl_penalty()`，进入 `train_step()` 前                    | A 随 datum 固定传入              |
| slime / `a4202e0`           | `train_actor()` 中先 `compute_advantages_and_returns()`，再 `train()` | 后续更新消费预先计算的 A         |
| Lightning / `cd6b559`       | 其 slime 分支也在训练循环前计算                                       | 调用内固定，下一次调用可重新计算 |
| NeMo RL MOPD / `d1e23ad`    | `OPDAdvantageEstimator` 使用 teacher 与 `prev_logprobs`               | 先存训练数据，再由 policy 消费   |

源码入口分别见本仓 [distillation loss](../../../../../verl/trainer/distillation/losses.py)及固定版本引用。[^async-code][^tinker-code][^slime-code][^lightning-code][^nemo-opd]

Lightning 默认离线配方的一次 rollout batch 与优化 global batch 相同，通常每次调用只更新一次。因此训练前计算 A 与 loss 内计算 A 可以数值等价；不能据此认定多次内部更新都会重算，也不能说整个离线训练永久冻结 A。Tinker 默认 `num_substeps=1` 同样不足以证明固定 A 在大量重复更新后仍等价。[^lightning-code][^tinker-code]

AsyncOPD 的公开配方将 `pg_online_advantage` 设为 true，以很大的 clip 范围近似无 clip；代码仍保留 log-ratio 数值保护。数学上未截断的 IS 与工程实现的保护边界应分别说明。[^async-config]

## 7. 数值验算

固定 $\beta=q=(0.2,0.8)$、$T=(0.35,0.65)$，令 $p=(\sigma(z),1-\sigma(z))$。表中是 loss 对 $z$ 的梯度；负数推动第一个 token 概率上升，clip 范围为 $[0.8,1.2]$。

| 当前第一项概率 | 固定 A + IS | 固定 A + clip | 当前 A + IS | 当前 A + clip |
| -------------- | ----------: | ------------: | ----------: | ------------: |
| 0.20           |   -0.122761 |     -0.122761 |   -0.122761 |     -0.122761 |
| 0.26           |   -0.147620 |     -0.039950 |   -0.082141 |     -0.024950 |
| 0.35           |   -0.174551 |     -0.047238 |           0 |             0 |
| 0.50           |   -0.191814 |             0 |    0.154760 |      0.154760 |

该例枚举完整动作空间并按 $\beta$ 加权，排除了样本噪声。它说明固定信号可能在匹配 teacher 后继续推动，也可能被 clip 停在不同位置；不构成 LLM 质量优劣的证明。

[CPU 验算脚本](../../../research/objectives/verify_fixed_prefix.py)在 20 组七分类随机分布上检查完整 KL、current surrogate、固定 A 加 KL 正则、修正标量 loss、无 IS 的 log-prob 平方误差关系，并可调用指定 AsyncOPD 源码。已保存的[结果](data/gradient-audit.json)中，解析实现差异约为 $10^{-16}$，作者实现因内部 FP32 转换产生约 $10^{-7}$ 差异。测试只使用 CPU 张量，没有加载 LLM。

```bash
python -m examples.mirroropd.research.objectives.verify_fixed_prefix

# 可选：对照上述固定版本的作者源码；目录需要事先准备。
python -m examples.mirroropd.research.objectives.verify_fixed_prefix \
  --async-opd-root /path/to/async-opd-e3f79e916aad9dba886256d202bab96f8504a447
```

## 8. 本项目的实验决策

以“重算 A + 正确行为 IS + 无 PPO clip”为固定前缀数学参照，保留其他三组对照。使用相同 prefix、样本、teacher 分数和真实采样概率，比较 1/2/4/8 次更新；不同时改变 optimizer、mask、聚合、归一化或 reward。

小规模审计优先记录真实全词表 reverse KL、与完整 KL 梯度的方向差异、IS 长尾和重复更新后的偏差。有限缓存、clipping 和不同 surrogate 数值口径都会影响训练日志；单个 token 的 loss 也不能代表全词表 KL，不能仅靠跨方案的 loss 曲线比较目标改善。

原 2026-10-20 审阅配方每批只更新一次，理想情况下 current 与 old A 在该更新处相同；差异主要在多次复用后出现。共享八卡首版保持现有 loss 和更新次数，概率估计器的实验另行进行。运行时最小性能指标由[指标方案](../../settings/指标口径.md)负责，不在数学实验中扩展系统监控。
