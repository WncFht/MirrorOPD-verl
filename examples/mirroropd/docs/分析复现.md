## 重新导出 W&B

每次选择一个新的快照目录；工具拒绝覆盖已有目录。默认实体/项目/run 为 `wncfht/MirrorOPD-verl/b38hw8v0`，可用 `--run` 指定其他实验。凭据可由 SDK 的正常配置提供，也可显式选择本机有权限的 netrc 文件：

```bash
python3 examples/mirroropd/docs/scripts/analyze_run.py export \
  --netrc-file /本机私密目录/netrc \
  --out examples/mirroropd/docs/data/b38hw8v0-api-新日期
```

新增的两个参考可使用同一入口下载；它们只有评测 history，没有训练 step，`analysis.json` 中 training_rows=0 属于正常情况：

```bash
python3 examples/mirroropd/docs/scripts/analyze_run.py export \
  --run wncfht/One-Shot-OPD/6uorrk2k --netrc-file /本机私密目录/netrc \
  --out examples/mirroropd/docs/data/oneshot-student-6uorrk2k-新日期
python3 examples/mirroropd/docs/scripts/analyze_run.py export \
  --run wncfht/One-Shot-OPD/u87buult --netrc-file /本机私密目录/netrc \
  --out examples/mirroropd/docs/data/oneshot-teacher-u87buult-新日期
```

`--api-key-file` 接受只含 key 的本地文件，与 `--netrc-file` 互斥；不要把 key 写到命令行或仓库文件。默认 endpoint 是 `https://api.forge.coreweave.com`。模型/训练密钥类配置字段会被脱敏，但发布其他 run 的配置前仍应检查导出内容。

训练 history 使用 `scan_history`，不传 keys，避免只保留所有 keys 交集而漏掉稀疏验证行。先固定 `lastHistoryStep` 边界，再读取该范围。系统 `history(stream="system", samples=100000)` 是单独的抽样接口，不能把较大的 samples 参数当成全量保证。在线 run 读取期间仍可能新增数据，快照只描述记录的边界与读取时点。

硬件和包版本通过同一凭据读取该 run 的 metadata / requirements 文件；这些文件缺失时会提示，而不会用本机包版本冒充训练环境。Git commit 是 metadata 报告值，工作区未提交改动需另保存 `source_changes.patch`。

## 从本地日志提取指标

```bash
python3 examples/mirroropd/docs/scripts/analyze_run.py import-log \
  --log /实验目录/train.log \
  --out examples/mirroropd/docs/data/本地日志快照
```

支持 `step:N - key:value` 和日志里的 `np.float64(...)` / `np.int64(...)` 数值包装；同一步重复输出保留最后一行。日志导入不会生成不存在的 W&B config、验证数据或 GPU 采样。`--gpus` 和 `--batch` 默认 8、64；其他资源配置必须显式传实际值，不能盲用本实验的吞吐分母。

## 重算统计与绘图

```bash
python3 examples/mirroropd/docs/scripts/analyze_run.py summarize \
  --out examples/mirroropd/docs/data/b38hw8v0-api-20261020
python3 examples/mirroropd/docs/scripts/analyze_system.py \
  --data examples/mirroropd/docs/data/b38hw8v0-api-20261020

# PYTHON 指向已有的 Matplotlib/NumPy 环境；不安装或升级训练依赖。
export FIGURE_VIZ_HOME=/figure-viz/skill/实际目录
"$PYTHON" examples/mirroropd/docs/scripts/plot_run.py \
  --data examples/mirroropd/docs/data/b38hw8v0-api-20261020 \
  --student-baseline examples/mirroropd/docs/data/oneshot-student-6uorrk2k-api-20261020 \
  --teacher-baseline examples/mirroropd/docs/data/oneshot-teacher-u87buult-api-20261020 \
  --out examples/mirroropd/docs/figures/b38hw8v0-api-20261020
"$PYTHON" examples/mirroropd/docs/scripts/plot_system.py \
  --data examples/mirroropd/docs/data/b38hw8v0-api-20261020 \
  --out examples/mirroropd/docs/figures/b38hw8v0-api-20261020
```

`FIGURE_VIZ_HOME` 下应存在 `assets/mpl/fvstyle.py`；定位逻辑来自 figure-viz 的 `fvlocate.py`，也支持已安装的标准 skill 路径。图表使用该 skill 的统一配色、样式和 `fv.audit(fig)`；输出 PNG 和矢量 PDF，共用可编辑 Python 源文件。机器审计后另检查 PNG 的标签、图例、裁切与颜色语义。

本快照提供 training、validation、timing、memory-mfu、system-gpu 五张图；验证只有一个训练后 checkpoint，因此用三个面板的分组柱状图比较 student 外部参考、OPD step 20 和 teacher 外部参考，未生成不存在的验证趋势。两个外部 run 记录的 pass@16 没有与当前 bootstrap best@16 混用。System 图的 0–3 与 4–7 是物理编号分组，不由绘图工具强制指定 student/teacher 身份。

MFU 的数值复算命令、长度平方项和内部 timer 边界见 [MFU 计算](2026-10-20-MFU计算.md)。
