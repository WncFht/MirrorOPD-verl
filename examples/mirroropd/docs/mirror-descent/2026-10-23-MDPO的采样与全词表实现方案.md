# MDPO 的采样与全词表实现方案

本文只讨论固定 state 的 MDPO。重点取一般 $0<\kappa<1$、$0<\eta<1$，同时保留 $\kappa=0$ 的解析分支；不依赖算术端点 $\kappa=1$ 或原 teacher 端点 $\eta=1$ 简化。目标定义的推导见[形状与插值理论](2026-10-23-形状与插值目标及Full-vocab离策略实现.md#target)，这里集中说明两条路径的计算图、数据合同和接入位置。本文是实现方案，生产代码尚未增加 MDPO 模式。

## 1. 两条实现必须共享的数学合同

每轮冻结锚点 $q=q_k$ 和原 teacher $T$；实际动作来自行为策略 $\beta$，当前学生为 $p=p_{k,n}$。定义

$$
r_a=\log T_a-\log q_a,\qquad
f_a=\frac{\log(1-\eta+\eta e^{\kappa r_a})}{\kappa},\qquad
U_a=\log p_a-\log q_a.
$$

$\kappa=0$ 时使用 $f_a=\eta r_a$。$f,q,T$ 整轮冻结；$U,p$ 每次更新后重算。真正要优化的是

$$
L_{\rm MDPO}=\frac1\eta\sum_ap_a(U_a-f_a),\qquad
\nabla L_{\rm MDPO}=\sum_ap_aR_a\nabla\log p_a,
\quad R_a=\frac{U_a-f_a}{\eta}.
$$

目标 teacher 为 $m_a=q_ae^{f_a}/Z$，所以 $L_{\rm fit}=\mathrm{KL}(p\Vert m)/\eta$ 与 MDPO 只差冻结常数 $\log Z/\eta$。Sampled 路径估计上述梯度；full-vocab 路径完整求和。二者不能一个使用 $1/\eta$、另一个省略后还声称梯度等价。

这里没有再选择 ordinary OPD 的 current/frozen advantage：**教师信号 $f$ 固定，实际 cost residual $R$ 随当前 $p$ 刷新**。Reward 形式为 $B=-R=(f-U)/\eta$。把 $f$ 改成 $f(\log T-\log p)$ 会变成 current-J；只用固定 $f/\eta$ 而没有 $U/\eta$ 则漏掉镜像项。

## 2. Sampled-token：缓存标量，用真实行为概率做 IS

<a id="sampled"></a>

### 2.1 每个有效 token 保存什么

| 字段 | 来源 | 生命周期 |
| --- | --- | --- |
| `log_beta` | 实际生成时对动作的 log-prob | 数据生成后固定 |
| `log_q` | 本轮冻结 anchor 对该动作评分 | 本轮所有 inner updates 固定 |
| `log_T` 或预计算的 `f` | 原 teacher 对该动作评分，再与 `log_q` 组合 | 本轮固定 |
| `log_p` | Actor 当前有梯度 forward | 每次 inner update 重算 |

从实际 $\beta$ 采样时，行为权重为 $w_a=p_a/\beta_a$，不是无条件使用 $p_a/q_a$。即使同权重 rollout 与 FSDP 在数学理想化中相同，也不能默认它们保存的概率逐位一致。

现有 `old_log_probs` 可以承载 `log_q`，但必须确保它由本轮 anchor 产生并整轮冻结，不能用 bypass 将它替换为另一行为策略的分数。当前 sampled 的 `advantage_source=rollout` 使用 `log T-log beta`，一般不等于所需的 `log T-log q`。

### 2.2 推荐的反向计算图

以下代码是有效位置上的局部参照；正式接入还需沿用现有 mask、DP 和 global token reduction。

```python
# Semantics: sampled MDPO gradient; q/T/beta frozen, residual refreshed each update.
# mirror_signal computes the general kappa/eta f, with an analytic kappa=0 branch.
with torch.no_grad():
    f = mirror_signal(log_T - log_q, kappa, eta)
    residual = (log_p.detach() - log_q - f) / eta

ratio = torch.exp(log_p - log_beta)  # ratio retains the student gradient
loss_per_token = ratio * residual  # residual is detached for this backward only
```

对固定样本反传得到 $w_aR_a\psi_a$；在 $\beta$ 下取期望：

$$
\mathbb E_\beta[wR\psi]=\sum_ap_aR_a\psi_a=\nabla L_{\rm MDPO}.
$$

也可使用 `loss_per_token = (ratio * residual).detach() * log_p`，一阶梯度相同，但前向 scalar 不同。不要用带梯度的 `ratio * residual.detach() * log_p`，它会重复引入 ratio 和 log-prob 两条导数。

第一种写法的前向值是 MDPO 积分的单动作估计。若直接对未 detach 的 `ratio * residual` 求导，会额外产生 $w\psi/\eta$：该项在完整动作期望下为零，在有限样本上增加另一项随机贡献。因此本文明确选择只对 ratio 求导的 score 实现，并用独立 loss 指标区分优化代理与真实 target KL。

整轮缓存的是 $f$，不是 `residual`。第二次更新必须重新读取 `log_p`、重新计算 $U$ 和 ratio，然后再 detach 当次 residual。

### 2.3 不需要 full-vocab normalizer 或精确中心

该 sampled 梯度只需实际动作的三个冻结 log-prob 和当前 log-prob。它不需要 $Z$，也不必精确计算 $K_T=-\mathbb E_q(f/\eta)$；这些都是在完整 $p$ 积分下不影响梯度的动作无关常数。

如果为了降低采样方差额外引入中心，应单独定义 baseline 并验证估计方式。首版不必为此加入完整词表数据通路。加 PPO clip 后，动作无关 baseline 会影响符号和截断区域，不能再随意替换未中心化 residual。

### 2.4 在当前代码中改哪里

[_sampled_token_loss](../../../../verl/trainer/distillation/losses.py#L405) 已有真实 behavior 分母、mask 和 global reduction，可复用外壳，但需提供独立 MDPO residual 分支。其现有 `current_advantage/frozen_advantage` 两种普通 log-gap 都不完整表达一般 $\kappa,\eta$ 的 MDPO。

Teacher sampled scoring 和 student anchor scoring 可以沿用既有阶段；新增的是冻结 `log_q` 的语义校验、非线性 $f$ 和当前漂移项 $U/\eta$。首版选择没有 PPO clip 的 IS 梯度；现有 `[-20,20]` log-ratio guard 若保留，需记录命中数并承认命中时偏离精确公式。

## 3. Full-vocab：构造冻结目标，复用精确 KL 的梯度结构

<a id="full-vocab"></a>

### 3.1 Dense oracle

```python
# Semantics: full-vocabulary MDPO; fixed anchor and teacher, current student.
log_p = student_logits.log_softmax(-1)
with torch.no_grad():
    log_q = anchor_logits.log_softmax(-1)
    log_T = teacher_logits.log_softmax(-1)
    f = mirror_signal(log_T - log_q, kappa, eta)
    log_h = log_q + f
    log_m = log_h - log_h.logsumexp(-1, keepdim=True)

target_kl_per_state = (log_p.exp() * (log_p - log_m)).sum(-1)
loss_per_state = target_kl_per_state / eta
```

这里没有 $\beta$ 或 ratio；完整词表已经按当前 $p$ 精确积分。Full-vocab 与 sampled MDPO 的理论区别是动作积分是否抽样，目标和 $q,T$ 的冻结方式保持一致。

一般形状下，必须先求出 q/T 各自归一化的 log-prob。直接混合两组未归一化 logits 会改变幂均值目标。稳定的信号函数复用[已有 CPU 参照](scripts/verify_mirror_targets.py#L17)：小 `kappa*r` 用 `log1p/expm1`，其余用 `logaddexp`，端点走解析分支。

### 3.2 数据通路需要新增 anchor hidden/head

当前 full reverse-KL 算子只有 `hs, ws, ht, wt`，见 [full_reverse_kl:193](../../../../verl/trainer/distillation/full_vocab.py#L193)。一般 MDPO 还需要冻结 anchor 分布，建议增加 `hq, wq`：

| Tensor | 含义 | 是否求导 |
| --- | --- | --- |
| `hs, ws` | 当前 student 有效预测行 hidden、head | 是 |
| `hq, wq` | 本轮 anchor 的有效预测行 hidden、head 快照 | 否 |
| `ht, wt` | 原 teacher 的有效预测行 hidden、head | 否 |

`hq` 按现有 sample key 与 prediction positions 写入 CPU/TQ；`wq` 是每轮独立存储的冻结 head 快照。仅 `detach()` 不隔离存储，必须避免 optimizer 更新原 student weight 后连带改动 `wq`。

必须在本轮任何 optimizer step 之前取得所有所需 anchor 信息。通用顺序为：固定 q → anchor scoring → teacher scoring → 多次 actor 更新。可复用原有 student scoring 调度，但 anchor 阶段输出 hidden，而不是只有 sampled `old_log_probs`。每次 inner update 都从缓存重建同一个 q；不可把更新后的 student 再当成本轮 q。

原有 teacher async write、actor prefetch、有效位置筛选和 key 对齐可以扩展到 anchor payload。它们解决传输与驻留，不替代冻结语义。只缓存实际动作的 `old_log_probs` 无法恢复 full-vocab q。

### 3.3 Token 分块和 precompute/fused

每个 token 块执行：重建 q/T logits 及各自 normalizer → 生成冻结 `log_h` → 重建当前 student logits → 计算 target KL 与 student logit 梯度 → 累积 student `dH/dW`。块处理顺序可以按工作区复用调整。

令 $b_a=\log h_a$、student logits 为 $z_a$，定义 $\mu=\sum_ap_a(z_a-b_a)$，则

$$
K(p,m)=\mu-\log Z_p+\log\sum_ae^{b_a},\qquad
\frac{\partial K(p,m)}{\partial z_a}=p_a(z_a-b_a-\mu).
$$

这与现有 `fused_rows(zp, zt, dtype)` 的归约形式相同：可以把第二组输入从线性 teacher logits 换成分块构造的 `b`，继续使用当前 precompute 的梯度累计和 FSDP head hooks。见 [fused_rows:68](../../../../verl/trainer/distillation/full_vocab_triton.py#L68) 与 [PrecomputedKL:151](../../../../verl/trainer/distillation/full_vocab.py#L151)。

数学上 m 整轮固定，工程上可以每次从同一组冻结 hidden/head 重建当前块，避免长期缓存完整词表的 m 或 f。构造后的 b 保持 FP32、连续布局再进入融合归约，不先舍入到 BF16。

算子仍可返回未归一化的 target KL token sum，loss 层统一乘 $1/\eta$ 和现有 DP/global-token 系数；backward 的上游梯度会把这两个尺度传给缓存 VJP。不要在算子和 loss 层各除一次 $\eta$。只返回 student hidden/head 梯度，q/T 的四个 tensor 都返回 None。

首版先实现可读的 PyTorch precompute，再适配 fused reduction；不要将目标构造与优化 kernel 一次混在一起验证。Liger 当前入口要求线性 teacher hidden/head，不能把非线性幂均值 $m$ 直接当作一个新的固定线性 head；需单独适配后才能支持该 backend。

### 3.4 保留原始 MDPO scalar 的另一写法

直接完整求和 $(p\cdot(\log p-\log q-f)).\mathrm{sum}/\eta$，也可得到同一梯度，且不需要最终的 `log Z`。但此时记录的是 $L_{\rm MDPO}$，不是归一化 target KL。q/T 的 normalizer 仍然需要；省去最终目标 normalizer 不代表可以省去构造一般 $f$ 所需的归一化。

若首版同时记录 target KL、MDPO loss 和两者的冻结常数差，可更容易发现归一化错误。当前 teacher KL 指标不能直接改名后复用为 target KL；原 teacher $T$ 与本轮目标 $m$ 是两个不同对象。

## 4. 建议的最小代码组织

<a id="code-plan"></a>

| 层 | 建议改动 | 复用内容 |
| --- | --- | --- |
| 目标与配置 | 独立 MDPO 模式，统一 `kappa/eta`；sampled/full-vocab 入口明确区分 | 现有 loss registry 与 payload 类型 |
| 信号函数 | 纯张量 `mirror_signal(log_T-log_q, kappa, eta)` | 两条路径共用相同稳定表达式 |
| Sampled loss | 当前 `log_p` + 冻结 scalar fields → residual + IS | Mask、reduction、ratio 诊断 |
| Full-vocab 目标构造 | q/T 分块 log-prob → 冻结 `log_h` | 原 teacher/current student projection |
| Anchor 生命周期 | 外层版本、hidden keys/positions、独立 head 快照 | Teacher hidden IO、FSDP hooks、阶段 offload |
| Full-vocab VJP | 当前 logits 与 `log_h` → KL 与 `dZ` | Precompute、Triton rows、`addmm` 与 optimizer |

一个低复杂度的首版可以给出两个显式 loss mode（例如 `mdpo_sampled`、`mdpo_full_vocab`，名称尚未实施），共享一份 MDPO 参数和信号函数。不要将“换目标”塞到普通 `advantage_source=current/rollout` 中，也不要复制一套 trainer/optimizer。

目前 [DistillationLossConfig](../../../../verl/workers/config/distillation.py#L124) 的校验和 trainer 的 Full-KL 判断仍按已有模式编写。接入新模式时要同步更新能力判断、teacher payload、anchor scoring 和 loss dispatcher，不能只改最后一行 loss 后以为数据通路自动成立。

## 5. 默认选择与验收顺序

两条路径都先固定 $q,T$、重算 $p,U$，不加入 PPO clip、advantage whitening 或 task reward。Sampled 使用完整 $p/\beta$；full-vocab 不额外乘 sampled ratio。现有 norm clipping 可保留，但它属于 optimizer 更新控制，不是 MDPO 的动作 clip。

首组验收使用一般形状，如 $\kappa=0.5,\eta=0.3$，以及多个 inner updates，使 $p$ 真正离开 q。检查顺序为：

1. 全词表 dense MDPO 与 sampled IS 的完整动作枚举期望梯度一致。
2. 第二次、第三次更新仍使用同一个 q/f，只有 p/U/ratio 刷新。
3. Full-vocab 的 precompute/fused 与 dense oracle 同时对齐 student hidden 和 head 梯度，q/T 无梯度。
4. 打乱样本、改变 micro-batch 切分后，anchor/teacher keys、positions 与 mask 仍对应。
5. 单 rank 零有效 token、不等长样本和多卡归一化正确；head 快照不随 optimizer 更新改变。
6. 完整训练验收后，再独立讨论 clip、IS guard、baseline 和性能，避免让这些变更掩盖目标错误。

已有 [CPU FP64 验算](scripts/verify_mirror_targets.py)已经核对一般形状的 target、logit 梯度、IS、detach 与常数身份；其 [2,348 项结果](data/finite-vocab-checks.json)是理论与计算图参照，不是新增 MDPO 生产后端的验收。

本文两个 Python 片段另以 $\kappa=0.5,\eta=0.3$ 验证了固定 q 的三次连续更新：$q=(0.1,0.3,0.2,0.4)$、$T=(0.4,0.1,0.4,0.1)$、$\beta=(0.2,0.4,0.3,0.1)$，从 `logits=log q` 开始，每步按 full 梯度做学习率 0.1 的普通更新。枚举全部动作得到的 sampled 期望梯度与 dense full-vocab 梯度最大绝对差约 $2.8\times10^{-16}$；这不是单次随机动作梯度必然相同的声明。
