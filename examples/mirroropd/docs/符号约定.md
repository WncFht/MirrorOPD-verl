# 文档统一符号约定

固定前缀下的目标、梯度、full-vocab 与镜像下降推导统一由[理论目录](theory/README.md)维护；本页继续作为跨目录的符号定义入口。

本目录的理论符号以同级项目 [MirrorOPD 核心稿的阅读约定](../../../../MirrorOPD/theory/core/sections/reading.tex)、[冻结信号定义](../../../../MirrorOPD/theory/core/sections/01_mirror.tex)、[内层拟合](../../../../MirrorOPD/theory/core/sections/04_inner.tex)和[条件积分估计](../../../../MirrorOPD/theory/core/appendices/e_estimation.tex)为准。2026-10-21 将本目录的手写公式统一到这套约定；训练配置、源码接口、论文原名、冻结实验数据和外部原始检索记录保留原样。

## 1. 分布、轮次和信号

| 记号 | 固定含义 |
| --- | --- |
| $T(\cdot\mid s)$ | 原始冻结教师；不再用 $q$ 表示教师 |
| $q_k(\cdot\mid s)$ | 第 $k$ 轮冻结学生锚点；省略外层下标时记为 $q$ |
| $p_{k,n}=p_{\theta_{k,n}}$ | 第 $k$ 轮、第 $n$ 步内层的当前学生；局部简写为 $p$ 或 $p_\theta$ |
| $m_k$ | 镜像子问题定义的目标教师；不等同于有限优化后的实际学生 |
| $\kappa,\eta$ | 目标形状与教师插值权重；沿用核心稿，不用作 optimizer LR |
| $\alpha_{\rm opt}$ | 参数优化器学习率 |
| $\tau$ | 固定教师目标后另选的镜像步长；带分布下标的 $\tau_p,\tau_T$ 才表示尾质量 |
| $\rho_a=T_a/q_a,\ r_a=\log\rho_a$ | 冻结的教师—锚点概率比及对数比；$\rho$ 不表示行为 IS |
| $f,\ A=f/\eta$ | 冻结信号、标准化但尚未中心化的教师信号 |
| $K_T=-\mathbb E_q A$ | 本轮冻结教师中心；$\kappa=0$ 时为 $\mathrm{KL}(q\Vert T)$ |
| $\mathcal A_k=C_qA=A+K_T$ | 按锚点中心化的本轮优势，$\mathbb E_q\mathcal A_k=0$ |
| $C_qh=h-\mathbb E_qh$ | 同一前缀下按锚点进行中心化 |
| $U_a=\log(p_a/q_a),\ K_S=\mathrm{KL}(q\Vert p)$ | 当前学生—锚点对数比及学生中心；随内层更新重算 |
| $F_k,J_{\kappa,\eta},L_k$ | 重心目标、教师目标、内层拟合损失 |
| $d_k,\widehat d_k$ | 冻结的总体、经验前缀访问测度 |
| $N,M,K_{\rm head}$ | 每轮内层步数、同前缀辅助动作数、头部候选动作数 |
| $\psi_a=\nabla_\theta\log p_a$ | 参数 score；$g_{k,n}$ 是参数梯度，区别于概率空间的 $g_k=-\mathcal A_k$ |

正文中的自然对数、KL 方向、向量方差（协方差迹）与核心稿一致。完整词表求和仅消除给定前缀的动作积分误差，不消除前缀覆盖、有限样本和模型表示误差。

## 2. 实际行为策略与代码字段

核心稿的理想同步情形从 $q_k$ 生成数据；实现中不同后端的同权重模型可能给出不同概率。因此沿用核心稿附录 E 的动作提案记号 $\beta$，表示实际 rollout 行为分布，而不强行令其等于 FSDP 冻结锚点。

| 数据 / 数学量 | 统一含义 |
| --- | --- |
| `rollout_log_probs` | $\log\beta(a\mid s)$，实际生成时保存的行为概率 |
| `old_log_probs` | $\log q_k(a\mid s)$，更新前重算的冻结参照；bypass 模式除外 |
| 当前 `model_output["log_probs"]` | $\log p_{k,n}(a\mid s)$ |
| `teacher_logprobs` | $\log T(a\mid s)$；候选维度和位置布局另由数据合同定义 |
| $w_\theta=p_\theta/\beta$ | 完整行为 IS 权重 |
| $w^{\rm PPO}=p_\theta/q_k$ | Legacy PPO 的更新比率 |
| $w^{\rm corr}=q_k/\beta$ | 额外行为校正；未截断时 $w^{\rm corr}w^{\rm PPO}=w_\theta$ |

这里的 $q_k$ 是冻结参照的理论角色；后端数值差异用 $\beta\ne q_k$ 明示。理想同步初始化是 $p_{k,0}=q_k=\beta$，不是对实际 kernel 的逐位相等承诺。

本仓 E 系列使用未中心化的 OPD 信号：

$$
A^{\rm cur}(a)=\log\frac{T_a}{p_a},\qquad
A^{\rm anchor}(a)=\log\frac{T_a}{q_a}=r_a,\qquad
A^{\rm roll}(a)=\log\frac{T_a}{\beta_a}.
$$

$A^{\rm anchor}$ 是核心稿 $\kappa=0$ 的冻结 $A$；$A^{\rm cur}$ 随当前学生刷新；$A^{\rm roll}$ 只有在 $\beta=q$ 时才等于 $A^{\rm anchor}$。代码和实验标签中的 “advantage / fixed A / current A” 保留兼容名称，但不意味着它们自动满足核心稿 $\mathcal A_k$ 的零条件均值约束。

KL baseline 使用当前条件标量 $K(p,T)=\mathrm{KL}(p\Vert T)$ 时，中心化信号为 $C_pA^{\rm cur}=A^{\rm cur}+K(p,T)$。仅在 $p=q_k$、$\kappa=0$ 时，它与冻结的 $\mathcal A_k=A+K_T$ 重合；不得将随更新变化的 $K(p,T)$ 仍记为整轮冻结的 $K_T$。

## 3. 局部估计器的扩展记号

核心稿附录 E 允许以 $P$ 表示可微分布、$Q$ 表示冻结参考，具体 OPD 文档统一代入 $P=p,Q=T$。分区和支持保持在相同前缀下固定。

| 记号 | 含义 |
| --- | --- |
| $\ell_a=\log(p_a/T_a)$ | 当前 reverse-KL 的逐动作成本；与冻结 $r_a=\log(T_a/q_a)$ 分开 |
| $r^{\rm cur}_a=-\ell_a$ | 当前 sampled-token reward |
| $S,\ K_{\rm head}=\lvert S\rvert$ | 固定支持集及候选数；算法名中的 top-k 原名不改写 |
| $p_S=\sum_{a\in S}p_a,\ T_S=\sum_{a\in S}T_a$ | 头部质量 |
| $\tau_p=1-p_S,\tau_T=1-T_S$ | 尾部质量，区别于无下标的镜像步长 $\tau$ |
| $\ell_{\rm tail}=\log(\tau_p/\tau_T)$ | 尾桶对数质量比 |
| $v_a=\ell_a\psi_a,\ g_{\rm head}=\sum_{a\in S}p_av_a$ | 单动作参数梯度、精确头部参数梯度；不占用冻结信号 $f$ |
| $\mathbf b_{\rm tail}=\ell_{\rm tail}\nabla\log\tau_p$ | ResOPD 的尾桶向量控制 |
| $C(s),\ b_{\rm base}(s)=-C(s)$ | 成本形式的标量 baseline 与相应 reward baseline |
| $\lambda_{\rm reg}$ | 额外 KL 正则系数；不用提案分布 $\beta$ 作为系数 |

## 4. 工程数量使用带职责的符号

| 记号 | 含义 |
| --- | --- |
| $B_{\rm prompt},n_{\rm resp},B_{\rm rollout}$ | Prompt 数、每题回答数、总回答数；$B_{\rm rollout}=B_{\rm prompt}n_{\rm resp}$ |
| $B_{\rm mini},B_{\rm micro}$ | 一次 optimizer update 的全局回答数、每卡 micro-batch 的回答数 |
| $G_{\rm DP},n_{\rm accum},E_{\rm PPO}$ | 数据并行度、梯度累积次数、同批遍历次数 |
| $N=E_{\rm PPO}B_{\rm rollout}/B_{\rm mini}$ | 无过滤/尾批且可整除时，每轮实际内层更新数的配置预期；运行计数仍取执行事实 |
| $B_{\rm tok},C_{\rm tok},K_{\rm tile}$ | 动态 micro-batch token 预算、位置分块大小、词表 tile 大小 |
| $\mathsf T_{\rm resp},\mathsf T_{\rm seq},\mathsf T$ | Response 位置数、完整序列位置数、按局部口径定义的总 token 数；$T$ 始终留给教师 |
| $L_{\rm prompt,i},H_i,L_i$ | Prompt 长度、生成 response 长度、输入总长度；$L_i=L_{\rm prompt,i}+H_i$ |
| $\mathsf Q_2=\sum_iL_i^2$ | Attention FLOPs 使用的长度平方和 |
| $d_{\rm hid},d_{\rm ff},n_{\rm layer},n_{\rm qh},n_{\rm kvh}$ | 模型维度、层数、attention head 数 |
| $V=\lvert\mathcal V\rvert$ | 词表宽度；工程公式可写 $V$，分布仍定义在 $\mathcal V$ 上 |
| $\mathsf P_{\rm dense}$ | 矩阵参数个数；不表示概率分布或前缀 batch |
| $M_{\rm KV,S},M_{\rm KV,T}$ | Student/teacher KV cache 字节量；不用中心量 $K_S,K_T$ 表示显存 |
| $\mathsf t,v_{\rm eff},B_{\rm bytes},v_{\rm bytes}$ | 墙钟时间、有效吞吐、搬运字节、有效字节带宽 |

工程中带明确阶段下标的 $t_{\rm new}$ 等也表示墙钟，不是核心稿梯度流时间 $t$。流式 softmax 的 running max 记为 $\zeta_p,\zeta_T$；归一化量 $Z_p,Z_T$ 及加权累加器 $\mathsf U$ 都带分布/算法语境，不复用内层对数比 $U=\log(p/q)$。

## 5. 源码、历史数据与论文记号的对应

手写公式统一，外部证据和程序接口保持可追溯。例如 `verify_reward_estimators.py` 的 `log_q` / `q` 是作者估计器中 teacher 概率，在本文公式中映射为 $T$；`mu` 映射为 $\beta$；`rho` 映射为行为权重 $w$。`verify_fixed_prefix.py` 同样保留 `mu`、`log_teacher` 等 Python 变量。JSON 的 `q`、`hidden`、`micro_tokens`，以及 MFU 脚本的 `T,Q` 键不改写，解释分别映射为教师、hidden 维度、token 预算和 $\mathsf T,\mathsf Q_2$。

这些兼容名称不构成第二套理论定义。引用原论文的公式时如需保留其字母，应紧邻给出对应关系；本目录自己的推导直接采用上表。模型概率变化、目标变化或 baseline 中心变化不能以“符号统一”为由改动。
