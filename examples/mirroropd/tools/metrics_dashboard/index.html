指标口径与比较边界

Held-out 图按题平均完整回答的 token RKL；训练 loss 按 token 聚合，两者不直接相减。实线训练点来自每批第 1 次更新前，虚线来自最后一次 reuse 更新前，缺失该日志的历史运行不补点。

固定 bank 在每个运行内保持不变；不同运行可能独立采样回答，因此初始值可能不同。请结合原始值和相对降幅看后段趋势。历史 AdamW 的 WD=0.01，当前 SGD 的 WD=0，比较包含衰减差异。跨师生 pair 的绝对 RKL 不代表统一难度。RKL 不等于任务准确率。

旧日志使用 domain/math 指标；若存在 dataset/math，则优先使用独立题集指标，避免混入开发集。开发集缺失时保留为空。曲线无平滑、无插值、无缺失值填充。鼠标滚轮或下方滑块缩放，可通过图例暂时隐藏单条曲线。
